# Round 9 — BTC 4년 +1590% 목표 재설계

작성일: 2026-08-21
범위: 연구 백테스트와 shadow 설계만. demo/live/실계좌 승격은 제외한다.

## 목표와 기준선

- 2022-01-01~2025-12-31 연속복리 기준선: +159.81%, 최종자산 2.5981배,
  CAGR 약 26.96%, MDD 16.20%, PF 1.924, 113건, 청산 접근 0건.
- stretch 목표 +1590%는 최종자산 16.9배, 4년 CAGR 약 102.76%다.
- +1590%만 맞고 실행 가능성·낙폭·holdout이 실패한 결과는 불합격이다.

## 고정 조건

1. 메인 신호·손절·청산과 Swing Lane B 신호 파라미터는 바꾸지 않는다.
2. 변동성 event 레인은 PF 0.62~1.01로 실패했으므로 OFF를 유지한다.
3. BTC/ETH L 계층은 강건성 WEAK라 노출 확대 근거로 사용하지 않는다.
4. 수수료·슬리피지·펀딩을 제거하거나 미래정보를 쓰지 않는다.

## 포트폴리오 설계

- Core 성숙추세와 Swing Lane B 추세초입을 공유 자본으로 결합한다.
- 위험기여 비율은 `core:swing = 2:1`로 고정한다.
- 유일한 탐색축 `g`:
  - core lifecycle 위험 = `2% × g`
  - swing 위험 = `1% × g`
  - 사전등록 후보 `g=1.0~3.5`, 0.25 간격 전체를 보고한다.
- 서로 반대 방향 신규 진입은 차단한다.
- 총 명목노출은 equity 8x 이하, open stop heat는 equity 10% 이하로 강제한다.
- swing 단독 명목노출은 기존 5x 이하로 유지한다.

### 인과적인 drawdown governor

- DD < 10%: 1.00x
- 10~15%: 0.75x
- 15~20%: 0.50x
- 20~25%: 0.25x
- DD ≥ 25%: 신규 진입 중단, 기존 stop/청산 유지

새 주문 시점까지 확정된 실현 equity와 고점만 사용한다.

## 합격 기준

1. 2022~2025 최종자산 ≥ 16.9배.
2. closed MDD ≤ 30%, 과거 공동 시뮬의 1.5배 보정 intra-MDD ≤ 45%.
3. gross ≤ 8x, heat ≤ 10%, 청산 접근 0건.
4. 네 연도 중 최소 세 연도 양수, 어떤 연도도 -25% 미만이 아님.
5. governor 결과가 최종자산 10배 이상을 유지.
6. 2021·2026 holdout 합산 양수.

**+1590% 목표 미달. production 위험 상향 금지.**

   아니라 리더 선택을 2022~2023에서 고정하고 2024~2025에 검증한다.
2. delta-neutral spot/perp basis·funding carry. 실제 basis, borrow, 수수료 포함.
3. BTCDOM 또는 crypto breadth trend. 장기 원본 데이터 수집 후 사전등록한다.
