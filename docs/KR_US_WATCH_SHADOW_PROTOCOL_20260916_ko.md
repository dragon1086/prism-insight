# 한국·미국 후보 감시 × 초분할 SHADOW 관측 계약

## 승인 범위와 현재 단계

2026-09-16 사용자 승인에 따라 기존 미국 연구를 한국에도 연결한다. 기존 설계
`ONEIL_WATCHLIST_MICRO_SPLIT_SHADOW_ko.md`의 US-only 범위를 확장하는 후속 계약이다.
실제 선발·매수·매도·주문·비중·손절 정책은 변경하지 않는다. READY가 되어도
보고서나 매수 LLM을 새로 호출하지 않는다. 추가 LLM 호출·상주 서비스·cron은 없다.
코드 배포와 정규 배치 관측, 성과 검증은 각각 별도로 확인한다.

## 1. 가설과 대안

오닐식 추세 지속 후보를 발견한 시점과 적절한 가격 구간이 형성되는 시점은 다를 수 있다.
확정 일봉으로 기다린 결과가 초기 후보보다 유리한지 관측하되, 단순한 20일 고점 지표를
정교한 CAN SLIM 베이스 판정이나 기관 매집 확인으로 부르지 않는다. 약세장에서
적격 후보가 없다는 이유로 조건을 완화하지 않는다.

대안은 기존 유지, 관측만 추가, 선발 변경, LLM 재검토 추가다. 이번에는 **관측만 추가**한다.
최근 성공 사례를 일반화하거나 한국·미국 표본을 합쳐 독립 표본이 두 배가 됐다고 하지 않는다.
공통 글로벌 장세의 상관성과 서로 다른 휴장일·통화·비용을 별도로 취급한다.

## 2. 실제 파이프라인의 역할과 차이

- 발견: `trigger_batch.py`, `prism-us/us_trigger_batch.py`의 기존 트리거·순위·최종 후보를 유지한다.
  감시는 최종 선정 결과의 별도 관측이며, 과거 후보를 실제 선정 결과에 다시 넣지 않는다.
- 감시: `prism_core/oneil_watchlist.py`, `observability/oneil_watchlist.py`가 완료 일봉,
  상승 MA50·60일 상대강도·고정 20일 고점과 105% 이내 구간을 판정한다.
  보유 기간은 최대 5개 완료 시장 거래일이다. 같은 봉의 오전·오후 재실행은 새 신호가 아니다.
- 보고서·BUY: 양국 `cores/agents/trading_agents.py`와 tracking agent의 사업·이벤트·RR·추세·
  섹터·cooldown 등 기존 판단 권한을 유지한다. 기술 READY와 BUY 적격은 같은 개념이 아니다.
  감시는 목표·손절·RR을 만들어 넣거나 BUY 점수를 가산하지 않는다.
- 연결: `stock_analysis_orchestrator.py`에서 KR batch reference를 실행 스레드까지 명시적으로
  전달한다. `observability/micro_split.py`는 같은 시장·배치·watch 수명·판단 참조만 결합한다.
  KR 신규 진입은 최신 시세 경계 재검증 후 `FRESH_QUOTE_REVALIDATED`로 관측한다.
  기존 US는 원래 위치를 유지하여 `LEGACY_ELIGIBLE_PRE_REFRESH`로 명시한다.
  이 차이를 숨기거나 양국의 적격 수준이 완전히 같다고 비교하지 않는다.
- 비중: 현재 초분할은 **최초 0→10% 투영만**이다. 1슬롯의 10%이지 계좌 전체의 10%가 아니다.
  KR은 기존 파일럿 비중이 있으면 함께 기록하고, 모르면 UNKNOWN으로 남긴다.
  브로커 정수 수량은 독립 집행 참고치이며 0주를 강제 1주로 바꾸지 않는다.
- 실행·SELL: 기존 주문 예산·보유 원장·손절·추세 청산을 보존한다. SHADOW는 주문 승인이 아니며
  실제 체결·브로커 손익을 주장하지 않는다. BUY 미검토 READY는 NOT_EVALUATED다.

의도한 차이는 발견/기술 재관측/최종 매매 적격의 역할 분리다. 기존 BUY와 SELL의 모든
경제적 전제가 완전히 통일됐다는 주장은 하지 않는다. 완전한 10→30→60→100 캠페인과
기존/감시만/초분할만/결합의 네 비교군 포트폴리오 재생은 후속이며 이번 구현에 없다.

## 3. 시장별 데이터와 비용 제한

- US: 기존 `oneil_watchlist_v1`, NYSE 완료 거래일과 SPY, 조정 일봉을 유지한다.
- KR: 별도 `oneil_watchlist_kr_v1`, XKRX 완료 거래일, KIS 공식 종목 master의 시장 분류와
  KOSPI 1001/KOSDAQ 2001 지수를 사용한다. 시장을 종목 코드로 추측하지 않는다.
- 한국·미국 상태·정책·이벤트를 분리하고 기존 US 식별자와 기록을 보존한다.
- 감시는 기존 배치 때만 실행한다. KR은 일별 캐시와 최대 20개 종목 조회 예산으로 감시 후보와
  성과 추적 대기열을 나눈다. 미시도와 실패를 구별하고 대기열을 순환한다.
- KR 호출자는 최대 20초 기다리지만, 진행 중 KIS 요청을 강제 종료하지 않아 비데몬 스레드가
  요청 timeout까지 남을 수 있다. 인증 파일 손상을 피하는 선택이며, 실제 지연을 점검해야 한다.
  추가 시세 조회가 공짜이거나 운영 지연이 절대 0이라는 주장은 하지 않는다.
- 결측은 결측이다. 조정주가 기준 변경은 BASIS_CHANGED로 분리하고 과거 성과를 재작성하지 않는다.

## 4. 성과 데이터 계약 `watch_price_path_v1`

`observability/watchlist_outcomes.py`는 시장별 registry·원자적 상태 저장·재전송 outbox와
내용 해시 기반 불변 OHLCV/benchmark 원본을 보존한다. `prism_core/watchlist_outcomes.py`는
네트워크 없는 계산 코어다. 실패는 기존 거래를 막지 않고 관측 불가 이벤트로 남긴다.

- 수명당 BASELINE과 최초 FIRST_READY를 각각 등록한다. 미진입·무효·만료 후보도 분모에 남긴다.
- 신규 계약 적용 전 US 후보는 LATE_ENROLLMENT다. 과거에 알고 있었다고 소급 등록하지 않는다.
- 참조 가격은 **실제 관측 현지 날짜보다 뒤인 첫 완전 거래일의 시가**다. 이미 지나간 당일 시가나
  전일 종가에 매수한 것처럼 계산하지 않는다. 1·3·5·10·20거래일 종가까지의 가격경로를 추적한다.
- 기록: 수익률 대용치, benchmark 대비 수익률, 최대 상승폭(MFE), 최대 하락폭(MAE),
  가정 왕복비용 0/10/25/50bp 민감도. 세금·수수료·슬리피지 실측이나 확정 순손익이 아니다.
- 시장·통화·트리거·정책·데이터 계약·등록 시점·시장 국면·자료 출처를 분리한다.
- PENDING/MISSING/EXCLUDED/BASIS_CHANGED를 0% 수익으로 채우지 않는다. 등록 누락,
  용량 제외, 수집 실패와 만기 표본수를 Packet에 함께 표시한다.
- 20거래일 후 결측이어도 관측을 종료하고 tombstone을 남겨 같은 기준점이 재등록되지 않게 한다.
- BASELINE과 READY 비교는 같은 종료일을 공유하는 표본만 사용한다. 노출 기간 차이가 남으므로
  인과 효과나 실현 가능한 매수 우위를 증명하지는 않는다. READY가 없었던 상승 종목도 따로 본다.

공식 산출물은 `tools/build_watchlist_outcome_evidence_packet.py`와
`tools/build_watchlist_micro_evidence_packet.py --market KR|US`다. 입력은 보존된 sanitized JSONL이며,
Packet ID와 출처 event ID를 함께 남긴다. 임의 SQL·날짜/종목만의 느슨한 결합으로 대체하지 않는다.

## 5. 관측 기간과 사전등록 평가

1. 첫 **5거래일**: 양국 정규 배치 실행, 누락·중복·오류·수집 지연·거래 무영향만 점검한다.
2. 예비 분석: **각 시장 20개 서로 다른 실제 관측 거래일 + 20일 만기 수명 30개 이상**부터다.
   오전·오후는 2일이 아니며 후보가 적으면 달력 기간을 늘린다. 이 조건은 승격 허가가 아니다.
3. 효과 평가 목표는 **8~12주**다. 약세장·후보 부족·국면 편중이면 **3~6개월 이상**으로 연장한다.
   첫 4주는 데이터 점검용, 그 뒤 관측은 고정 정책의 시간순 holdout으로 별도 보고한다.
   중간에 정책을 바꾸면 버전을 분리하고 새 holdout을 시작한다.
4. 주평가: 각 시장 20일 공통 종료일 쌍의 benchmark 상대수익 차이. 보조 평가는 MAE/MFE,
   하위 꼬리, 비용 민감도, 기회 누락, 트리거/국면별 분포와 최고 수익 사례 제거다.
   동일 날짜 후보의 상관성을 고려해 날짜 단위로 불확실성을 평가한다. 수익 상위 몇 건만 고르지 않는다.
5. 결과가 약하거나 결측·소표본이면 CONTINUE_CAPTURE/보류다. 가격경로가 좋아도
   실제 진입·퇴출·자본 제약과 전체 초분할 재생을 검증하기 전에는 포트폴리오 개선으로 결론 내리지 않는다.

## 6. 중단·복귀와 위험

기존 거래는 항상 기준선으로 유지한다. 관측 때문에 주문/LLM/선발이 달라지거나, KIS 요청이
기존 배치에 영향을 주거나, 미래 정보·식별자 충돌·반복 등록이 발견되면 해당 시장 SHADOW를
중단하고 결측 구간을 보존한다. 소스 수정/설정 변경은 검증된 PR과 배포 절차를 따른다.
성과 부진만으로 즉시 조건을 바꾸지 않고 국면·데이터·집행과 규칙의 문제를 분리한다.
시장 국면이 돌아와도 자동 전략 전환하지 않는다. **LIVE는 별도 명시적 승인**이 필요하다.

결론: 승인된 SHADOW 연구이며, 반드시 기존보다 나아진다는 보장은 없다. 기존 로그는
무효가 되지 않는다. 구버전 기준선과 새 계약 전진 관측을 분리하여 계속 사용한다.
