# 공통 시장 근거 표시 개선: 분리 배포 범위

## 배포하는 변경

`prism_core/market_report_context.py`의 공통 보고서 표시만 바꾼다.
한국·미국 보고서에서 공통 시장 packet이 제공되는 경로에 적용된다.

- 수익률·SPY 대비 값이 전혀 없는 선택 ETF 행은 생략한다.
- 미측정 개수와 종목은 한 줄로 안내한다.
- 유효한 0, 부분 측정값, SPY 비교 기준, 자료시점, 확정 국면과 관측 모집단의
  미확인 정보는 숨기지 않는다.
- 원시 packet·계산·수집·캐시·스크리닝·매수/매도·손절 정책은 변경하지 않는다.

사용자가 제시한 자료의 Evidence ID `MI-213889d8d50e1586`를 DB 저장 packet과
대조했다. 16개 중 SPY·IWM·XLF·XLE의 네 행만 측정됐고 나머지 열두 행은 빈 값이었다.
선택 ETF가 구조적으로 지원되지 않는다는 증거는 아니다. 당시 개별 다운로드 실패인지
관측 기간 정합성 부족인지는 저장 packet만으로 확정하지 못했다.

## 분리하는 변경

보고서 전체 복구 변경 PR773은 이 배포에 포함하지 않는다. 해당 후보의 자동검사와
신규 생성 성공을 보고서 전체 내용의 정확성으로 확대하지 않는다. PDF 직접 대조에서
기업개요의 자본금 환산 표기와 공시 장의 값이 다른 사례가 남아 있어 인수 검증은
보류했다. 반복 횟수를 늘리거나 오류를 숨겨 통과시키지 않는다.

## 검증 기준

- 신규 회귀를 기존 코드에 적용하면 미측정 표시 관련 12개가 실패했다.
- 수정 후 한국·미국 공통 소비 경로, 측정값·한계 보존, 원시 packet 불변을 확인한다.
- 실제 Chromium HTML→PDF 생성과 텍스트 추출을 사용하며 외부 네트워크는 차단한다.
- CI의 정확한 PR head와 clean ff-only 배포 후 운영 Python smoke를 확인한다.
- 첫 정규 배치는 별도로 관측하며, 실행하지 않은 배치를 성공으로 보고하지 않는다.

이번 변경은 빈 표시 행의 정리다. 데이터 수집률 개선이나 새 매수 필터, 전체 보고서
생성 장애의 해결 완료를 의미하지 않는다.
