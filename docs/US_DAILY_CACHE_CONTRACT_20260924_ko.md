# 미국 일봉 결측 보완 계약

사용자 승인 범위는 정상 일봉 저장·정확한 전일 캐시·제한적 재조회다. 기존 지수 대상, 시총/트리거/BUY/SELL 정책은 보존한다. 전시장 확대와 repair 자동 사용은 별도이며 이번에 활성화하지 않는다.

현재 시세는 yfinance auto_adjust=True를 사용한다. 이를 raw 가격으로 바꾸면 기존 비교 기준이 달라지므로, 이번에는 동일한 명시적 조정 기준을 유지한다. 캐시 재사용에는 같은 공급자/버전/조정 설정/종목/거래일과 현재 응답의 과거 정상 anchor bar 일치를 요구한다. anchor를 확인할 수 없거나 달라졌으면 캐시를 사용하지 않는다. 이는 모든 사후 정정을 탐지한다는 보증이 아니므로 source/captured_at을 남기고 새로운 유효 원본을 우선한다.

NYSE 실제 세션 마감(조기폐장/DST 포함)이 지난 날짜의 유효 OHLCV만 보존한다. 장중 현재일·미래일·repair 재구성·잘못된 날짜/모호한 열은 캐시에 넣지 않는다. 마감 이후 관측이라는 뜻이지 공급자의 사후 정정이 없다는 보증은 아니다.

누락 종목은 정확한 날짜/같은 가격 설정으로 소수만 한 번 재조회한다. rate limit이나 시간 예산 도달 시 중단하고, 복구되지 않은 자료는 MISSING으로 남긴다. 다른 날짜/장외거래/분봉 재구성 값을 섞지 않는다. 최초 수집이 정상이어야 미래의 결측을 캐시로 보완할 수 있으며 이미 없는 9/22 전체 데이터가 소급 복구된다고 주장하지 않는다.

캐시는 ignored runtime/us_daily_ohlcv_cache 아래에 원자적으로 기록한다. 비밀값·계정·DB·cron은 수정하지 않는다. 테스트는 캐시 경로를 tmp_path로 격리하거나 기능을 명시적으로 끄고 네트워크/주문/발송 경계를 차단한다.

자동 장마감 수집 스케줄은 추가하지 않는다. 정규 조회 시 응답에 포함된 완료 세션 자료를 축적한다. 해당 날짜가 한 번도 정상 수집되지 않았다면 최초 결측은 캐시로 해결할 수 없다. 시장 개장 중 받은 현재일은 저장하지 않으므로 당일 자료의 마감 후 자동 보존까지 구현했다고 말하지 않는다.

구현 검증: 저장·재조회·동시성·실제 cache→US 오전/오후 JSON 및 기존 snapshot 계약 88개 통과. 기존 KR/US consumer 및 파이프라인 회귀 71개 통과. 최초 bulk가 삼키는 rate-limit은 실제 yfinance bulk 함수 시험으로 재현해 로그 관측으로 추가 재조회를 억제한다. 전역 로그 비활성 또는 알 수 없는 필터가 있으면 재조회를 보수적으로 생략한다. 정상 yfinance formatter는 허용한다. 치명적 Ruff 규칙 및 diff 검사 통과. 실제 데이터의 소급 복구·성과 개선을 입증한 것은 아니다.

변경 유형은 수집 신뢰성 보완이다. 유지 사례(정상 원본 그대로), 복구 사례(동일 날짜와 anchor), 거절 사례(분할/배당 등 anchor 변화·장중·repair·오염 파일)를 같은 입력으로 시험한다. 실제 KR consumer 및 US 오전/오후 batch→JSON, 운영 Python과 bounded quote smoke를 통과하기 전 배포 완료라 하지 않는다. 가격/시총 정책·손절/수량·실제 주문은 변경하지 않는다.
