# B3 전 진입 SHADOW (KR/US) — `oneil-adaptive-v3-ae`

## 결정 (2026-10-02, 사용자 선택)

- 한국 초분할은 미국 B3와 같은 규칙으로 간다(2026-10-01 확정). SHADOW는 **모든 실제 진입**에 적용한다.
- 미국 B3 SHADOW(v2)는 2026-09-28 이후 캠페인 0건이었다. 유일한 진입(NVDA 9/30)이 리포트 자동검토의
  "적정 베이스·선도주" 미확인으로 거부됐다. 재현 v1(KR)도 이 게이트 없이 모든 진입에 비중 규칙만 적용했다.
- 따라서 SHADOW 사이징에서 셋업 자동검토 게이트를 빼고, 한·미가 같은 대상을 관측한다. 주문·보유 DB·메시지·
  수익률 숫자 영향 0. v2 SHADOW와 LIVE 경로는 그대로 둔다(병행 관측).

## 규칙 (v2 B3와 동일, 차이만 명시)

| 항목 | v3-ae |
|---|---|
| 대상 | 정규 배치의 최초 진입(`entry_eligible`, 피라미딩 추가·반슬롯 시험매수 제외), KR/US |
| 최초 비중 | `initial_sizing(진입가, ATR14)` = clip(0.5×0.07/stop_proxy, 0.30, 0.80), **실제 진입 시점·가격에 즉시 가상 체결** |
| ATR14 | 계획일(시장 현지 날짜) 이전 확정 14세션의 평균 true range, 비수정 일봉 |
| 증액 | v2와 같음: 직전 완료 5분봉 2개가 진입가 이상, 현재가·종가 ≥ 진입가×1.02 → 0.8(최초<0.8일 때), ≥1.04 → 1.0, 진입가×1.10 이하, 완료 일봉 종가 > SMA20, Market Pulse UPTREND, 국면 moderate_bull/strong_bull/parabolic, 기존 매수 게이트(admission/risk/RR/sector/slot), 수익 중, 봉당 1단계, 위험 한도 clip |
| 증액 기한 | 계획 후 14 달력일(v2와 같음) |
| 청산 | 기존 전략 원장의 실제 청산(같은 가격·시각)으로 전량. 별도 손절을 만들지 않는다(기존 하드스탑이 집행) |
| 비교군 | 같은 진입·청산에 100% |
| 피벗 | 셋업 피벗 대신 실제 진입가(=증액 하한) |

시장 파라미터: US = America/New_York 09:30–16:00(NYSE), KR = Asia/Seoul 09:00–15:30(XKRX). 둘 다 390분.

## 데이터

| 입력 | US | KR |
|---|---|---|
| 현재가 | 기존 yfinance 시세 | KIS 국내 현재가(조회 시각을 관측 시각으로 명시) |
| 5분봉 | 기존 yfinance 5분봉 | KIS 당일 분봉 → 5분 집계(체결 없는 5분 구간이 있으면 그 틱은 판단 보류, 채우지 않음) |
| 일봉 추세 | 기존 | KIS 비수정 일봉 확정 20세션 종가 |
| 국면·Pulse | 기존 S&P/나스닥 | `cores/data_prefetch` KR 국면 + `regime_policy` KR Pulse(캐시 미사용, 관측 시각 부착) |
| 게이트 | `current_gates`(공용 buy_gate) | 같음 |

## 기록과 평가

- 캠페인·이벤트: `runtime/b3-ae-shadow.sqlite`(시장별 행). 증액 판단마다 증거 해시와 사유 코드를 남긴다.
- 거래별 슬롯 수익률: B3 = Σ 비중ᵢ × (청산가/체결가ᵢ − 1), 비교군 = 청산가/진입가 − 1. 증액 비용 0.25% 보조 보고.
- 관측 2~4주: 운영 기준(오류 0, 재시작 후 중복 증액 0, 증거 결측 사유 분포)과 재현 v1 방향 일치 여부를 본다.
  표본이 작으므로(시장별 주 1~3건) 수익성 증명이 아니라 실행 검증이다. 제한 LIVE는 별도 승인.

## 구현 단계

1. 정책 코어: `oneil_adaptive_policy`에 v3-ae(시장 파라미터) 추가, 순수 가상 원장. 기존 v1/v2 해시·동작 불변.
2. 입력: KR 현재가·분봉·일봉 추세·국면/Pulse 공급자, US는 기존 공급자 재사용.
3. 연결: KR/US 배치 진입 캡처 훅, 청산 훅, 워커(시장별 장중 60초), 설정 OFF 기본, systemd.
4. 평가 도구와 결과 기록.

## 롤백

설정 `mode=OFF` 또는 워커 중지. 캡처 훅은 fail-open이며 원래 매수·매도에 영향이 없다.
