# US 근거 전달·TradingView 제거 배포 범위

사용자가 2026-09-23 전후 예시 확인과 배포를 승인했다. 최신 origin/main 264fd487에서 별도 clean worktree로 시작한다.
기존 feat/general-competitive-research의 미완료 작업을 통째로 병합하지 않는다.

## 포함
- 기존 US Yahoo 추정치의 부분확보/누락/오류·0/단위 처리와 회사 분석 전달.
- 코드가 부착하는 수집상태를 보고서→전략/요약→PDF→BUY로 보존.
- BUY/SELL의 예상/실제, 과거/현재, 장중관측/확정봉 해석 수정. 기존 수치 임계값·주문/보호 루프는 불변.
- main에 남아 있는 사용하지 않는 TradingView evidence 모듈·전용 테스트·설정/receipt 상태 제거.

## 제외
- KR 검수 PDF의 회사별 문장 수정은 산출물 교정이며 생성 코드의 정답 치환으로 넣지 않는다.
- KR 실험용 10역할 분석/구조화 셀 참조/대용량 source-tree와 PR #752의 SEC parser 등 미병합 변경은 포함하지 않는다.
- 새 유료 공급자, 위험 한도 변경, DB/cache/cron/계정 설정 변경, 실거래 배치 수동 재실행은 하지 않는다.

## 게이트
포트 전후 source scope 확인 → 실제 모듈 오프라인/시세 shape/PDF→BUY/격리 tracking 테스트 → 독립 리뷰 → 정확한 PR head CI → 정상 PR merge → clean 서버 ff-only 배포 → 운영 Python 안전 스모크 순서다.
인증정보·주문·발송은 테스트에서 차단한다. 기존 동작과 스케줄을 보존하며 첫 정규 실행 관측은 배포와 별도로 보고한다.
다른 분석/거래 프로세스가 진행 중인 때에는 배포를 미룬다. 실패하면 완료로 보고하지 않는다.
