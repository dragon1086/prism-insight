# BTC 강제청산 위험 검사 보강

## 승인 해석과 범위

사용자는 교차마진 강제청산 위험 검사를 보강하고 앞으로 확인할 사항을 기록하도록 요청했다.
이를 **신규 진입·추가 진입의 위험 검사 보강**으로 적용한다. 격리마진 전환, 계좌 간 송금,
데모 자산 삭제, 기존 포지션 강제 청산, 손절·레버리지·위험 예산 변경은 수행하지 않는다.
로드맵 대상은 M0 보호·체결 안전 및 M1 공통 자본 위험 검사 후속이다.

이번 실행 범위는 현재 사용하는 **공유 진입 정책이 활성화된 demo 메인·스윙**이다.
기존 공유 정책이 꺼진 경로와 실자금 LIVE 경로까지 검증 완료했다고 주장하지 않는다.
리스크 정책을 끄는 것이 새 검사까지 우회할 수 있다는 사실은 후속 점검과 배포 검토에 포함한다.

## 기존 전략과의 적합성 검토

- 신호: 메인 고유 신호, 스윙 4시간 이동평균 교차·일봉 조건은 그대로 둔다.
- 수량: 손절 거리 기반 사이징과 기존 메인·스윙 위험 예산을 유지한다.
- 최종 권한: 실제 주문 직전 shared entry coordinator에서 양 계좌의 포지션·미체결 잔량,
  최종 진입 제한가격을 확인한 다음, 신규 예약 생성 전에 위험 검사를 수행한다.
- 보호·청산: 복구, 기존 손절 재확인, 감축·청산을 새 진입 검사로 차단하지 않는다.
- 의도한 차이: 신호가 유효해도 담보/위험 자료가 없거나 자본 여유가 부족하면 진입하지 않는다.
  이는 신호 점수를 다시 깎거나 여러 단계에서 수량을 중복 축소하는 변경이 아니다.
- 영구 수익 규칙을 추정하지 않는다. 최근 단일 거래 손실에서 전략 수익성을 일반화하지 않으며,
  새 검사로 수익이 좋아졌다고 주장하지 않는다.

## 검사 계약

1. 실제 계좌의 마진 방식·증거금률·잔고 자료를 확인한다. 지원하지 않는 방식이나 결측을
   안전으로 간주하지 않는다. 실제 강제청산은 교차계좌 전체 상태에 의해 발생한다.
2. 공식 위험 단계별 유지증거금 요구와 비용을 참고하여, **메인 운용 기준자금 한 번만**을
   기준으로 포지션·미체결 잔량·새 주문의 손절 초과 스트레스를 평가한다.
   큰 스윙 데모 지갑의 추가 가상자산을 운용 위험 예산에 더하지 않는다.
3. 기존 1.2배 손절 거리 여유 기준을 재사용한다. 이것은 모형의 스트레스 범위이지
   슬리피지 상한이나 '강제청산 불가능' 보증이 아니다. 평가 시점·통화를 구분한다.
4. 거래소 liqPrice가 있으면 기존 포지션의 위험 거부 근거로 사용할 수 있지만,
   주문 전 값을 추가 진입 후 청산가로 부르지 않는다. 빈 교차 청산가는 0원이나 안전의 증거가 아니다.
5. 신규 API는 대상 후보의 제한된 GET 조회이며 기존 snapshot 신선도 기한 안에 포함한다.
   실패/시간 초과는 신규 진입만 거부하고, 원시 API 오류·인증 정보를 알림에 노출하지 않는다.

## 사전 검증 기준

- 정상 flat 메인/스윙 및 유효한 추가 진입은 기존 진입 경로를 통과해야 한다.
- 결측·NaN·미지원 마진 방식·불명확한 환율/위험 단계·과도한 증거금 위험은 예약·주문 전에 거부한다.
- 스윙 지갑 평가액만 크게 늘려도 운용 기준 스트레스 결과가 개선되면 안 된다.
- 부분 체결은 잔여 예약만 추가 계산하고, 반대 방향이나 이익 중인 손절을 위험 차감 크레딧으로 쓰지 않는다.
- 기존 복구·보호·감축·청산 회귀를 함께 실행한다. 실주문으로 시험하지 않는다.
- CI와 운영 Python 격리 검사 후 배포한다. 읽기 전용 실응답 smoke와 첫 정규 tick/실제 신규 후보를 구분한다.

## 앞으로 확인할 사항 (미완료)

- [ ] 약 9,600달러만 담보로 존재하는 별도 데모 환경에서 큰 지갑과 비교한다. 자산 이동/초기화는 별도 승인 후 수행한다.
- [ ] 동일 시장 급락 시 BTC·ETH 담보 가격 하락, 담보 인정률, 부채·타 상품 노출까지 포함한 계좌 스트레스를 검증한다.
- [ ] LastPrice 손절과 MarkPrice 강제청산의 차이, 갭·호가 공백·API 장애를 재현한다.
- [ ] 체결 후 실제 수량·증거금률과 사전 검사값을 비교하고, 추가 진입 뒤 청산가 변화를 확인한다.
- [ ] 스윙의 누적 실현손익·펀딩을 공통 운용 자본에 반영하는 M1.4 정합성을 검증한다.
  현재 메인 평가액은 별도 스윙의 미실현손익을 포함하지 않으므로, 스트레스에서는 스윙의
  이미 발생한 미실현 손실도 차감하되 이익을 다른 위험의 상쇄 수단으로 쓰지 않는다.
- [ ] 격리마진과 교차마진의 전략 적합성을 별도로 비교한다. 자동 전환하지 않는다.
- [ ] 공유 정책 비활성/legacy 및 실자금 LIVE 진입 경로의 동일 검사 적용을 검토한다.
- [ ] 거부 코드별 발생률과 정상 후보 오차단을 기준선과 비교한다. 정상 응답 구조 누락에 의한
  대량 오차단이면 데이터 계약을 수정하며 위험 검사를 무조건 우회하지 않는다.
- [ ] 새 검사 중단/교체 시 기존 보호·복구를 유지하고, 검사 버전과 거부 기록을 보존한다.
