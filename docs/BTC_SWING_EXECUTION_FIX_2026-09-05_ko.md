# BTC 스윙 실행 교정

## 범위

스윙 데모의 큰 별도 지갑이 위험 예산을 부풀리는 오류와 30분봉 대기로 인한
실행 지연을 수정한다. 신호 조건·2ATR 손절·MA35 청산은 유지한다.
신규 트레일과 진입 필터는 도입하지 않는다.

## 변경

- 실제 메인 데모 계좌를 읽어 스윙 수량의 논리 자본으로 사용한다.
- 자본·포지션·미체결 조회 실패나 미완전 페이지는 신규 스윙 진입을 보류한다.
- 스윙 진입 시 기존 메인 명목노출·미체결 진입을 합산해 8배 상한을 검사한다.
- 10분 cron에서 확정 4시간 신호를 평가한다. 15분 넘은 진입 신호는 재생하지 않는다.
- 실제 체결시각이 있으면 bar 시각 대신 저장한다.
- 미확인 청산은 로컬 포지션과 보호 스탑을 유지한다.
- 브로커 지갑 평가액은 보존하며 신규 거래부터 별도 실현 NAV 메타를 기록한다.

## 검증 및 한계

기존 BTC 전체 테스트 413개 통과 후 미확인 청산 회귀 테스트를 추가했다.
추가 후 전체 테스트를 다시 실행한다. 기본 가상체결 경로는 종전 봉 처리 의미를 유지한다.

이는 통합 리스크 엔진의 완성본이 아니다. 메인 진입 방향의 역방향 합산 검사,
두 계정 stop heat 및 동시실행 잠금은 남아 있다. NAV는 미실현손익을 포함하지 않는
prospective 실현 NAV이며 미확정 정산의 재처리도 남아 있다.
정밀 백테스트·10분 실행 실측·전략 성과 개선을 보장하지 않는다.

## 운영

db-server 기존 demo cron을 사용하며 추가 cron은 없다. app-server는 변경하지 않는다.
배포 시 포지션이 없는지 확인한다. 롤백은 이 교정 커밋을 revert하고 기존 cron은 유지한다.
