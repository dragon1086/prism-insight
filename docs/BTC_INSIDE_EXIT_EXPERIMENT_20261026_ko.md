## 실험과 검증

사전 고정된 첫12개 비중복 구간의 직전 확정1시간 종가는 모두 MA10/35 사이였다. 제공된 최근 확정3봉에서 실제 가격 이동을 동반한 MA10 횡단이 확인된 구간은4개였다. 나머지를 ‘횡단 없음’으로 확정하지 않으며 더 오래된 경로는 이 검사 범위 밖이다. 이 표본은 개발용이며 독립 holdout이 아니다.

실제 DRAFT→host 계산→SELECT를 같은12개 입력으로 양쪽 실행했다. 합성 무포지션 계좌10000·복구 위험0.5%이며 실제 과거 계좌를 복원한 것이 아니다. 총30 HTTP/한도48, 재시도0, 실제 주문0. 장부는 봉인했으며 남은18회를 다시 사용하지 않는다. 모든 첫 단계 입력·스키마·모델 설정이 같고 system prompt는 등록한6줄만 다른지 확인했다. 후속 선택 입력은 각 모델의 후보에 따라 달라진다.

등록서의 호출 순서 교대와 달리 재사용 실행기가 매 쌍 기준→후보로 실행했다. 결과 검토 전 편차를 기록했고 원 등록서를 수정하거나 실행을 재시작하지 않았다. 순서 효과를 통제한 비교로 보고하지 않는다.
