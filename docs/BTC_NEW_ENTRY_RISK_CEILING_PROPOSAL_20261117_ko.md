# BTC 신규 진입 물량 상한 제안 및 배포 기록

> 후속 상태: 2026-11-17 사용자가 적용·배포를 승인했다. #1390 정확한 head `27f3bb21`의
> 검사 9개가 모두 성공한 뒤 `a71d043a`를 17:57 KST에 데모 서버에 ff-only 배포했다.
> 운영 Python 3.11.11 수량 계산·상한 초과 거절·소스 일치와 설정/cron 불변을 확인했다.
> 18:00 첫 정기 판단 WAIT와 보호 정상, 실제 모델 입력의 최소 15분봉을 확인했다.
> 자연 발생 신규 체결의 실제 물량·손익과 승률·수익성 개선은 아직 미입증이다. 아래는 승인 전 제안 기록이다.

M0/M4 경제적 의사결정 변경 후보다. 기준선은 `01fb4b3ab4ffeab88e0b8f10cebbd700764f8531`이다.
새 위험 기본값이므로 사용자 선택 전에는 병합하거나 배포하지 않는다. 실자금 대상이 아니다.

1. **문제와 가설:** 최근 40개 정산 중 체결이 확인된 30건을 검산했다. 이전 26건의 모델 배분은 0.7 이하,
   최근 4건은 0.8~1.0이었다. 시나리오 위험 비율은 0.5%로 같지만 계획 위험과 체결 물량이 커졌다.
   이전 집단은 7승 19패(승률 26.9%), 평균 이익 4.84 USDT, 평균 손실 4.47 USDT, 손익비 1.08이었다.
   최근 집단은 0승 4패, 평균 손실 11.62 USDT이며 평균 이익과 손익비는 계산할 수 없다.
   이 구분은 사후 기술 통계다. 최근 손실만으로 승률 개선 규칙을 입증한 것은 아니다.
2. **기존 전략과의 관계:** 신규 `OPEN`/`ADJUST` 진입 배치의 합산 계획 위험을 원래 시나리오 예산의 30%로 제한한다.
   현재 약 46.5 USDT 예산에서는 배치 상한이 약 14 USDT다. 과거 물량 수준으로 낮추려는 후보이지 최적화한 값은 아니다.
   원본 confidence·배분·방향·진입가·손절·목표는 유지하고 기존 allocator에서 수량만 줄인다.
   기존 포지션, 예약 주문, 미확정 취소, 비용과 추격 가격의 위험 예약은 유지한다.
3. **경로와 검증:** 모델 원문 → `allocate_entry_risk`의 전체 배치 상한 → 기존 가격 정책 →
   `validate_allocation_prices`의 상한 재검사 → 기존 시나리오·실행 관문이다.
   원래의 계좌 위험 단계 및 시나리오 전체 예산은 유지한다. 작은 요청 배분을 다시 일괄 30%로 곱하지 않는다.
   `ceiling = min(confidence 예산, 남은 예산, 배치 상한 / 배분 합)`을 각 배분에 나눠 쓴다.
   최소 주문 수량에 못 미치면 올려서 주문하지 않고 거절한다. 저장된 과거 intent는 재산정하지 않는다.
4. **비교와 한계:** 같은 실제 입력 3건을 기존 계산기로 재현한 비교에서 수량은 0.038→0.021,
   0.036→0.021, 0.038→0.023 BTC이며 계획 위험은 각각 25.15→13.90, 23.14→13.50,
   22.97→13.90 USDT였다. 실제 손익을 비례 추정하지 않았다. 개발 표본이며 holdout이 아니다.
   여러 진입, LONG/SHORT, OPEN/ADJUST, 기존 예약, 추격, 최소 수량, 위조된 배분 예산을 회귀 검사한다.
5. **유지·중단 조건:** 현재 결론은 검토 보류다. 배치 위험 초과, 최소 수량 상향 또는 기존 위험 예약 누락은 결함이다.
   이 후보로 승률이나 수익성이 좋아졌다고 판정하지 않는다. 운영 선택을 받으면 배포·첫 정기 실행을 따로 확인하고,
   이후 자연 발생한 체결에서 기존 조건과 수량·비용·낙폭을 비교한다. M5 수익성 판정은 별도 게이트를 따른다.
6. **남은 결정:** 신규 진입 일시 중단 여부와 30% 배치 상한 적용 여부를 사용자에게 질문한 상태다.
   계좌 위험 단계가 바뀌면 절대 금액도 달라진다. 여러 배치와 가격 급변·수수료·펀딩까지 포함한 실제 손실의
   14 USDT 상한이나 무손실을 보장하지 않는다. 승률 개선은 최소 15분봉의 고정 기준 차트와 진입·청산 품질 검증으로 분리한다.
