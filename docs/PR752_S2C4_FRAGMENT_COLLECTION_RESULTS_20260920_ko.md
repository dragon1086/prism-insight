# S2c-4: 선택된 대형 주석의 제한된 하위 문서 수집 결과

## 판정

수집 경로와 실패 상태 보존은 검증했습니다. **최종 금융 근거 품질은 불합격이며 전체 완료가 아닙니다.** 기존 Draft PR #752를 유지하며 머지·배포하지 않습니다.

## 구현과 독립 피드백

- 선택된 기본·연간 전체 주석을 먼저 시도하고, 개별 2 MiB 초과에만 검증된 공식 목차의 자식을 최대 2개 계획합니다. 전체 호출·바이트·시간 예산, 부모 PARTIAL과 누락 상태를 유지합니다. 전송·누적 예산 실패를 같은 예외로 뭉개지 않습니다.
- 회사명·eleId 특례 없이 기존 주제 분류와 목차 순서를 사용합니다. 최종 선정에서 탈락한 원문의 raw context는 버립니다. fragment provenance는 공식 부모 검증을 거쳐야 합니다.
- 독립 리뷰의 낮은 심각도 지적 2개를 수정했습니다. 미선택 수는 전체 자식 수에서 계획 수를 빼고, 중단 사유를 collector→adapter→요약까지 보존합니다. 최종 리뷰 APPROVE입니다.
- CI 연구 입력 회귀 1,875개가 통과했습니다(기존 경고 4개). 이 수치는 Python 타입 검사나 최종 금융 품질 통과를 의미하지 않습니다.

## 실제 1건 검증

삼성생명은 개선용 회귀 사례이며 새 검증군 성공으로 세지 않습니다. identity 2회와 collector 28회, 합계 HTTP 30회/5,247,757바이트를 관측했습니다. 기본 보고서는 `20260814003263`, 연간 보고서는 `20260331004244`입니다.

연간 부모는 2 MiB 초과로 PARTIAL을 유지했습니다. 공식 자식 54개 중 52·60을 계획했고, 52만 취득한 후 호출 예산 소진으로 60을 미실행 처리했습니다. 미선택 52개, `full_notes=false`, `stop_reason=CALL_BUDGET_EXHAUSTED`입니다.

- 자식 52: 24,873바이트, SHA-256 `25ced427fd9e6c4d54c76513378dcfe77b1babd373bd5807e83a7fe5ecb691c5`.
- 검증된 부모 문맥으로 후보 8개를 생성했습니다. 최종 담당자 입력에 들어간 연간 fragment는 **0개**입니다.
- 최종 news/overview/status는 각각 2/4/3개, 5,726/5,894/5,936바이트입니다. 모두 기본 보고서 근거입니다.
- 기존 fixture recorder는 자체 2 MiB 한도를 먼저 적용합니다. 따라서 이번에는 실제 collector 반환 뒤에 진단용 component만 저장했습니다. **완전한 네트워크 replay fixture가 아닙니다.** 원문과 manifest는 Git 밖 비공개 디렉터리에 보존했으며 첨부하지 않습니다.

기존 LG·카카오·HMM·POSCO fixture를 추가 네트워크 없이 엄격히 replay했습니다. 정상 경로에는 fragment fallback이 없었습니다. 카카오/HMM 요약은 최초 capture와 같고, LG/POSCO 차이는 앞서 기록한 scope·표 기하 복구 때문입니다.

## S3 원문 독립 기준과 실패

최종 packet 내용을 보기 전에 원문만으로 `PR752_S3_SAMSUNG_LIFE_GOLD_20260920_ko.md`를 고정했습니다. 이후 compact provenance를 펼쳐 대조한 결과, 기본 보고서의 필수 충당부채 표 781과 자회사 소송 표 1018이 모든 담당자 입력에서 빠졌습니다. 전자는 excerpt만 7,957바이트이고 후자는 1,229바이트입니다. 둘 다 caption/unit 문맥이 연결되지 않았습니다.

연간에는 소송 진행 중, 최신 기본 보고서에는 최종 승소·의무 소멸이 적혀 있습니다. 연간을 무조건 우선하거나 잘린 숫자만 전달하면 현재 위험을 뒤집을 수 있습니다. 다음 단계는 회사별 예외가 아니라 일반적인 제목·기간·단위·각주 연결과 조건을 보존하는 예산 내 선택입니다. 기본·연간 수집 성공과 테스트 개수로 이 실패를 덮지 않습니다.
