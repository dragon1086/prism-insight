# 미국 보고서 공개자료 보완 범위

## 구현

1. 기존 공시 메타데이터를 한 번 수집해 재사용한다. SEC의 최신 실적 8-K(Item 2.02) 첨부 및 최신 10-Q/K에서 가이던스·재무·사업부 원문을 기간·단위·표 헤더와 함께 전달한다. 회사별 수치 하드코딩, 새 모델 호출, 비공식 요약의 사실 승격은 하지 않는다.
2. 보고서용 시세만 원시 OHLCV를 명시적으로 사용한다. 기존 거래·스크리닝 기본값은 바꾸지 않는다. 시세 필드와 해당 필드의 시각·거래소 시간대를 보존하며, 없는 일봉 종가를 조회 가격으로 채우지 않는다. 지표·교차일은 같은 이력과 기준일을 쓴다.
3. CPI·PCE·동일일자 장단기 금리의 공식 자료를 공통 함수와 제한된 캐시로 수집한다. 봇과 정규 파이프라인의 같은 보고서 함수가 사용한다. 이 자료는 설명용이며 기존 확정 매매 국면·점수·게이트를 대체하지 않는다.
4. 공개자료 미수집·원문 미해독·이력 부족·미발표·비교 정의 불일치를 구분한다. 원문 전체를 PDF에 복사하지 않고 모델 입력과 간결한 공개 출처 안내를 분리한다.

## 이번에 하지 않는 것

- 유료 데이터 계약, TradingView 재도입, 전체 업종 평균·실시간 기관 순매수 추정.
- 새 모델·전문 분석 에이전트·추가 매매 신호, 보호 루프나 위험 한도 변경.
- 공개되지 않은 세부 손익 생성, 종가/기관 수급의 근거 없는 보정.

## 검증·배포

소스 형식·단위·기간·미래 자료·SSRF 경계·실패 캐시·실제 보고서 소비자 연결 회귀를 먼저 실행한다. 독립 검토와 정확한 PR head CI 통과 후 clean DB/app 서버를 ff-only 배포한다. 기존 서비스·OAuth 연결·cron·비밀 설정은 유지한다. 읽기 전용 공급자 확인과 주문 없는 PDF 전달 경계를 검증하며 정규 배치 결과는 별도로 보고한다. 실제 보고서 재생성은 필요할 경우 최종 1건만 수행한다.

## 배포 전 근거

- 보고서·자료·소비자 관련 회귀 묶음 390개 통과. 독립 검토 138개 통과, HIGH/MEDIUM 지적 수정 후 재검토 승인.
- app-server에서 후보 코드를 메모리로만 실행한 읽기 전용 조회로 공식 DGX 7월 23일 가이던스, BLS 8월 CPI, BEA 7월 PCE와 다음 발표일, FRED/H.15 동일 날짜 2년·10년 금리를 확보했다. 모델·주문 호출 없음.
- SEC 직접 접근 및 일부 공시 CDN에는 차단·시간 제한이 있어 issuer release만 수집된 경우는 partial로 남긴다. DIS 매출 행은 실적 발표의 financials 표에 있으므로 overview에도 financials를 제공한다. 입력 분류를 자료 부재로 해석하지 않는다.
- BLS 요약 페이지 차단 시 공식 API의 비계절조정 CPI-U로 전년 대비를 계산한다. 계절조정 전월 대비로 바꾸지 않는다. Treasury 직접 조회 실패 시 공식 FRED/H.15의 같은 날짜·같은 정의 자료로 보완하며 원래 Treasury par 자료를 받았다고 주장하지 않는다.
- 거시 내용의 실제 변경만 시장본문 캐시를 갱신한다. 조회시각만 바뀌면 기존 시장본문을 재사용한다. 모델 단계 수는 늘리지 않는다.
- 없는 최신 Close의 독립 공급자 복구, 과거 시점별 컨센서스, 자동 peer 묶음·전체 업종 평균은 이번 제한 범위에 포함하지 않는다. 원시 O/H/L과 종가 결측 상태는 분리해 보존한다.
