# 한·미 수급 입력 보강 v1: 사전 계약

## 범위와 승인 경계

사용자 요청: 미국 퀀트의 수급 접근을 조사하고 기존 PRISM에 맞춰 미국→한국 순서로 개선·비교 검증한 뒤 적절한 변경만 배포한다. 이번 범위는 데이터 해석 계약과 계산 가능한 입력의 보강이다. 손절폭·비중·레짐·점수 임계값·주문 로직·새 매수 게이트·자동 SHADOW/LIVE 승격은 변경하지 않는다. 수익률 개선이나 최적 지표 선택은 이번 검증으로 주장하지 않는다.

## 조사 결과와 선택 이유

1. 호가·체결 데이터 접근: Nasdaq TotalView/NOII 같은 주문장·경매 불균형은 직접적인 시장 미시구조 자료다. 그러나 거래소 범위와 데이터 구독·수집 체계가 필요하며 주문이 기관 투자자의 정체를 자동으로 알려주지는 않는다. 현재 일봉 중심 PRISM에 새로운 유료 틱 수집 체계를 붙이지 않는다.
   - https://www.nasdaq.com/products/data/equities/nasdaq-totalview
2. 일봉 가격·거래량 접근: OBV는 상승/하락 종가에 따라 거래량을 더하거나 빼며, 가격과 거래량의 동행·괴리를 보는 보조 지표다. 원시 절대 OBV 대신 기간 거래량으로 정규화한 증분을 사용하면 단위와 초기값 문제를 줄일 수 있다. 기관의 실제 순매수는 아니다.
   - https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/OBV
3. CMF는 종가의 일중 위치와 거래량을 함께 보는 가격·거래량 기반 지표다. 개발자 측 설명도 기관 주문을 직접 관측하는 방식이 아니라고 명시한다. 갭 하락일에 일중 상단 마감하면 양수가 될 수 있으므로 단독 매집 확정으로 쓰지 않는다.
   - https://help.chaikinanalytics.com/en_US/knowledge-center/chaikin-money-flow
4. 기관 보유 스냅샷은 느린 보유 구조 자료다. 13F는 분기말 기준·분기 종료45일 이내 제출이므로 일별 기관 순매수와 분리한다.
   - https://www.investor.gov/introduction-investing/investing-basics/glossary/form-13f-reports-filed-institutional-investment
5. Cont·Kukanov·Stoikov의 연구는 NYSE TAQ의50개 미국 종목에서 최우선 호가의 주문 흐름 불균형과 짧은 시간의 가격 변화를 다룬다. 본문은 체결 매수/매도 불균형과 주문 흐름 불균형을 구분하며, 단순 거래량의 설명력이 주문장 정보를 대체하지 못함을 보인다. 이를 일봉 OBV/CMF의 수익 우위 근거로 옮겨 쓰지 않는다.
   - https://arxiv.org/abs/1011.6402 (Firecrawl 연구 인덱스의 본문 대조)

이는 모든 퀀트가 동일 지표를 쓴다는 조사가 아니며 수익 우위의 실증 연구도 아니다. 현재 제공 가능한 자료와 전략 주기에 맞는 최소 구성 선택이다.

## US 고정 구성

- 기존 일봉을 재사용해 확정봉만 계산한다. 추가 네트워크·LLM 호출을 만들지 않는다.
- OBV형 signed-volume ratio의5/20세션 창: sum(sign(C_t-C_t-1)*V_t)/sum(V_t). 이전 종가가 추가로 필요하며 동가 거래량은 분자0이다.
- CMF20: sum(((2*C-H-L)/(H-L))*V)/sum(V). H=L이면 해당 봉의 위치 기여를0으로 정의하고 그 사실을 기록한다. 전체 거래량0·음수/비정상 값·불완전 창은 MISSING이다.
- 기존 거래량 급증 정보와 함께 맥락으로만 제공한다. 이 상관된 지표들을 독립 신호 여러 개로 중복 가점하지 않으며 새 점수·차단 기준을 도입하지 않는다.
- 보유 기준일과 조회 시각을 구분하고, 일별 기관 수급은 현재 공급되지 않는다고 명시한다. 보유잔고나 proxy를 기관3/5일 연속 순매수로 읽지 않도록 보고서·매수 프롬프트 양쪽을 보강한다.

## KR 고정 구성 (US 검증 후 구현)

- 이미 조회하는 KIS 일별 순매수 수량과 가격/시장 세션 기준을 재사용한다. 외국인·기관 각각과 합계의5/20/30거래일 수량을 코드로 계산한다.
- 창의 시작·종료일, 관측/필요 세션 수, 원천·수량 단위·기준시각·결측을 표시한다. 주식 수에 현재가를 곱한 값을 실제 순매수 금액으로 부르지 않는다.
- 당일 추정/미확정 세션을 확정 누적에 섞지 않는다. 기준 세션이 없거나 중간 날짜가 빠지면 충분한 과거 행으로 빈 날을 숨기지 않는다.
- 한국 원천에 확정성 증명이 없는 현재 KST 날짜는 시간이15:40을 지났어도 누적에서 제외한다. 직전 완료 날짜까지의 관측 기준임을 표시하며 시각만으로 당일 수급 확정을 가정하지 않는다.
- 최근5일과20/30일 방향 차이를 함께 보여주되 자동 전역 게이트로 바꾸지 않는다.

## 비교·검증 기준 (결과 열람 전에 고정)

1. 산술: 독립 손계산/벡터 계산과 일치, 거래량 배율 불변, signed ratio/CMF 범위 및0 거래량·동가·H=L 처리.
2. 시간: 미래봉·진행봉 제외, 일광절약시간·휴일·지연/누락 입력·미래 보유일 처리. 캘린더와 관측 세션의 근거를 구분한다.
3. 반례: 갭 하락+일중 상단 마감(CMF 양수/방향 거래량 음수), 강한 정상 상승, 거래량 부재, 오래된 기관 보유,5일 기관 순매수/20일 순매도 공존.
4. 배선: 동일 원천에서 만든 숫자가 보고서 및 실제 매수 입력까지 도달하는지 확인하고 중복 네트워크·추가 LLM 호출이 없는지 테스트한다.
5. 보존: 기존 임계값·손절·비중·브로커 주문·공개 발송 경로는 변경하지 않는다. 결정론적 게이트 출력이 관련 없는 사례에서 유지되는지 확인한다.
6. 배포 판단: 정확한 숫자·시점·단위·해석 경계와 배선이 검증되면 입력 보강으로만 배포할 수 있다. 후보 수·수익률·승률 개선 및 새 전략 승격은 별도 prospective 비교가 필요하다. 최근 정본 US46후보/8일/4청산, KR12후보/3일/0청산으로 장기 우위 주장은 불가하다.
7. 실제 데이터 검사는 수동 읽기 전용으로 소수 종목에 한정한다. 과거 모델 응답을 새 검색 결과로 보정하지 않는다. 기존 안전 하네스·정확한 PR head CI·clean ff-only 배포·롤백 참조를 지킨다.
8. 실제 입력 점검 종목은 US HPE/NVDA/SPY, KR000660/005930으로 고정한다. 이들은 수집·배선 점검용이며 성과 표본이나 독립 holdout이 아니다. 특히 HPE는 이미 본 발견 사례다. 공개 가격·거래량과 허용된 보유 기준일만 저장하며 계좌·주문·자격증명을 복사하지 않는다.
