# 미국 보고서 실물 검증 후 제한적 수정 계획

대상은 DGX 검증에서 재현한 오류다. 회사별 정답 치환, 모델 교체, 추가 전문 에이전트, 매매 기준 변경은 하지 않는다.

1. SEC 입력: 백분율을 금액으로 바꾸는 오류와 분기를 FY로 바꾸는 오류를 회귀 테스트로 고정한다. 단위·배율·부호·기간을 검증한 매출만 반환하고 불확실하면 제외한다. 가장 최근 적격 공시를 날짜로 선택한다.
2. 기술 지표: 기존 OHLCV 1회 조회를 재사용해 코드로 계산한다. 결측·부족한 기간은 숫자를 만들지 않는다. 가격 분석과 최종 전략·요약에 같은 기준값을 전달한다.
3. 섹션 통합: 이미 생성한 뉴스 근거를 기업 현황·개요 생성 전에 공유한다. 미확보와 실제 부재, 회사 전망과 컨센서스, 가격 기준일과 조회 시각을 구분한다. 근거의 모델 작성 사실을 숨기지 않고 새 사실로 인증하지 않는다.
4. 공식 원문 접근 실패: 기존 조회 횟수 안에서 다른 공식 URL을 찾도록 지침을 보강한다. 반복 재시도나 새 유료 공급자를 추가하지 않는다.
5. PDF: 내부 근거 기록은 손실 없이 부록으로 이동하고 표지 티커 중복을 고친다. 소비자에게 필요한 근거 ID·원문은 유지한다.
6. 운영: 정확한 PR head CI, 무주문 회귀, 독립 검토 후 clean 서버에 ff-only 배포한다. app-server OAuth 연결은 기존 인증을 재사용하고 인증정보를 복사·출력하지 않는다. 봇 재기동 및 PDF 스모크, 실제 DGX 보고서 1건을 마지막으로 검증한다.

회귀 실패를 숨기거나 알려진 오류 보고서를 정상 캐시에 남기지 않는다. 기존 운영 배치와 주문 경로는 수동 재실행하지 않는다. 실제 모델의 모든 숫자가 항상 정확하다고 주장하지 않는다.

## 검증된 구현 범위

- 보고서·근거·PDF 소비자 회귀 묶음 265개 통과, 시세 형식·기존 게이트 회귀 79개 통과(기존 KIS 설정 의존 사례 1개 제외).
- 신규 파일 Ruff, 변경 Python 구문 검사, diff check 통과. 별도 Python 타입 검사 성공으로 표현하지 않는다.
- SEC는 단위가 USD이고 지원하는 매출 concept·변환·기간이 명확한 inline XBRL만 사용한다. 일반 HTML 표나 비율을 금액으로 추측하지 않는다.
- 과거 지표는 마지막 유효일과 최신 행을 별도로 표시한다. 최신 행 결측을 최신 가격으로 보정하지 않으며 중간 결측은 이어 붙이지 않는다.
- 뉴스 호출 수를 늘리지 않고 이미 생성하는 뉴스 결과를 기업 현황·개요에서 재사용한다. 시장 공통 캐시는 종목별 기준값을 받지 않는다.
- 출처 부록은 본문 정리 이후 붙여 원문 JSON·코드펜스 등을 보존한다. 기존 KR 영숫자 우선주 코드도 유지한다.

## app-server OAuth 배포

`deploy/systemd/prism-report-oauth-tunnel.service.example`을 app-server에 설치한다. 기존 prism 사용자의 전용 SSH 키와 DB의 기존 OAuth proxy를 재사용한다. DB authorized_keys에서는 해당 키의 기존 `permitopen=127.0.0.1:8765`를 유지하면서 `127.0.0.1:18741`만 추가한다. 기존 forced command, no-pty, no-agent-forwarding 등은 그대로 보존한다. 다른 키나 전역 SSH 정책을 변경하지 않는다.

`deploy/report-oauth.env.example`을 app-server의 ignored `.env.report-oauth`에 설치한다. 이 파일에는 루프백 URL과 placeholder만 있으며 실제 인증정보는 없다. 봇은 SDK·worker import 전에 이를 읽는다. 터널 오류 시 다른 인증 경로로 전환하지 않는다. 기존 `.env` 및 비밀 설정은 수정하지 않는다. 인증정보·개인키는 서버 사이에 복사하지 않는다.

배포 전 파일 해시·서비스·프로세스 상태를 기록하고 변경 대상 외 설정과 cron 불변을 확인한다. 실패한 임시 시험 터널은 이미 종료했다. 서비스 설치·권한 변경·봇 재기동은 정확한 PR head CI 통과 이후에만 적용한다.
