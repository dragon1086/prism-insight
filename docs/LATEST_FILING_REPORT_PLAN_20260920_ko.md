# 최신 공시 보고서 연결 작업 계획

기준: PR #752, c894284c. 기존 보유기간·손절·재진입·주문 경로는 수정하지 않습니다.

1. 기존 adapter/선택기/prefetch 회귀 100개 통과를 기준으로 고정합니다.
2. 공식 DART 회사 프로필로 종목코드와 법인코드를 연결합니다. 이름만으로 확정하지 않습니다.
3. 기존 목록·표지·정정 계보 선택기를 재사용하고, 선택된 기본 공시와 연간 보완 자료만 보고서에 전달합니다.
4. 원문 전체 대신 검증된 viewer의 재무제표·주석을 개별 수집합니다. 각 응답 2 MiB 한도는 유지하고, 섹션 초과·누락은 실패로 남깁니다.
5. 기존 HTML 파서와 주제 분류를 재사용합니다. 공통 블록 변환만 추출하여 Firecrawl 경로를 보존하고 DART 원문을 Firecrawl 정제본으로 표시하지 않습니다.
6. 신규 옵션은 기본 OFF로 유지합니다. 기준시점·범위·캐시 버전을 분리하고 검색으로 얻은 과거 공시가 최신 자료로 혼합되는 것을 막습니다.
7. 실패·미래 자료·다른 회사·해시/URL 불일치·조건 보존·6,000바이트·OFF/US 회귀를 검사합니다. 이어서 미국 소비 경계와 남은 전체 검증을 수행합니다.
8. 실제 오스코텍 주석에서 발견한 회계정책 제목의 범위 초기화 오류를 먼저 실패 테스트로 고정합니다. 알려진 내부 주석 제목만 상속하고, 장식된 별도/연결 최상위 제목은 미지원이면 UNKNOWN으로 끊습니다. 고정 3문서 원문 위치 검증도 다시 수행합니다.

한국·미국 전체 품질 게이트가 닫히기 전에는 머지·배포하지 않습니다. 실제 모델 생성 품질과 오프라인 고정 응답 테스트는 별도로 보고합니다.
