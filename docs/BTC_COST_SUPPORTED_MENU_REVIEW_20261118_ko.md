1. **변경 유형·범위:** M4 경제적 의사결정 입력 선택 보완이다. 기준선은 배포fbf9762e이다.

   실제3일전체AI판단을재현한것이아닌기존24시점시험에서1거래가나왔다는한계를구분한다.

   더쓸수있는같은방식의대안을가릴수있다. 11/14 11:15 돌파대안에서도같은누락을확인했다.

   먼저제공한다. 예시가없으면미평가계획도그대로남긴다. 예시는확률/허가나완전한가능성목록이아니다.

   더넓은구조적손절은이미존재하던신규계획이며수량은원래계산기로다시산정한다.기존보유손절은건드리지않는다.
4. **검증 설계:** LONG/SHORT에서유효대안이가려지지않음,방식다양성·순서·6개/12KB·입력불변,
   전부미평가인경우기존후보보존과실제호스트가격/리스크검증을시험한다. 실제선택은별도AI비교로확인한다.
