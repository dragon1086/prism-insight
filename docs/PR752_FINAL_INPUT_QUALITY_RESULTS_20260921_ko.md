# 최종 공시 입력 품질 개선 결과: KR 게이트는 아직 불합격

## 판정과 진행 순서

사용자 요청에 따라 한국 품질을 먼저 개선하고 검증했습니다. **필수 G1·G2는 실패, G3는 통과**입니다. 따라서 새로운 KR 홀드아웃 수집, 실제 모델/PDF/BUY/SELL 소비 검증, 미국 확장은 아직 진행하지 않았습니다. 단위 테스트·CI 통과를 내용 품질 합격으로 바꾸지 않습니다. 운영 설정·매매 규칙·머지·배포는 변경하지 않았습니다.

## 구현한 개선

- `filing_report_evidence.py`: 제목·기간·단위의 `context_paths`도 기존 DOM prefix 공유에 포함했습니다. 새로운 저장 계층이나 외부 참조 없이 기존 compact/expand를 확장했고 원문 문자·출처는 그대로입니다.
- `material_filing_selection.py`, `report_insight_prefetch.py`: 전체 material HTML 후보의 구체적인 문맥을 검토한 뒤 기존 source/topic 24개 제한을 적용합니다. 번호가 같은 큰 주석 안에서도 서로 다른 caption·명시적 기간 문맥이 첫 기회를 받도록 했습니다. 금액·회사명·열 번호·gold 일치 수·긍정/부정 점수는 사용하지 않습니다. 내부 선정 분류는 모델 입력에 넣지 않습니다.
- `filing_html_projection.py`: 엄격한 header/기하 문법이 성립하는 큰 표에 한해 `html_column_view_v1`을 제공합니다. 같은 검토 주제의 독립 열을 대칭적으로 선택하고 모든 원래 행·row-label·선정 셀·조건·단위·기간을 보존합니다. 원래 shape와 좌표를 유지하며 부분 표현임을 명시합니다. 각주·교차 참조의 범위가 미해결이면 거절하고 전체 원본 후보로 남깁니다.
- `filing_html.py`, `dart_report_evidence.py`: 원문 반입부터 parser·representation·projection·후보 사전 정렬까지 하나의 협력적 10초 deadline을 전달합니다. standalone parser 기본 동작은 유지합니다. 이후 최종 packet 조립은 기존 고정 frontier와 6,000바이트 계약을 따르며 전체 네트워크/보고서 실행이 10초라는 뜻은 아닙니다.
- `evaluate_large_filing_html.py`: 전체 provenance를 전달 block과 대조하고, 원래 표의 단위/기간 문맥·각주 문자까지 비교합니다. 좌표만 같고 조건이 바뀌는 변조와 Boolean 좌표 metadata도 거절합니다. 새 schema의 mask·원본 셀·전체 행·label을 독립적으로 대조합니다.
- `isolated_responses_proxy.py`: 후속 실제 검증을 위한 명시적 `--tool-free` 모드를 추가했습니다. 도구 요청/결과, 함수 호출 입출력을 거절하고 기존 요청 수·시간·응답 바이트 방어를 재사용합니다. 이번에는 실제 OAuth 모델을 호출하지 않았습니다. native upstream token 강제 제한이나 upstream 즉시 취소를 구현했다고 주장하지 않습니다.
- parser revision을 `bounded-html-v10-material-detail`로 갱신하고 신규 모듈 fingerprint/CI 회귀를 연결했습니다. 의존성 추가, 24개 cap 확대, 6,000바이트 증액, 수집 한도 변경은 없습니다.

## 실제 필수 기준 결과

원문만으로 먼저 고정한 `PR752_S3_SAMSUNG_LIFE_GOLD_20260920_ko.md`는 바꾸지 않았습니다. evaluator는 필수 셀뿐 아니라 row-label/header, 완전한 조건, 원문 해시·주체·기간·단위·scope·출처를 실제 전달 packet에서 확인합니다.

- **G3 복구:** 별개 종속기업 소송의 주체, 6건, 청구 금액24,426백만원, 결과·영향을 예측할 수 없다는 조건을 원래 14개 셀 및 문맥과 함께 전달합니다. 충당부채나 확정 손실로 바꾸지 않습니다.
- **G1·G2 미복구:** 최신 승소·지급 의무 소멸과 환매지연 충당부채의 추정·불확실성 묶음은 여전히 빠집니다. 큰 원본 표는 현재 packet에 들어가지 않고, 투영은 미해결 `상기` 참조 때문에 거절됩니다. 두 gold 열만 특별히 허용하거나 참조 guard를 약화하지 않았습니다.
- 마지막 일반 source 구성의 news/overview/status는 **5,803 / 5,607 / 5,917바이트**입니다. 연간 fragment를 전체 연간 주석으로 바꾼 component 비교도 G1·G2 실패/G3 통과이며 news는5,804바이트입니다. 둘 다 전체 네트워크 replay나 현재 시점의 최신성 재검증이 아닙니다.
- 새 evaluator 자체도 기간 변조·조건 절단·row-label 누락·단위 변조·알 수 없는 codec·공통 metadata 충돌 등 7개 반례를 거절했습니다. 필수 기준이 실패하면 종료 코드1을 유지합니다.

## 원문 충실도와 자원 검증

기존 비공개 원문7개를 SHA 대조 후 다시 처리했습니다. **86,480개 원문 위치와 모든 후보/실제 packet의 원문 대조에서 오류0개**, parser 원본 record 불변을 확인했습니다. 과거 사용한 회귀군이며 새 홀드아웃이 아닙니다.

실제 부분 뷰는 기존 LG 원문 두 표에서 생성됐습니다. 두 표 모두 원본15행×10열/99셀 중 row-label과 합계 열의23셀을 보존합니다. 독립 architect가 원본 전체 표와 생략한 열까지 읽어, 선정된 covenant 설명의 조건 손실을 발견하지 않았습니다. 약정 미충족 조건, waiver 완료/진행의 차이 및 나머지 약정 준수 문구가 그대로 남습니다.

이는 합계와 구성 항목이 수학적으로 독립적이라는 뜻이 아니며, 전체 금융기관별 만기·금리나 차입 내역의 검증도 아닙니다. 전기말 caption 안에 당반기말 상태를 서술한 셀도 있어 후속 실제 소비 단계의 기간 해석 검증이 필요합니다. 삼성생명과 POSCO 등에서 거절된 투영은 그대로 실패/원본 후보로 보존했습니다.

파싱부터 후보 사전 정렬까지 기존2,833,488바이트 연간 주석은 약2.84초, 해당 단계 직후 프로세스 peak RSS 약114.2MiB였습니다. 이전0.525초는 parser만 측정했으므로 직접적인 속도 비교가 아닙니다. 원문 oracle 감사는 별도입니다. macOS 로컬 측정이며 OS 메모리 hard cap 또는 운영 서버 보장치가 아닙니다.

## 테스트와 독립 리뷰

- 최종 연구 입력 회귀 **2,193개 통과**, 기존 경고4개.
- 별도 tool-free proxy **57개**, KR/US provider 호환 통합 **46개 통과**. 미국 신규 원문/품질 확장을 실행한 것이 아닙니다.
- 변경 Python18개 AST/구문 검사와 `git diff --check` 통과. 동일 repository Ruff로 이전 HEAD와 비교했으며 기존11개 진단은 남고 신규 진단은0개입니다. Python 타입 검사 통과는 주장하지 않습니다.
- 독립 리뷰에서 미해결 주석 의존성, 문맥/각주 문자 변조, Boolean metadata, 긍정·부정 및 금액 문자열 길이로 달라지는 선정 분류를 발견했습니다. 각각 실패 회귀를 먼저 재현한 뒤 수정했습니다. 마지막 코드/안전성 리뷰는 **APPROVE**, LG 두 부분 뷰의 제한된 원문 의미 검토도 통과했습니다. 전체 내용 품질 승인은 아닙니다.

## 남은 의사결정과 후속 작업

확인한 범위에서는 무손실 경로 공유·일반적인 후보 다양화·엄격한 부분 뷰만으로 현재6,000바이트 필수 기준을 통과하지 못했습니다. 독립적인 full-grid/metadata 공유 가상 schema 공간 진단도6,000을 넘었지만, 구현/decoder/consumer 검증 결과나 모든 안전한 표현의 불가능성 증명은 아닙니다.

다음 선택지인 **운영6,000은 유지한 채 무모델·오프라인6,000/12,000/24,000/32,000바이트 비교**는 아직 명시적으로 승인되지 않아 실행하지 않았습니다. 이 실험은 예산 효과를 같은 원문·후보·순서·gold로 분리해 확인하기 위한 것이며, 성공해도 운영 한도 변경이나 실제 모델/미국 품질 통과가 아닙니다.32,000에서도 실패하면 자동 증액하지 않습니다.

기존 미완료인 새로운 KR source-first 홀드아웃, 실제 보고서/PDF/BUY·fresh SELL, 미국 공식 SEC 및 소비 검증, 기존 BUY snapshot 두 건과 최종 운영 게이트는 그대로 남아 있습니다. 실제 source/model 호출·주문·운영 채널 발송은0회입니다. 결과·패치·인수인계를 보존하고 비교 실험의 사용자 결정을 기다립니다.
