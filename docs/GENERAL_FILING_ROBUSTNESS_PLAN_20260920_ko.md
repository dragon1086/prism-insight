# 범용 공시 분석 개선 계획

사용자 지적: 특정 종목 몇 개의 성공이나 미국 고정 PDF 소비 테스트는 범용 분석의 증거가 아닙니다. 미국의 기존 자료 경로와 새로 검증한 범위를 분리해서 설명합니다.

## 기준과 변경 경계

- 기준 커밋: 3a8bfac0. 기존 Draft PR #752를 유지합니다.
- 한국은 DART, 미국 공시 원천은 SEC EDGAR입니다. TradingView는 별도 선택형 보완 자료이지 공시를 대체하지 않습니다. 현재 미국 운영 경로는 yfinance 재무·가격·주주·추정치, Yahoo CDN의 SEC 공시 부문 매출, Perplexity·Firecrawl 뉴스/원문을 사용합니다. 새 공식 SEC 목록 기반 최신성 검증과 기존 운영을 구분합니다.
- 거래 규칙·기본 OFF·운영 설정·인증을 변경하지 않습니다. 모델 OAuth 오류와 무관하게 가능한 원문 수집·파싱·전달 개선을 계속합니다.

## 사전 고정 검증

- 아래 manifest의 개발군과 별도 검증군을 파서 출력을 보기 전에 고정합니다. 기업별 이름 분기·하드코딩 금지입니다.
- 개발군에서 실패를 재현한 뒤 일반 구조 규칙으로 수정합니다. 수정 전후 같은 원문의 hash를 비교합니다. 검증군 결과를 본 뒤 수정하면 해당 군은 회귀군으로 전환하고 새로운 검증군을 고정해야 합니다.
- 성공은 발행사 연결, 기준시점/기간/정정 처리, 본문 확보, 후보 추출, 최종 예산 내 전달, 조건·단위 보존으로 나눕니다. HTTP 200이나 레코드 수만으로 분석 성공이라고 판정하지 않습니다.

## 실행 순서

1. 한국의 실제 보고서 입력 전체를 측정하는 종목별 하드코딩 없는 평가기를 만듭니다. 여섯 업종 개발군으로 실패를 모으고, 이전 기본 종목 성공은 대조군으로만 취급합니다.
2. 미국의 기존 inline XBRL 부문 매출에서 임의의 백만 USD·기간·빈 값 0 추정을 먼저 실패 테스트로 고정합니다. 공통 구조·context·unit·scale·sign·nil·dimension을 확인한 값만 전달하고 서로 다른 기간을 합치지 않습니다. 기존 함수를 얇은 어댑터로 바꾸되 새 의존성은 추가하지 않습니다.
3. 공식 SEC 제출 목록으로 종목/CIK·보고기간·공개시각·서식을 검증하는 유한 예산 수집기를 추가합니다. 10-Q/10-K, 외국 발행사의 20-F/40-F, 6-K/8-K 사건 자료, 정정의 다른 의미를 분리합니다. 정정 원문이 전체 대체인지 모르면 임의 최신 원문으로 승격하지 않습니다.
4. 공통 보고서 예산과 연결하고 기본 OFF/US 기존 경로 회귀를 검사합니다. SEC 접근 정책을 지키고 적절한 User-Agent가 없거나 접근이 거부되면 실패를 명시합니다. 차단 우회·인증 복사·종목별 fallback은 하지 않습니다.
5. 개발군 개선 후 미사용 검증군을 한 번 실행하고 누락·왜곡·비용·전달 결과를 모두 보고합니다. 새 모델 생성 품질과 수익률은 원문 테스트로 대체하지 않습니다.

## 합격 조건

- 다른 회사/미래 공시/범위·기간·단위 혼합 0건, 근거 hash·원문 위치 보존, 지원하지 않는 서식은 명시적 상태로 처리합니다.
- 최종 전달까지 다업종에서 검증하고, 실패 사례가 남으면 어떤 입력군이 미지원인지 공개합니다. 범용성을 주장하려면 개발군 성공뿐 아니라 별도 검증군 결과가 필요합니다.
- API/원문 접근·모델 인증 등 외부 제약은 코드 결함과 분리합니다. 전체 PR 검증이 끝나기 전 머지·배포하지 않습니다.
