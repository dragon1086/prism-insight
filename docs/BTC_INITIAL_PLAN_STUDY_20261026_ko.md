# M2/M4 최초 진입 계획 비교 후속 — 2026-10-26

## 결론

후보 DRAFT 프롬프트는 미배포 HOLD를 유지한다. 12개 구간·두 안을 실제 45회 호출로 비교했으며
최대48회 중 남은3회는 잠갔다. 이번 후속은 저장된 응답만 계산했고 모델 호출·주문은 0회다.
기준안은 진입6/대기6, 후보안은 진입3/대기9다. 수익 개선이나 매매 승률을 입증한 결과가 아니다.

## 후보가 한 개만 나온 단계

실제 HTTP 요청 24개 DRAFT schema 모두 후보 상한2를 허용했다. 원문에서 기준안은
한 후보10개 구간·빈 후보2개 구간, 후보안은 한 후보11개 구간·빈 후보1개 구간이었다.
총21개 원 후보가 host 계산 후에도 그대로 남았고, 모두 선택 가능한 검증 통과 상태였다.
따라서 host의 필터·수량 계산·SELECT 입력 누락 때문에 두 번째 후보가 사라진 것은 아니다.

후보 프롬프트의 추가 문장도 실제 요청에 포함돼 있었다. 현재 계약은 한 후보를 허용하며,
후보가 한 개일 때 두 번째를 제시하지 않은 이유는 기록하지 않는다. 21개 모두 그 이유는
NOT_COLLECTED다. 모델이 선택지를 검토하지 않았는지, 검토 후 근거 부족으로 제외했는지는
알 수 없다. 후보 수를 강제로2로 늘리거나 근거 없는 가격·목표를 만들도록 바꾸지 않는다.

## 동일 수수료 가정의 민감도

실제 과거 계좌의 수수료 근거는21개 모두 UNKNOWN이다. 이를 소급 채우지 않고 기존 재생기의
maker 0.0002·taker 0.00055를 별도 가정으로만 사용했다. 원 수량·가격·반올림 결과를 그대로
두고 STOP·TP1_STOP·TP_STOP의 총손익과 잔량을 host 값과 전부 대조한 뒤 가정 수수료를 뺐다.
펀딩과 슬리피지는 제외돼 있으므로 실제 순수익이나 전체 비용 차감 성과가 아니다.

| 가정 | TP 후 잔량 SL 경로 / 전량 SL 손실 비율이 1 이상인 계획 |
|---|---:|
| 진입·TP maker, SL taker | 3/21 |
| 모든 체결 taker | 0/21 |
| 모든 체결 taker 수수료2배 | 0/21 |

첫 TP 뒤 수량이 남는18개 계획 중17개는 나머지를 SL로 끝내면 taker 가정 수수료 차감 후 손실이다.
이는 부분익절만으로 전체 손실이 방지되지 않는다는 계산이다. 해당 경로의 발생 확률이나 기대값은 아니다.
TP_STOP은 목표 체결 뒤 잔량을 SL로 끝내는 스트레스 경로다. S06 기준안은 의도적으로30%를
목표 없는 보호 잔량으로 남겼으므로, 이 스트레스 수치를 추세 잔여분의 가치로 보거나
그 잔여분을 없앤 후보안이 더 낫다고 단정하지 않는다. 나머지20개 계획은 TP 비중 합계1이다.

양안 모두 계획이 있는10개 구간의 taker 가정 비율은 후보가5개에서 높고5개에서 낮았다.
S06의 상승은 보호 잔량 제거를 포함하므로 단순 개선으로 세면 안 된다. 유리한 사례만 골라
후보를 채택하지 않는다. 제한구간은 높은 승률로 낮은 보상/손실 비율을 보완할 수도 있지만,
현재 표본은 그 승률을 검증하지 않았으며 일괄 차단 기준을 새로 만들지 않는다.

3. 시장성 체결 재현 오차를 보완하고, 보호 잔량을 강제 SL로 평가한 결과와 실제 추세 보유 결과를 구분한다.
