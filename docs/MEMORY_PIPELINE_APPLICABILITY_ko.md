# 누적 기억의 현행 파이프라인 적용성 계약

## 변경 범위와 판단

2026-09-27 사용자 요청: 누적 직관과 교훈은 현 시스템에서 실천할 수 있는 내용을
중심으로 남기고, 향후 기능 개선 제안도 일부 구분하여 보존한다.

기준선 `5c054f0c`에서 기억은 높은 신뢰도·우선순위만으로 BUY 입력에 들어갔다.
이 변경은 **기억 생성·분류·전달 경계 변경**이며 단순한 보고서 문구 수정이 아니다.
매수 점수, 손익비, 예산, 손절, 트리거, 주문 정책을 새로 만들거나 변경하지 않는다.

### Strategy adoption/fit 검토 기록

1. 유형: 잘못된 적용범위 전달의 수리와 LLM 참고 입력 변경. 기존 정책의 입력과
   권한을 보존하고, 미구현 기능을 요구하는 조언을 현재 실행 규칙에서 분리한다.
2. 가설: 현재 가능한 판단과 미래 개발 제안을 구분하면 실행 불가능한 지시를 줄일 수 있다.
   수익률 개선 가설이나 새 진입 전략은 아니다. 관련 조언이 BUY에 계속 유입되거나
   정상적인 현재 판단 근거가 사라지면 구현이 잘못된 것이다.
3. 궁합: 아래 실제 단계별 권한을 공통 계약으로 제공한다. 과거 손실을 근거로 모든
   돌파·갭 트리거를 전역 차단하거나, 기존 pilot을 일반 임의 분할매수로 확대하지 않는다.
4. 검증: 동일 후보·기록에서 현재 보고서 근거 확인은 유지하고, 자동 후속 진입·새 비중·
   새 임계값·다른 시장 데이터 해석은 차단하는 양방향 오프라인 테스트를 실행한다.
   점수 조정·주문 로직은 바꾸지 않는다. 수익성이나 LLM 판단의 인과 효과는 미검증이다.
5. 원인 분리·복귀: application_context와 계약 버전으로 분류 근거를 남긴다.
   원문·출처·기존 활성 상태는 보존한다. 잘못된 분류는 해당 메타데이터를 재검토하며,
   원문을 현재 기능에 맞는 내용인 것처럼 임의로 고쳐 승인하지 않는다.
6. 결론: 사용자 승인 범위인 기억 적용성 경계만 구현한다. 새 전략·SHADOW/LIVE 승격,
   새로운 관찰목록 집행기·사이징·데이터 수집은 도입하지 않는다.

## 분류와 소비 경계

- `current_pipeline`: 기존 기능·자료·권한 안에서 가능한 **조건부 참고**.
- `improvement`: 새 자료, 감시/후속 주문, 전략·임계값·비중 변경 등 구현과 검증이 필요한 제안.
- `unreviewed`: 출처·시장·단계·필요 기능 또는 적용성이 확인되지 않은 기록.

직관·원칙에는 `application_context` JSON을 저장하고, 개별 journal lesson에도 같은
메타데이터를 둔다. 계약 버전·시장·단계·필요 기능·이유를 포함한다.
누락된 legacy 기록을 자동으로 current로 승인하지 않는다.

BUY의 세 입력 경로(원칙, 누적 직관, 동일 종목 lesson)에는 검토된 현재 BUY 참고만 넣는다.
가격·수익률·보유기간 등 사실 이력은 유지한다. 보유관리 단계의 현재 원칙도 BUY의
전역 진입 차단 규칙으로 바꾸지 않는다. 개선 제안은 주간 보고서의 별도 소수 항목으로
보여주며, 정해진 비율을 채우려고 없는 교훈을 만들어내지 않는다.

## 검증 상태

구현과 로컬 검증을 완료했다. 보고서·메모리·양국 동일 후보 입력·기존 경험 점수·관측
연계·중복 출처 관련 테스트 123개가 통과했다. 신규 생성자의 자체 분류는 무조건
미검토로 저장하며, 생성 에이전트의 SQLite 도구 접근도 제거했다.
읽기 전용 legacy 스키마에서 거래 사실을 보존하는 사례와, 다시 작성된 통합 직관이
이전 적용 승인을 상속하지 않는 사례도 검증했다.

양국 `get_score_adjustment`, `get_performance_tracker_stats`, `_format_performance_context`의
AST가 기준선과 같음을 확인했다. 이 사실은 LLM 참고 입력의 영향까지 불변이라는 뜻은 아니다.
실제 모델 분류 운영 적용(2026-09-27, KR 472·US 289개 검토): 원문 8행 비활성화로 활성 직관 50→45개,
현재 참고 15·개선 제안 27·미검토 3개. 미매수 후 등락 건수는 가상 관찰이고 모델 신뢰도 93~97%는 추정값이라
인과·정확도 근거로 쓰지 않는다.
정규 배치 결과는 아직 미관측이다. 이 문서는 수익성 검증이나 전체 전략 궁합이
개선됐다는 증거가 아니다.
