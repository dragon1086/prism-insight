# M4 신규 진입의 목적 우선 초안 후보

상태: v2 실제16회 비교 완료, **HOLD·미배포**. 안쪽 목적 설명은 구분했지만 바깥 추세 계획의 일관된 개선과 근거 누락 방지를 입증하지 못했다.

1. 경제적 의사결정 변경 후보다. 최신 비교 기준선은 main1924cbda(운영5e4a0f0a와 실행 코드 동일)이며, 실패한 cad393b8 후보를 누적하지 않는다.
   version2 무포지션·새 진입이 가능한 DRAFT에만 붙인다. SELECT·보유·대기 주문·위험·보호·실행은 바꾸지 않는다.
2. 사용자 방향은 MA10·MA35 사이에서 높은 승률을 목표로 짧게, 밴드 밖의 기존 추세추종 자리에서 좋은 손익비로 크게 먹는 것이다. 가설은
   목적을 먼저 정하면 가까운 목표로 전량 종료하는 계획과, 근거 있는 추세 참여 계획을 실제로 구분해 검토한다는 것이다.
   두 후보를 늘리는 것 자체는 목적이 아니다. 모든 시장에 러너를 강제하거나 WAIT 감소를 성공으로 보지 않는다.
3. 12구간의21개 계획 중14개가 TREND로 명명됐지만20개는 TP 비중 합계1이다. BOUNDED_BEFORE15개,
   NO_MA_BOUND6개, REFERENCE_EXTENSION0개다. 이것은 명명/목표/물량 설계의 간극을 의심할 근거이며,
   근거 있는 확장 기회가 실제로 있었다는 증명은 아니다. 한 후보 허용과 대안 부재 이유 누락도 확인됐다.
   기존 v2 목표 계약은 새 후보별 서로 다른 목적을 허용하되, 등록 후에는 원 목표를 바꾸지 못한다.
   MA10→MA35 제한 횡단을 추세로 재명명해 상한을 우회하지 않는다. SELECT의 잔여분 스트레스와 추세 가치 구분을 유지한다.
4. 실제 조립된 두 단계 요청에서 DRAFT만 변화, SELECT/schema/input/호출 수 동일성을 확인한다.
   LONG/SHORT의 bounded/extension 두 후보 계산, 단일 후보 허용, 근거 부족 WAIT, 보유/대기/첫 관측 제외,
   목표 위반 거절을 확인한다. 이전12구간은 개발 자료다. 새 모델 검사는 새 등록과 별도 호출 예산이 필요하다.
5. 추가 목표·가격을 지어내거나 SL을 줄임, 제한 횡단의 상한 우회, 강한 현재 진입의 무조건 대기 전환,
   근거 없는 고승률 주장, 보호 잔량 일률 강제가 나오면 중단한다. 수익은 독립 자료/실제 비용/보유 경로까지 검증해야 한다.
6. 현재 결론은 미배포 후보 구현이다. 함수 검사 통과로 모델 행동이나 수익 개선을 주장하지 않는다.
   기존45회 호출 장부는 봉인 그대로 유지하며 이 변경을 위해 재사용하지 않는다.

## 변경 문단의 한국어 의미

- 먼저 현재 가격 진행이 추세 지속 기회인지, 특정 경계까지의 제한된 이동인지 정한다.
- 추세 계획은 더 진행될 때 남길 물량과 구조적 실패 시 지킬 위험을 함께 설계한다. 전량익절도 근거가 있으면 허용한다.
- 상위 시간대 MA는 실제 반응 근거를 평가할 대상이다. 존재한다는 이유만으로 모든 새 거래의 자동 목표 상한으로 삼지 않는다.
- 제한 횡단은 상한을 지킨다. 고승률은 주장만으로 인정하지 않고, 수량 축소·가까운 익절이 구조를 고쳤다고 말하지 않는다.
- 두 번째 계획은 진입 위치나 익절/보호 잔량에 독립적인 근거가 있을 때만 낸다. 없으면 기존 설명에 검토한 대안과 제외 근거를 남긴다.
- 새 무포지션 후보끼리는 목적이 다를 수 있으나, 각 목적에 실제 근거가 있어야 한다. 등록된 보유 목표를 바꿀 권한은 만들지 않는다.

## 표본의 위치 기준 재점검

기존12구간의 UP/DOWN/RANGE는 당시 사전 정의한 MA 배열·간격·가격 진행 분류다.
RANGE가 곧 가격 BETWEEN이라는 뜻은 아니었다. 입력 시점의 합성 형성봉 가격을 MA10/35에
대조하면 30m·1h 모두 BETWEEN인 구간은 S03 한 개이고, 나머지11개는 밴드 밖이다(4h도 동일).
기존 RANGE4개 중 S01/S04는 ABOVE, S02는 BELOW, S03만 BETWEEN이었다.
따라서 기존 비교는 사용자의 안/밖 두 목적을 균형 있게 검증하지 못했다. 원 분류·응답은 보존한다.
다음 등록은 가격 BETWEEN과 기존 추세추종 자리를 별도로 표집하고 시간축·확정/형성·조건부
활성화를 구분해야 한다. 밴드 안 표본 하나로 높은 승률 가설을 판정하지 않는다.
근거: `tasks/btc-purpose-first-20261026/band-location-coverage.json`.

명확화 이후 관련136개 오프라인 검사 통과. 기존 준비 실행은 superseded 표식에서

안쪽 두 사례는 양안 모두 MA35 앞 제한 횡단을 지켰고 고승률을 실측 사실로 주장하지 않았다.
