# TradingView Essential 실호출 검증 결과

> 역사적 기록: TradingView는 2026-09-23 사용자 결정으로 자동매매 프로젝트에서 제거합니다.
> 현재 배포 범위는 `US_EVIDENCE_RELEASE_20260923_ko.md`를 따릅니다. 아래 내용은 당시의 조사 기록입니다.

## 범위

리눅스 서버의 사용자가 승인한 OAuth로 실제 tools/list와 읽기 도구를 호출했다.
문서상 기능 나열이나 인증 성공만을 데이터 검증으로 취급하지 않았다.
이 시험은 한국시간 2026-09-18에 실시했으며 일부 시각은 UTC 9/17이다.
주문·관심목록 생성/편집·알림 생성/삭제는 하지 않았고 운영 보고서·매매에는 연결하지 않았다.

- 실제 도구 카탈로그: 35종.
- 서로 다른 읽기 도구22종에서 호출 결과43건을 기록했다. 재시도·입력 수정 시험을 포함한다.
- 별도 세션 초기화 실패도 있어 모든 시작 시도가 데이터 호출로 이어진 것은 아니다.
- 기록된 호출 중 시간값이 있는41건: 최소0.754초, 중간19.816초, 최대70.07초(클라이언트 제한시간).
  이는 작은 진단 표본이며 SLA나 비용 절감률이 아니다.
- 계정 변경10종과 기본 관심목록을 생성/활성화할 수 있는 get_active_watchlist는 제외했다.
- 기존 watchlist 상세와 alert 상세는 이번에 완료하지 못했다. 계정별 본문은 일반 결과물에 노출하지 않았다.
- 수집은 Python이 호출을 결정했다. 신규 보고서 생성 에이전트는 실행하지 않았다.

## 실제 확인한 활용처

### 미국·한국 조회와 스크리너

- MSFT와 삼성전자의 심볼 검색·일괄 스냅샷·기술지표·재무·재무 이력·전망 응답을 받았다.
- 명시적인 시총 필터를 넣은 미국·한국 스크리너가 결과 행과 totalCount를 반환했다.
  이는 조회 가능성을 확인한 것으로 전체 반환 건수가 적격 투자 종목 수라는 뜻은 아니다.
- individual ticker를 symbolset으로 지정한 첫 시험은 양국 모두0행이었다. 필터 없이 호출한
  시험은 명시적으로 거절됐다. 문서만 보고 인자 의미를 가정하면 안 된다.
- 스크리너 표본에는 보통주뿐 아니라 DR도 포함됐다. instrument type·통화·거래소 필터가 필요하다.
- 강한 기술 등급이어도 50일 EMA 대비 크게 이격된 한국 종목이 반환됐다. TV의 BUY 등급은
  우리 전략의 적정 진입 구간 또는 실제 매수 승인과 동일하지 않다.

### 뉴스와 기업 문서

- 뉴스 목록은 출처·발표시각·관련 종목·유료 여부를 제공했다. headline 접근과 전문 접근은 다르다.
- 미국의 공개 기사1건은 원문 응답을 받았다. 뉴스 ID는 URN만 있는 것이 아니므로 반환값을
  그대로 써야 한다. 초기 시험의 URN 전용 선택 조건은 너무 좁아 별도 재시험으로 수정했다.
- MSFT 경영진 컨퍼런스 대화와 삼성전자 실적 컨퍼런스콜의 텍스트 응답을 확보했다.
  응답 표현은 각각 약36,787자와70,206자였다. 전체를 모든 에이전트에 넣으면 비용이 늘어난다.
- RF머트리얼즈 같은 한국 소형주도 공시 목록을 반환했다. 다만 해당 요약 본문은 이번 세션에서
  확보하지 못했으므로 목록 조회를 원문 확보로 세지 않는다.
- LITE 문서 조회는 시간초과가 발생했다. 미국 종목이라고 모두 같은 성공률을 보장할 수 없다.
- 삼성전자 목록에서 실제 반환한 PDF view ID를 그대로 사용해도 get_document_view는 실패했다.
  별도 반환된 transcript view는 성공했다. 표시상 usable이나 views 존재를 본문 확보로 간주하지 않는다.
- 문서 AST는 object, 뉴스 AST는 JSON 문자열인 사례가 있었다. 공통 추출기에 두 형태가 필요하다.

이 자료는 경영진의 주장·질의응답을 파악하는 데 유용하나, 그 자체로 동종사 대비 경쟁력의 독립 증명은 아니다.
뉴스·문서의 길이보다 사업 가정 변화·반대 근거·확인할 사건을 짧게 추출하는 것이 목표다.

### 일정과 경제지표

- 실적·배당 일정을 MSFT/삼성전자 묶음으로 요청했으나 MSFT만 반환한 사례가 있었다.
  미반환 종목은 '일정 없음'이 아니라 미확인이다.
- 경제지표 카탈로그·미국 근원물가 시계열·경제 일정의 실제/예상값을 조회했다.
  첫 시계열 조회는 시간초과였고 재시험에서8개 월별 값을 받았다.
- 공급자 자체가 최신 시계열의 공표 지연과 값의 사후 수정을 알린다.
  현재 응답으로 과거 판단 당시 알 수 있었던 값을 복원하지 않는다.

## 반드시 격리할 위험

### 1. 시세 지연·조정 기준

동일 계정의 스냅샷 update_mode는 미국 delayed_streaming_900, 한국 delayed_streaming_1200였다.
즉 이번 계정·시험에서는15분/20분 지연이 표시됐다. 실시간 실행 시세 대체에 사용하지 않는다.
미국 OHLCV 응답은15분 이상 지연·마지막 봉 변경 가능·정규장 밖 봉 제외·분할 조정만 적용한다고 알린다.
배당까지 조정한 기존 yfinance 자료와 조용히 연결하거나 오늘 진행 중 일봉을 완료봉으로 사용하면 안 된다.
한국 OHLCV는 재시도에서도 공급자 tvws 시간초과를 반환했다. 현재 KIS 경로 유지가 적절하다.

### 2. 한국 전망의 통화/단위 불일치

삼성전자 전망 응답은 currency=KRW, price=252500, pe_ratio=11.2360474545,
eps_ttm=14.5631538726을 함께 반환했다. price/PER로 역산한 EPS는22472.3152로 약1543배 차이다.
이는 같은 통화·정의로 곧바로 읽을 수 없다는 진단이며 환율을 추정해 자동 교정할 근거는 아니다.
공급자도 target_mismatch=true로 목표가를 제외했지만 estimates 수치는 남겼다.
해당 응답 전체를 검증 전 격리하고 전망치를 보고서나 BUY 계산에 넣지 않는 것이 안전하다.

### 3. 도구 성공과 데이터 성공은 다름

MCP isError=false지만 payload success=false/error를 반환한 사례가 있었다.
필터 없는 스크리너, 실패한 PDF view, 한국 OHLCV가 해당한다.
HTTP/MCP 수준 성공만으로 데이터가 확보됐다고 기록하면 안 된다.

### 4. 산업 분류와 지표 정의

TV sector/industry 문자열은 기존 yfinance/KIS 분류와 다르다. 예컨대 MSFT는 Technology Services로
반환됐다. 이 문자열로 기존 섹터 제한과 랭킹을 자동 대체하지 않는다.
거래량 비율·상대 거래량·부분 봉 정규화도 서로 다른 지표일 수 있으므로 이름만 보고 혼용하지 않는다.
재무 이력의 Q1/Q2 라벨은 회사 회계연도 분기인지 달력 분기인지 원 공시 기간과 대조해야 한다.

## 오프라인 입력 검사 구현

새 prism_core/tradingview_evidence.py와 tests/test_tradingview_evidence.py를 추가했다.
네트워크·캐시·인증·LLM·운영 hook은 없다. 이미 수집된 payload의 분류·최소 정규화만 수행한다.
신규 응답 검사29개를 포함한 관련 회귀263개가 통과했고 Ruff·컴파일·diff 검사를 통과했다.
이는 오프라인 계약 검증이며 운영 보고서 개선이나 LIVE 집행 안전성을 입증하는 테스트가 아니다.

- transport 성공이어도 provider error이면 PAYLOAD_FAILURE.
- 한국 전망 target_mismatch는 전망 수치 전체 QUARANTINED.
- 숫자/통화/기간 불일치를 분리하고 EPS 음수·0을 결측으로 버리지 않음.
- 출처·문서 ID·view type·뉴스 paywall·조회 요청 대비 미반환 종목을 보존.
- AST 텍스트를 제한된 길이로 추출하고 잘림을 표시.
- AVAILABLE도 공급자 응답을 확보했다는 뜻이며 독립 사실 검증이 아니다.
- 가격/PER/EPS 비율 범위 검사는 미검증 연구용 휴리스틱이고 매매 게이트가 아니다.
- 단위·기간을 확인하지 못한 재무는 PARTIAL, 미래 봉/공표 확정성은 UNKNOWN으로 남긴다.

실제 응답을 넣은 검사에서 미국 전망은 미검증 자료로 유지, 한국 전망은 격리,
실패한 PDF와 무필터 스크리너는 실패, 양국 요청 중 한 종목만 반환한 일정은 PARTIAL로 분류했다.

## 다음 적용 방향

보고서의 기존1~5절과 기존 매매 정책은 유지하고, 뉴스·문서·실적 근거를 선택형 prefetch로 보강한다.
전체 AST 대신 질문별 짧은 발췌·숫자·출처·미해결 목록만 공유한다.
한국 전망의 단위 문제·한국 OHLCV 실패·누락 일정은 기존 자료를 대체하지 않는다.
실제 보고서/PDF/BUY까지 전달·비용·가용성을 검증하기 전 운영 ON으로 바꾸지 않는다.

OAuth 갱신은 사용자의 기존 승인으로 실제 성공했고 응답 유효기간900초, 저장 권한0600을 확인했다.
운영 adapter에는 단일 갱신 관리자·동시성 제어·실패 시 기존 도구 fallback이 필요하다.
이 시험에서 사용한 갱신 보조 스크립트는 완성된 운영 인증 어댑터가 아니다.

상세 초분할·프롬프트 매핑 설계는 TRADINGVIEW_REPORT_AND_MICRO_REVIEW_20260918_ko.md 참조.
실제 데이터 정확도와 투자 성과가 개선됐다고 주장하지 않는다. 운영 시 자동 처리·보관·재배포 권한은 별도 확인한다.
