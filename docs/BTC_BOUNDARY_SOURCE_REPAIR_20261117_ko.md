# BTC 과거 재생의 봉 경계 대체값 수리

M2/M4 데이터 의미 오류 수정이다. 운영 기준선은 위험 상한 배포 `a71d043a`이다.

과거 재생은 새 봉 시작 시 아직 거래가 없으면 직전 종가로 OHLC를 채우고
`forming.observation_kind=synthetic_boundary`를 붙인다. 같은 값으로 먼저 계산된
`ma_path.forming_point`에는 표식이 없어, 기존 MA 검증기가 이를 실제 형성봉으로 받아들였다.
그 결과 재생의 진입 후보에 대체값을 근거로 한 손절·가격 수준이 생겼다.
11/16 21:00 숏의 손절 64,419.6과 23:30 롱의 손절 64,458.4가 확인된 반례다.
이는 11/17 09:20 실제 진입 손실의 원인을 입증한 것이 아니다.

수리는 `HistoricalScenarioData.snapshot` 한 곳에서 합성 경계의 형성 MA 경로·간격을
미관측으로 남기는 것이다. 확정봉의 경로·간격과 실제 진행된 형성봉은 보존한다.
운영 시세 수집·판단·손절·수량 규칙과 모델 프롬프트는 바꾸지 않는다.

같은 역사 시각·동일한 가상 호가/계좌의 전후 대조에서 21:00 숏 손절은 64,419.6에서
실제 확정 고점 근거 64,522.7로, 23:30 롱은 64,458.4에서 64,412.9로 바뀌었다.
후자가 더 수익성이 좋다는 뜻은 아니다. 잘못된 관측 근거를 제거했다는 기능 검증이다.
가상 계좌·호가는 실제 체결이나 체결 가능성의 증거가 아니다.

회귀 검사는 합성 경계/실제 형성의 15분·30분·1시간 경로, 확정봉 보존,
가격 참조 카탈로그와 기존 진입 계획, 네이티브 기록/재생 일치를 포함한다.
관련 126개 검사가 통과했다. 과거 결과는 원본으로 보존하며 새 재생의 성과와 섞지 않는다.
CI·배포는 별도 상태다. 실모델 호출·주문·운영 DB 쓰기와 수익성 입증은 없다.
