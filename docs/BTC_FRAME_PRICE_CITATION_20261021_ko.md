# 시간봉 가격 경로 인용 수리 사전 검토

1. **유형·범위:** M3 판단 설명의 사실 인용 오류 수리다. 기준선은 `7ac18d4e`다.
   slot 5975140에서 1h/30m 경로의 now는 83123.1인데 SELECT 설명은 다른
   시간봉의 83133.6을 사용했다. 원시 계산과 손실 없는 입력 복원은 정확하다.
2. **작동 이유·반증:** 공통 SYSTEM 지침 한 곳에서 인용 경로의 실제 숫자와
   시각·시간봉·확정/형성 구분을 유지하도록 한다. 같은 입력 묶음의 close도
   같다고 가정하지 않는다. 실제 응답이 다시 다른 경로 값을 쓰면 효과 미입증이다.
3. **보완·충돌:** DRAFT/SELECT와 단일 판단이 공유하는 지침만 수정한다.
   changed_evidence.before는 recovery baseline이지 직전 확정봉 close가 아니다.
   경제·전략 판단, 위험/주문/TP/SL, 출력 schema, 모델 effort, 일정은 그대로다.
   출력 정규식 수리·새 거절 조건·추가 수치 필드는 만들지 않는다.
4. **검증:** 최소 시장 숫자 fixture로 1h/30m과 12h/1d/1w 차이,
   confirmed/forming/Mark 차이 및 baseline 차이를 보존한다. 기존/수정 SYSTEM을
   같은 모의 응답에 적용하여 user payload·schema·receipt·계획이 동일하고
   user 입력 크기 변화가 0인지 확인한다. 모의 응답은 모델 이해도 증거가 아니다.
   부모가 보존 SELECT 요청으로 실제 1회 진단한다. 수익·일반 오류율 검증은 아니다.
5. **유지·중단:** 숫자를 올바르게 인용했는지와 WAIT/OPEN 선택을 분리한다.
   해당 숫자 인용이 없으면 미관측/부분으로 기록한다. 추가 호출로 맞을 때까지
   튜닝하지 않는다. 실패해도 원문을 고치지 않고 보존한다.
6. **현재 결론:** 좁은 지침 수리와 오프라인 검증을 진행한다. 실제 응답·CI·배포·
   자연 관측은 별도 게이트이며 아직 성공으로 선언하지 않는다.
