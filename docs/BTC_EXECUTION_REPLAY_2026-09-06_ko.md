## 1. 이번에 검증할 것

사용자는 단타 모드의 구현·배포 상태를 확인하고 백테스트를 정교하게 구축·실행하도록 요청했습니다.
#665는 청산/확인 주기 정책 코드 배포이며 실제 단타 진입·빠른 실행 연결까지 완료한 것이 아닙니다.

이번 작업은 다음 세 층을 구분합니다.
1. 정수 수량·부분체결·수수료·실제 시각 펀딩·현금/미실현손익 원장의 합성 사건 회귀 테스트.
2. 실제 과거 OHLC·펀딩 자료의 연속성/확정 여부/내용 해시 검사.
3. 기존 추세 신호가 발생한 시점에서 동일 진입 조건으로 청산 후보를 비교하는 조건부 역사 실험.

3번은 **기존 main 전체 전략의 완전 재현이나 새 단타 진입 전략의 성과**가 아닙니다.

## 3. 사건 재생 계약

- 주문 제출·활성화·체결·TP·SL·수정·펀딩·평가에 정수 UTC millisecond 시각을 사용합니다.
- 진입과 주문 변경의 지연을 명시하고, 다음 가용 사건 이전에 소급 적용하지 않습니다.
- 부분 진입부터 기존 native SL 모델로 보호합니다. TP 계획은 진입 정산 후 동결합니다.
- 한 가격 사건의 체결 용량을 여러 주문이 중복 사용하지 못하게 합니다.
- passive limit의 단순 접촉은 체결로 보지 않고 trade-through 가정을 명시합니다.
- market/SL/time-exit에는 불리한 방향의 슬리피지와 taker 비용을 적용합니다.
- maker 비용은 별도 입력이며 음수 rebate도 명시적으로 다룹니다.
- SL 발동 후에는 TP/미체결 진입을 이어서 실행하지 않습니다. 남은 감축은 다음 가용 유동성으로 넘깁니다.
- 같은 가격 사건에서는 기존 SL/대기 청산을 우선하고, resting TP를 정산한 뒤 정책을 평가합니다.
  따라서 TP1이 완료된 사건의 정책은 그 체결을 알고 runner 자격을 판단합니다.
  새로 진입한 사건에서 신규 TP를 곧바로 체결시키지는 않습니다.
- 최초 실행 가격이 이미 SL을 넘었거나 TP1을 지나면 진입을 거절합니다.
  불가능한 native SL을 붙였다고 가정하며 무보호 진입하지 않습니다.
- 실제 펀딩 사건 시각의 당시 보유량과 rate를 사용합니다. rate 누락은 0이나 마지막 값으로 채우지 않습니다.
  누락 검사는 자료 로더의 책임입니다. 순수 엔진에 빈 사건 목록을 직접 넘기면 완전성을 알 수 없습니다.
- 동시각에는 펀딩을 가격/신규 진입보다 먼저 처리합니다. 이것은 고정된 재생 규약이며
  거래소 경계 밀리초의 실제 사건 순서를 입증하는 것은 아닙니다.
- 모든 출력 체결은 SIMULATED입니다. 주문 ACK·OHLC 접촉을 실제 CONFIRMED 체결로 바꾸지 않습니다.
- NAV = cash + 잔여 수량의 방향별 미실현손익으로 계산하고 사건마다 낙폭을 기록합니다.
- 자료 종료 시 남은 포지션은 평가손익으로 남깁니다. 종료 체결을 임의 생성하지 않습니다.
- 개별 캠페인의 명목 한도를 검사하되 다중 전략 증거금·공통 원장·청산 엔진 전체를 구현한 것으로 보지 않습니다.

## 5. 결과를 보기 전에 동결한 실험

실험 ID: scalp-exit-conditional-v1. 아래 수치는 연구 fixture이며 운영 기본값이나 최적값이 아닙니다.

- 구간: 2022-01-01부터 2026-01-01 UTC 직전까지.
- 신호: 기존 generate_signal을 4시간봉 확정 시각에 평가합니다.
  6개 시간대 모두 open_time + duration <= decision_time인 자료만 사용합니다.
  ATR EWM은 구간 앞 60봉 warmup으로 시드하므로 원본 시작부터 계산한 main과
  완전한 지표/신호 패리티를 주장하지 않습니다. 두 청산 후보에는 같은 입력을 사용합니다.
- 비교 단위: 각 신호에서 2시간 보유 상한을 가진 독립 캠페인.
  지연 청산을 관측할 추가 5분을 포함해 총 125분 자료가 있는 신호만 사용합니다.
- 초기 스탑: 같은 시점의 기존 compute_sl_price와 1h ATR/최근 10봉/MA35 구조 기준을 사용합니다.
- 진입: 시장가 모델, 고정 20 lots × 0.001 BTC. 최초 현금 10,000, 캠페인 명목 한도 10,000.
  실제 포트폴리오 사이징·기존 main 피라미딩을 재현한 것은 아닙니다.
- R은 제출 시 기준가격과 초기 SL의 거리로 고정합니다.
- TP1: 0.5R에서 50%, TP2: 1R에서 25%, 잔여 25%는 runner.
  이 추가 비율·가격은 첫 실험을 위한 가정이며 사용자 확정 운영값이 아닙니다.
- 기준 후보 tight_remainder: early/runner 추적 폭 모두 0.5R.
- 비교 후보 trend_runner: early 0.5R, 실제 TP1 완료와 상위 추세 허용 이후 runner 1.5R.
  TP1·진입·SL·수량·보유상한을 바꾸지 않고 runner 폭만 비교합니다.
- 배경 허용: 당시 확정된 1h·4h의 방향이 해당 보유 방향과 일치한 상태.
  신호 발생 뒤 매 5분 시점의 그때 가용 배경만 사용합니다.
- 관측 주기: 5분, entry/amend latency 0ms. 이는 이상화된 기준 사건 모델입니다.
- 비용: maker 0.0002, taker 0.00055, 시장가 슬리피지 5bps.
  같은 캠페인에 수수료·슬리피지 2배 스트레스를 별도로 적용합니다.
- 각 5m 봉의 O→H→L→C 및 O→L→H→C 두 경로를 별도로 재생합니다.
  봉 내부 시각 배분은 합성 규약일 뿐 실제 tick 시각이 아니며 엄밀한 수익 상·하한도 아닙니다.
- 유동성은 역사 자료에서 알 수 없으므로 역사 실행은 unlimited-model로 표시합니다.
  부분체결·용량 제한·지연은 별도의 결정론적 사건 fixture에서 검증합니다.

결과는 연도·방향·경로·비용 시나리오별 평균 net R, 손익 부호, TP1 빈도,
남은 물량, 캠페인 내부 MTM 낙폭과 paired 후보 차이로 보고합니다.
복리 계좌수익·Sharpe·전체 포트폴리오 MDD를 만들어내지 않습니다.
겹치는 캠페인은 독립 표본이 아니며 통계적 승격 근거로 사용하지 않습니다.

5m 자료의 합성 사건을 잘게 나눠 5초/10초 운영 성능을 검증했다고 주장하지 않습니다.
빠른 확인 주기·호가 대기열·mark 청산·실제 체결 패리티는 고해상도 자료와 전진 관측이 필요합니다.

펀딩 해석: 4h 경계 진입·2h 보유는 다음 8h 펀딩 경계를 넘지 않으며 시작시각 펀딩은 진입 전입니다.
따라서 이 단타 조건부 실험의 보유 중 펀딩은 0일 수밖에 없습니다. 이를 펀딩 비용 검증으로 포장하지 않습니다.
별도 ACCOUNTING_ONLY constant-exposure probe는 같은 기간의 실제 펀딩 timestamp/rate에
고정 0.02 BTC 롱/숏을 대입하여 재생 엔진의 합계와 독립 수식 합계를 비교합니다.
이는 가격 경로·스탑·청산·수익성을 평가하는 매매 전략이 아니며 mark price 대신 거래가격을 쓴다는 한계도 유지합니다.

## 7. 장기 시계열 계산 환경 방어

첫 실제 자료 실행은 수익을 계산하기 전에 NaN 지표로 중단됐습니다.
저장소 README에 기록돼 있던 Python 3.14.6/pandas 2.2.3/numpy 2.2.6 환경의
rolling 계산 문제를 32,768개 합성 값으로 재현했습니다. 같은 pandas/numpy의
기존 .venv-bt Python 3.12.12에서는 합성·실제 장기 시계열 모두 정상입니다.
운영 환경을 바꾸거나 계산식을 다른 지표로 교체하지 않고 문서의 .venv-bt를 사용합니다.

재생 입력 준비 단계는 warmup 이후 지표 전체의 유한성과 독립 SMA 수식 표본을 검사합니다.
NaN을 “신호 없음/0거래”로 바꾸지 않습니다. 32,768행 회귀와 실패 차단 테스트를 추가하고,
결과에 Python/pandas/numpy 버전을 남깁니다. 이 교정은 실험의 TP/SL/시점/비중 가정을 바꾸지 않습니다.

## 8. 실제 역사 실행 결과

사전등록 commit 0761230e, 계산 환경 차단 보완 a6317110으로 실행했습니다.
환경은 Python 3.12.12 / pandas 2.2.3 / numpy 2.2.6입니다.
입력 DB는 읽기 전용이며 전체 실행 동안 네트워크 접속을 차단했습니다.

- 기존 추세 신호 조건부 진입 463개, 두 경로×두 비용×두 청산 방식으로 3,704개 시나리오.
- 연도별 캠페인은 2022년 93개, 2023년 119개, 2024년 140개, 2025년 111개입니다.
- 기본 비용의 평균 net R: tight_remainder -0.168653, trend_runner -0.166910.
- 2배 비용의 평균 net R: tight_remainder -0.308008, trend_runner -0.305014.
- 기본 비용에서 TP1 완료는 약 19.01%입니다. 50% quota가 있다고 매번 익절되는 것은 아닙니다.
- 후보 차이는 기본 비용 약 +0.001743R에 그쳤고, 2022/2025년은 양수,
  2023/2024년은 음수입니다. 통계적으로 입증된 개선이라고 해석하지 않습니다.
- 두 OHLC 경로의 위 집계는 이번 fixture에서 동일했습니다. 실제 봉 내부 순서가
  중요하지 않다는 증거나 엄밀한 수익 상·하한이라는 뜻은 아닙니다.
- 종료 잔량·진입 거절은 이번 역사 시나리오에서 0건입니다.

R은 제출 시 기준가격과 초기 SL 차이에 고정 수량을 곱한 기준 위험입니다.
위 수치는 계좌 수익률이 아니며 기존 main/swing 실적이나 사용자 단타 전략 전체의 평가도 아닙니다.
기존 느린 추세 신호에 2시간 청산 규칙을 붙인 조건부 연구의 결과입니다.
다른 TP 거리나 진입 규칙을 탐색해 손실 결과를 바꾸지 않았습니다.

OHLC는 네 개의 불연속 가격 관측으로 재생하며 노드 사이를 선형 보간하지 않습니다.
