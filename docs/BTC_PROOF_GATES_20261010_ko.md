# BTC 독립 입증 계약

범위: M3 기록 정합성, M4 설명 근거, M5 성과 판정. 기준 코드는 PR #992의
`074e870d37405689d6f93b02d03e4e09850cd0b7`이다. 운영 정책·프롬프트·주문은 변경하지 않는다.

## 구현 전 고정한 판정

1. 재평가 등록: 원본 입력·제안·적용 직전/직후 메모리·영수증·core 검증 근거를
   같은 input/scenario/action에 연결한다. 별도 구현한 오라클로 등록, 중복 유지,
   용량 부족, 정확한 ACK 교체, 새 도달 조건의 거절과 무변경을 검사한다.
   적용 직전 상태가 없으면 다음 입력으로 대신하지 않고 INSUFFICIENT로 남긴다.
2. MA 인용: 원본 입력의 level ID, 시간프레임, MA 종류, 확정/형성 구분, 시각,
   가격 기준과 숫자를 인용 원문에 연결한다. 검증 범위는 주석 처리한 주장뿐이다.
   인용이 없는 자유서술은 UNASSESSED_PROSE이며, 전체 설명의 참이라고 하지 않는다.
3. 판단 연속성: WAIT→EXIT만으로 모순이라고 하지 않는다. 당시 새 시장·계좌 사실과
   변경 근거를 확인한다. 근거 없는 경우 미입증이며 새로운 매매 차단 조건은 만들지 않는다.
4. 수익성: 기존 profitability_gate를 재사용한다. 독립 OOS 종료 60건, forward 체결
   30건만 채우면 통과하는 것이 아니다. 비용·펀딩·실행·MTM·holdout·다중검정·
   paired CI·낙폭·2배 비용 기대값을 모두 충족해야 REVIEW_READY다.
   자동 배포는 없으며 미래 수익을 보장하지 않는다.

## 반증과 기록

- 정상 사례뿐 아니라 ID 바꿔치기, 가격/영수증 변조, 누락, 메모리 용량 경계,
  ACK 직전 새 도달을 독립적으로 검사한다. 합성 경우의 수를 실제 거래 수로 세지 않는다.
- 해시는 자료의 내부 연결과 변경 여부만 확인한다. 그 자체로 원본의 진정성을 보장하지 않는다.
- core_validated는 제공된 근거에 대한 전제다. 등록 검증기가 경제적 타당성을 다시 증명하지 않는다.
- 이미 검토한 손실 거래와 4개 A/B 입력은 개발 표본이며 holdout으로 재사용하지 않는다.
- 배포 후 실제 자료는 SQLite 읽기 전용 스냅샷과 당시 코드 manifest를 사용한다.
  최신 수집 시점 HEAD를 과거 판단의 코드 버전으로 대체하지 않는다.
- 자료 누락·검증 실패·미평가를 성공으로 합치지 않는다. 운영 변경 없이 검증 결과를 먼저 보고한다.

## 1차 관측 결과

2026-10-10 21:01:50 KST까지 배포 이후 15판단의 보존 요청/원응답 해시,
input/action/scenario 연결 및 당시 코드 manifest를 대조했다. 입력의 MA 이름표
240개가 canonical ID와 일치했다. 이는 모델 설명 240개의 정확성을 뜻하지 않는다.
두 OPEN은 후속 운영 packet에서 모두 미체결 취소로 확인됐다. 새 체결 표본은 0건이다.
두 영수증은 missing_metadata였고, 실제 등록 전이의 직전/직후 경계 자료가 없어
실거래 등록 전이는 INSUFFICIENT다. 해당 구간에는 비어 있지 않은 조건 등록 사례가 없다.

과거 15:55의 `12h forming MA10 83712.78`은 원본 요청과 수동 주석으로 연결해
명시된 인용 한 개를 VERIFIED로 판정했다. 같은 설명의 `4h/12h MA35 약 84054–84056`은
정확한 level/phase가 없어 MISSING_REFERENCE다. 당시 12h MA35는 확정 84385.4971,
형성 84287.5171이므로 어느 쪽도 해당 숫자 범위와 맞지 않는다. 자유서술 전체는 미평가다.

독립 검증기 43개 테스트 안에 선언된 유한 영역 576조합과 변조 반례를 포함했다.
기존 review memory 회귀와 합쳐 65개가 통과했다. 이 숫자는 실제 거래 수가 아니다.
운영 packet 46시나리오 중 기존44개/새2개이며 새2개는 미체결 취소다.
packet은 CONTINUE_CAPTURE이고 독립 회계·전체 생명주기 입증은 여전히 불충분하다.

## 남은 완료 조건

- 실제 등록 전이 경계가 보존되는지 확인한다. 관측 입력을 적용 직전 상태로 대체하지 않는다.
  현재 자료로 불가능하면 bounded before/after 감사기록 보완을 별도 실행 안전성 수정으로 검토한다.
- 설명의 MA 인용은 level 선택과 호스트 렌더링으로 오류를 제한할 수 있지만 출력 계약 변경이다.
  아직 운영에 반영하지 않았으며 무근거 자유서술 전체 정확성을 주장하지 않는다.
- 판단 변경에는 당시 사실 변화와 변경 근거가 필요하다. 단순 action 일치율은 대체 지표가 아니다.
- 기존 매일 09:10 연구 관측에서 새 근거와 실패를 이어서 보고한다. 추가 매매 배치나 자동 승격은 없다.
- M5 성과 게이트 미충족 상태에서는 완전 해결·손실 감소·수익 개선 완료로 표시하지 않는다.
