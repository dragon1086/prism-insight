# S2c-2 결과: 공식 목차 관계와 두 부분 문서

## 완료 범위

원문 목차의 literal 객체 생성과 explicit parent-child push를 검증하는 별도 순수 파서를 구현했습니다. 회사별 운영 예외, offset 허용 오차, JavaScript 실행은 없습니다. 기존 flat viewer API와 운영 수집·매매 코드는 변경하지 않았습니다.

검토한 main 4개는 동일한 원문 해시에서 삼성172/LG132/카카오155/HMM125, 합계584개 노드를 검증했습니다. 삼성생명 연결 주석 parent `11213317:24`는 직접 자식54개이며 마지막 `11213317:78`을 포함합니다. 단순 offset 포함 검사의 마지막 주석 누락을 피합니다. 새 검증군 성공으로 세지 않습니다.

## 리뷰·피드백

- 첫 설계 REJECT 후 필수 필드·epoch 봉인·sink·probe 한도를 구체화해 OKAY를 받았습니다.
- 첫 코드 리뷰의 간접 변경·함수/script 경계 문제를 실패 회귀로 고정하고, 실제 4개 원문의 고정 UI postlude와 선언·호출 경계를 검증하도록 보완했습니다.
- 두 번째 리뷰에서 전역 token/statement 제한 우회와 변수 문자열 timer가 발견됐습니다. 공유 누적 예산을 append 전에 검사하고 Match 목록·중복 token화를 제거했습니다. 변수 callback 예외는 관측된 shim script 전체 일치만 허용합니다.
- 백만 세미콜론 반례는 이제 VIEWER_TREE_LIMIT로 거절합니다. 독립 검토 실행에서는 약0.177초, peak RSS57.8MiB였으며 이전 약227MiB보다 줄었습니다. 이 수치는 해당 OS의 별도 실행 관측값이지 모든 환경의 시간/RSS 보증은 아닙니다.
- 마지막 LOW 입력 타입 지적도 RED→GREEN으로 수정했습니다. graph112개, 관련 통합364개가 통과했습니다. root probe15개와 기존 fixture68개도 별도 통과했습니다. 묶음에는 중복이 있으므로 합산하지 않습니다.
- 최종 연구 입력 CI 목록 전체는 1,677개가 통과했습니다(기존 의존성 경고4개). 기존 KR BUY snapshot 실패는 이 목록과 별도이며 아직 수정하지 않았습니다.
- 최종 독립 리뷰 APPROVE 뒤에만 실제 두 자식 probe를 실행했습니다. Python 전용 타입 검사·전체 브라우저 동작 검증은 주장하지 않습니다.

## 실제 취득과 같은 본문 대조

공식 graph의 URL로 최대2 GET·개별2MiB·합계4MiB·60초·재시도 없음 조건에서 취득했습니다. **실제2회, 총751,558바이트, 두 응답 모두 EOF까지 성공**했습니다. 추가 네트워크 없이 strict replay로 요청 순서와 바이트를 대조했습니다.

- `15-3. 보험계약자산 및 보험계약부채 (연결)`: 742,428바이트. SHA-256 `03350ac2ddcb5728a93e25a1eb35552decd5df785b1f2eba667ec2ba701d24e4`.
- `37. 사업결합 (연결)`: 9,130바이트. SHA-256 `fba2d80cb1375ecacf25018506366da0a8f191d12609f7d3b12b22eb17c4113d`.

취득 전에 고정한 부모 원문의 해당 구간과 비교했습니다. 첫 구간131개 단위/130개 표, 마지막15개 단위/14개 표의 텍스트·셀 값·병합·grid를 포함한 canonical hash가 각각 일치했습니다. 이는 HTML raw bytes 전체 동일성이나 금융 사실 gold가 아니라 같은 부분의 구조·텍스트 비교입니다.

- 첫 구간 canonical SHA: `2780ea3f13c21370cadd91a2b724e721302355bd63435c07242058882c88cfcc`.
- 마지막 구간 canonical SHA: `a81e8bc80af231b27ee1b02c7a529e39f0925844ca5af8d532ebdb0704a9cfd8`.
- 자식 자체의 원문 위치11,125개/76개를 DOM과 대조해 오류0건입니다. 원문은 private fixture로만 보존하고 첨부·커밋하지 않습니다.

## 남은 실제 문제

두 자식 본문은 부모 제목 없이 각각의 주석 제목으로 시작합니다. 기존 HTML 파서는 이를75개/6개 record로 읽지만 **모든 scope가 unknown**입니다. 그러므로 지금 결과를 운영 보고서에서 연결 주석으로 사용하면 안 됩니다.

다음 단계는 검증된 공식 graph와 자식의 명시적 제목을 함께 확인해 외부 부모 scope의 출처를 보존하는 어댑터 설계입니다. 부모 제목을 HTML 앞에 끼워 넣거나 원문 XPath를 바꾸지 않습니다. 이후 호출 예산 내 부분 선택·누락 표시, 단위·조건 연결, 최종6,000바이트 필수 근거 검증이 필요합니다. 54개 전체를 기존28호출로 모두 취득했다고 주장하지 않습니다.

신규 파일은 `prism_core/dart_viewer_tree.py`, `tools/probe_dart_note_children.py`와 관련 테스트2개이며, CI에 연결했습니다. 기존 literal 검증·private recorder·취소 정리 helper를 재사용했습니다. 머지·배포와 한국·미국 범용성 승인은 여전히 보류합니다.
