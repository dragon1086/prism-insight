## 복구 범위와 권한

-15m는 현재 판단과 진입 시점·반응의 보조 근거다.1h 방향·30m 기본 판단의 기존 역할을 유지한다.
- 실제 모델 입력,15m 구조 요약, timing_only 역할, 공통 지시문과 숫자 인용 근거를 맞춘다.
-5m 분석은 현재 판단에서 제외한다.5분 실행 주기는 분석 봉의 시간축과 별개다.
- 수치 가격 후보·원래 목표·위험 예산·레버리지·정산·복구 허가는 기존 계약을 유지한다.
  15m만 바뀌었다는 이유로 복구 허가를 새로 만들거나15m 목표·손절로 자동 전환하지 않는다.
- 설명 인용 카탈로그에15m를 복원하더라도 기존 가격 후보 산술에는 새15m 기준을 섞지 않는다.
  원문·기존 계약·저장 테이프·수치 코덱의 과거 자료는 변경하지 않는다.

## 검증과 보고

무포지션·보유·미체결의 실제 조립 입력에서15m를 확인하고5m 제외·원본 불변·입력100KB 한도·
기존 가격 후보 불변·복구/목표 권한 불변·15m 인용 검증을 함께 시험한다. 시스템 지시문 pin은
의도적으로 바꾼 MA_STRUCTURE_PROMPT만 갱신하며 나머지 매매 지시문은 유지한다.

실제 손실 진입·보유와 기존 수익 개발 입력의 주문 없는 재검토는 제한된 기능 검증이다.
동일 위험의 성과 비교·M5 입증·자동 전략 승격으로 해석하지 않는다. 구현·로컬 검증·정확한head의
전체CI·배포·첫 정기 실행·새15m 경로 관측을 구분한다.

5분봉 기준이 섞였던 모범답안은 철회했다. 최소15m 기준으로 다시 작성해야 하며,
15m가 제외된 과거 고정3일 기준선은 당시 정책의 기록으로 보존한다.
