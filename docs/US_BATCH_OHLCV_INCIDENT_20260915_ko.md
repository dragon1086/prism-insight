# 미국 오후 배치 장애: OHLCV 열 구조

## 원인과 책임

2026-09-15 03:35:37 KST 미국 오후 배치가 스크리닝에서 중단되었다.
예외는 `AttributeError: 'DataFrame' object has no attribute 'tolist'`다.
PR #726에서 추가하고 #727에서도 유지한 관측 고점 추출이 단일 High Series를
가정했으나, 운영 yfinance는 단일 종목도 Price/Ticker MultiIndex를 반환했다.
따라서 High 선택 결과가 DataFrame이 되어 실패했다. 이전 검증이 평탄한 테스트
데이터와 일부 AST 단위 실행에 치우쳐 실제 공급자 구조를 통과시키지 않은 누락이다.

## 수정·검증 계획

1. 단일/다중 열 구조의 실제 회귀를 먼저 재현한다.
2. US 단일 종목 OHLCV 공급자 경계에서 요청 종목의 열을 명시적으로 선택하여 평탄화한다.
   열 순서가 반대여도 처리하되, 중복/모호한 구조나 다른 종목을 첫 열로 추측하지 않는다.
3. KR/US 관측 고점 소비자도 같은 정규화를 사용해 대체 공급자의 중복·다중 열에서
   배치 전체가 실패하지 않도록 방어한다. 결측은 결측이며 가공 손익비를 되살리지 않는다.
4. 평탄한 데이터와 MultiIndex 데이터가 같은 결과를 내는지, US 오전/오후 실제 배치
   함수부터 JSON 출력까지 오프라인 통합 검증한다. 함수 몸통만 추출한 테스트로 대체하지 않는다.
5. CI 및 서버 Python 검증 후 배포한다. 실시간 시장 데이터 조회는 읽기 전용이며
   매수·매도·채널 발송을 유발하는 운영 배치 재실행과 구분한다.

## 회귀 방지 계약

기능 수정 시 공급자 응답의 현실적인 구조(평탄 열/MultiIndex/빈 응답/중복 열),
변경 함수의 호출자와 결과 소비자, 오전·오후 모드를 검증한다. 스크리닝/데이터
경계를 수정할 때는 실제 모듈을 불러오는 통합 테스트를 필수 CI에 포함한다.
서버 스모크도 수행하며, 단위 테스트 숫자만으로 운영 정상화를 단정하지 않는다.

참고: yfinance 공식 download API의 multi_level_index 기본값은 True다.
https://ranaroussi.github.io/yfinance/reference/api/yfinance.download.html

## 검증 기록

- 운영 서버에서 CRWD 10일 자료를 읽기 전용으로 조회하여 2단계 열/High DataFrame을
  확인하고, 기존 함수에서 동일 AttributeError를 직접 재현했다.
- 실제 US 배치 통합 14개: 오전·오후, Price/Ticker 양방향, 다중 종목 중 정확한
  종목 선택, 평탄 데이터와 JSON 결과 동일성, 잘못된 종목/중복 열을 검증했다.
- 공통 정규화 8개 및 실제 KR 소비자 3개를 합쳐 25개 통과.
- 기존 스크리닝·오케스트레이터·provider·약세장 회귀 75개 통과.
- 신규 핵심 함수·테스트 Ruff, 함수 Bandit, 변경 Python 구문 검증을 수행한다.
- 통합 테스트의 관측 출력은 임시 디렉터리로 격리하고 네트워크 연결을 차단한다.
