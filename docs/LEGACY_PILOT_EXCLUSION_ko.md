# 기존 피라미딩과 50% 파일럿의 경계

기존 피라미딩은 정상 진입 단위를 추가하는 경로입니다. 이를 50% 파일럿에 그대로
적용하면 남은 50%가 아니라 정상 100%를 더 요청할 수 있으므로 경로를 분리합니다.

## 차단 대상

- 저장된 시나리오에 명시된 50% 파일럿
- `split-pilot-v1` 소유권이 명시된 포지션
- 소유권·정책·비중을 명시했지만 지원되지 않거나 잘못된 값인 포지션

오래된 일반 포지션처럼 관련 메타데이터가 없거나, 정상 100%가 명시된 경우에는
기존 시장 국면·수익률·행 수·슬롯·독립 매수 게이트를 유지합니다.
과거 파일럿을 새 승급 시스템에 자동으로 편입하지 않습니다.

## 검사 지점

한국·미국의 사전 검사, 배치 매수 게이트, 원장 행 삽입 직전과 주문 가격 검증
콜백에서 저장된 소유권을 다시 확인합니다. 주문 콜백은 변경 가능한 현재 계좌가
아니라 주문 준비 시점에 확정된 계좌 식별자를 사용합니다.
한국의 기존 pending 경로도 같은 검사를 추가하되 활성화하지 않습니다.

## 보장하지 않는 것

기존 asyncio 잠금은 동일 에이전트의 읽기·삽입을 직렬화합니다. 프로세스 사이에서
소유권 읽기부터 실제 주문 제출까지 원자적으로 묶는 전역 잠금은 아닙니다.
새 SHADOW 원장의 CAS와 기존 주문 경로의 방어 검사를 혼동하지 않습니다.

이 변경은 일반 피라미딩이 파일럿에 끼어드는 것을 막는 방어입니다.
실매매의 자동 50→100 승급, 과거 원장 변환, 손절 규칙 완화는 활성화하지 않습니다.
계좌 예산이 없는 파일럿의 전략 판단과 브로커 집행을 분리하는 작업은 별도입니다.
