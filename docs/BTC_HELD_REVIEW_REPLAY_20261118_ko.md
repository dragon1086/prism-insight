# BTC 핵심 진입 표본과 보유 관리 일정 분리 (M2)

이전 고정7구간/15시점 샘플은 두 손실 거래의 보유 중 AI판단이0회였다. 두 번째는166분 보유했고, 수익거래도첫추가판단까지약330분이었다. 이는 최소핵심시점 샘플의 성과이며 운영의 지속 보유판단까지 재현한 성적이 아니다. 기존−8.62348USDT 결과는 그대로 보존하고 다른 일정의 결과를 로직개선율로 비교하지 않는다.

`run_replay`/`contract_for`에 명시적인 `holding_review_slots_ms`를 추가했다. 진입시점 목록을 반드시 함께 지정하며 두 목록을 계약에 고정한다. native시장·보호·정산을 해당시각까지 진행한 뒤 오프라인 거래소에 실제 체결 잔량이 있을 때만 추가관리 판단을한다. 무포지션이면새진입을만들지않고건너뛴다. 대기주문만있는경우의추가AI관리까지제공하는기능은아니다. 기본(None)경로는기존일정과동일하다. 운영의5분판단주기나전략·위험·시간프레임·보호규칙을변경하지않는다.

계약은추가관리시점과조건을기록하며보고서는실제로실행한관리시점/무포지션으로생략한시점/미처리후보시점을구분한다. 생략을MISSING이나AI실행으로계산하지않는다. 모델실패·예산도달등으로중단되면전체검증완료로사용하지않는다. 명시적관리일정도표본이므로`full_live_review_cadence=False`를기록한다.

실제runtime를쓰는모의통합검사에서진입표본사이관리슬롯의EXIT가원래포지션을청산하며,다음무포지션관리슬롯에서는새진입이없고호출이없어야한다. 고정응답재생의결과해시가같아야한다. 잘못된/중복/범위밖/정렬오류/불린시점은실행전에차단한다. 기존기본경로검사도유지한다.

새사용자요청에따른비교주기2는최대48회로고정하고이전48회장부는봉인한다. 첫단계는현재배포본의측정기준선교정이며경제적후보와의양팔비교를시작한것이아니다. 원경로에매30분보유관리를더하면32판단/최악64HTTP지만새응답으로보유시간은변한다. 새주기의48회보다많이필요하면불완전자료로표시하고전구간수익성검증완료·전승·전략승격을주장하지않는다. 미래가격극값을입력이나확정익절로쓰지않으며강제청산/HTTP재시도/봉인장부재개는없다.
