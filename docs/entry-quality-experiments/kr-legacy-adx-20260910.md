## 비교와 불확실성

각 book의 원본 대상 trigger 진입 날짜를 성과와 무관하게 정렬해 70/30 경계를
고정합니다. 학습은 경계 30일 전까지 진입하고 청산한 기록만 포함합니다.
검증 구간은 경계부터이며 30일 embargo와 청산 purge를 표시합니다.
이는 과거 재구성 진단이지 독립 prospective holdout이 아닙니다.

고정 원본 진입·청산을 바꾸지 않는 retain/drop 비교만 수행합니다. 제외한 진입은
수익률 0, 유지한 진입은 원본 기록 수익률로 둔 대응 차이를 계산합니다.
재투자·대체 후보·슬롯 점유·포트폴리오 손익은 계산하지 않습니다.
각 book 전체와 학습/검증, trigger 층별 결과를 함께 보고하며 최적 규칙을 선택하지 않습니다.
최소 30행과 20개 진입 날짜를 모두 충족할 때 날짜 cluster bootstrap 1000회,
seed=20260910, H1~H4 family 4의 Bonferroni 98.75% 탐색 구간을 냅니다.
미달이면 구간은 null입니다. 층별 결과를 새로운 유의성 주장으로 쓰지 않습니다.
승자 보존율, 손실 기록 제거율, 최고 승자 1행 제거 후 차이와 비용 편도 0/10/30bps
민감도를 표시합니다. 비용은 기록에 이미 포함됐는지 모르므로 추가 비용 stress이며
실제 수수료를 뜻하지 않습니다. 결측을 통과/탈락/수익률 0으로 채우지 않습니다.

결과는 운영 ADX 개선/수익성 검증이 아닙니다. 자동 SHADOW/LIVE 승격은 금지하며
