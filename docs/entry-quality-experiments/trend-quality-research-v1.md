# 추세 강도·방향·지속성 검증 사전 등록 v1

상태: **연구 전용. LIVE 신호 변경 없음.** 등록일 2026-09-09 KST.
목표는 독자적 지표 이름을 만드는 것이 아니라, 현재 돌파형 후보에서 어떤 시장·종목
상태가 기존 진입·청산 방식과 맞는지 검증하는 것입니다.

## 고정 가설

동일한 기준 후보에서 다음 4개 가설과 현행 기준군을 비교합니다. 결과를 본 뒤 임계값을
최적화하지 않습니다. 현재 scope는 KR/US 갭 상승 모멘텀·일중 상승률 트리거입니다.

- H1 강도: Wilder ADX14 ≥20일 때 유지.
- H2 강도+방향: ADX14 ≥25이며 +DI14 > −DI14일 때 유지.
- H3 초기 강화: 최근 완료 3개 봉의 ADX가 연속 상승하며 +DI14 > −DI14일 때 유지.
- H4 지속성: 20개 변화 구간의 효율비율 `abs(C_t−C_t−20) / sum(abs(ΔC)) ≥0.30`, 순가격 변화 양수일 때 유지.

20·25는 널리 쓰이는 ADX 해석값이지만 우리 전략의 최적값이라는 뜻은 아닙니다.
ER20의 0.30 역시 고정된 연구 가설입니다. 4개 모두 각각 하나의 시험으로 집계하며
시장·오전/오후·레짐·정책 버전별로 나눕니다. 횡보 매집·반등 트리거에 일괄 적용하지 않습니다.

기존 입력 재사용 수집기는 최근 완료60봉을 보존합니다. 이 유한한 입력 창에서 Wilder
초기값을 계산하므로 더 긴 history를 쓰는 차트와 ADX 수치가 완전히 같다고 가정하지 않습니다.
입력 창·초기값 변경도 버전과 검증을 필요로 합니다.

첫 구현은 **일봉**입니다. Threads의 15분봉 경험이나 '크로스한 날 고가 돌파' 규칙을
동일하게 재현했다고 표현하지 않습니다. 후자는 시간대·크로스 정의·대기 기간·종가
확인 조건과 장중 데이터가 별도로 고정돼야 새 trial로 검토할 수 있습니다.

## 입력과 누수 방지

- 정확한 decision_ref, market, session, session_date, regime, policy_version와 판단 as-of를 요구합니다.
- OHLCV는 판단 당시 알려진 완료 봉만 사용하며 close_at에는 시간대가 필요합니다.
- 미래/미완료 봉, 중복·역순 timestamp, 비유한 숫자, 가격 고저 모순을 허용하지 않습니다.
- 조정주가·기업행위와 세션 누락 검증 정보를 명시합니다. 현재 조회한 조정 일봉을 과거
  판단 시점의 immutable snapshot인 것처럼 주입하지 않습니다.
- 결측은 MISSING/INPUT_UNAVAILABLE이며 통과나 탈락으로 바꾸지 않습니다.
- 관측이 판단보다 늦으면 거절합니다. 관측 후4시간 초과 또는 마지막 완료 일봉이7일
  초과된 경우도 연구 입력에서 제외합니다. 장기 휴장 등 정상 사례도 보수적으로 제외될
  수 있으며 coverage에 보고합니다. 관측 benchmark는 공식 거래일 달력의 대체 증거가 아닙니다.
- snapshot hash, 원본 Packet ID, registry hash를 보존합니다.
- 신규 관측 수집은 기본 ON이며 `TREND_RESEARCH_CAPTURE_ENABLED=false`로 끌 수 있습니다.
  기존에 이미 조회한 종목/지수 frame만 재사용하고 추가 네트워크·LLM 호출을 하지 않습니다.
  입력은 별도 research_context에만 보존하며 프롬프트·점수·주문 조건에는 넣지 않습니다.
- 후보 가격 outcome, 전략 원장 청산 결과, 브로커 집행 증거를 분리합니다.
  전략 원장 성과는 브로커 거절·미체결 여부로 제외하지 않습니다.

## 비교·통계 방법

- 첫 단계는 기존 원장 결과에 대한 **짝지은 유지/제외 진단**입니다. 새 매수·매도
  에이전트를 재실행한 종단 전략 백테스트가 아닙니다. 신규 진입 가격 변화나 비워진
  슬롯의 재투자 효과를 안다고 주장하지 않습니다.
- 시간순 앞 70%와 뒤 30%를 나누며, 경계에는 30 calendar-day embargo를 적용합니다.
- 학습 쪽 거래는 실제 원장 청산 시각이 holdout 경계 이전이어야 합니다. 판단 시각에
  보유시간을 더해 청산 시각을 추정하지 않습니다. 정확한 시각이 없으면 보수적으로 제외합니다.
- 시장·세션·레짐·버전별 표본을 합쳐 하나의 승률만 보지 않습니다.
- 충분한 표본에서 날짜 단위 block bootstrap 1,000회, 고정 seed를 사용합니다.
  4가설 family의 98.75% Bonferroni 보정 구간을 탐색용으로 표시합니다. 구간이 있다고
  선택 편향·시장 변화가 모두 제거되는 것은 아닙니다. 셀 간 최종 승자 선택에는 추가 검토가 필요합니다.
- 각 비교의 최소 표본 30개·20개 날짜 미달이면 효과 추정과 승격 판단을 하지 않습니다.
- 손실 제외 비율과 함께 승자 보존, 최고 수익 한 건 제거, 기준군 대비 놓친 수익을 보고합니다.
- 단순 거래 수익률 합으로 포트폴리오 MDD나 자본 수익률을 만들지 않습니다. 비용·재투자·슬롯
  경로까지 비교하려면 뒤의 분할 원장 기반 종단 실험이 필요합니다.
- 같은 후보 수익률로 신호 선택 후 그 후보를 독립 검증이라고 부르지 않습니다.

## 검증 계층

1. 수학 검증: Wilder seed·평활, DI 방향, ER 경계, 상승/하락/횡보 synthetic oracle.
2. 시점 검증: prefix invariance, 미완료·미래 봉·gap·기업행위 결측 반례.
3. 분석 검증: 정확한 join, 입력 순서 불변, fill 상태 불변, holdout purge, 다중시험 기록.
4. 실제 자료 감사: 현재 Packet에 시점 고정 지표 입력이 있는지 먼저 검사합니다.
5. 전략 검증: 충분한 prospective 입력을 확보한 뒤 별도 가상 원장의 동일 BUY/SELL 정책으로 비교합니다.

합성 데이터 테스트 통과는 수익성 증명이 아닙니다. 유효한 역사 입력이 없으면 결과를
INPUT_UNAVAILABLE로 보고하고 새 신호를 운영에 적용하지 않습니다.
