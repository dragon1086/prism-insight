# KR 오전·오후 배치 유상 권리락 스냅샷 복구

## 장애

2026-09-22 오전 09:30 및 오후 14:46 정규 배치가 종목 선정 전에 모두 중단됐다.
오류는 `KIS master previous-volume/session mismatch; cap date unverified`이며 ChatGPT OAuth
인증 또는 보고서 생성 오류가 아니다. 두 실행 모두 종목 0개로 종료되어 보고서·추적·주문은
실행되지 않았다.

## 원인과 관측 근거

전체 2,678개 비교 대상 중 상지건설(042940) 한 종목만 불일치했다.

- 마스터 권리락/액면/증자 플래그: `01/00/01`
  (KIS 공식 헤더 정의상 권리락/액면변경 없음/유상증자)
- 원시 2026-09-21 일봉: O/H/L/C 5,780/6,090/5,700/5,900원,
  거래량 54,737주, 거래대금 321,782,045원
- 마스터 전일 거래량 52,695주, 기준가 5,680원
- 독립 현재가 조회 기준가 5,680원
- 조정 일봉: 5,564/5,862/5,487/5,680원, 거래량 56,857주,
  거래대금 321,782,045원

공식 수치가 엄격한 양방향 정수 항등식을 만족한다.
`floor(54,737 × 5,680 / 5,900) = 52,695`,
`floor(54,737 × 5,900 / 5,680) = 56,857`이다.
캐시 원시 일봉과 새로 조회한 원시 일봉도 정확히 같았다.

기존 코드는 같은 검산을 무상증자 권리락(`01/00/02`)에만 실행하고 유상증자
권리락(`01/00/01`)은 실행하지 않았다. 따라서 검산 가능한 정상 데이터를 허용 목록
앞에서 차단했다.

## 수정

유상·무상 권리락 두 플래그만 엄격한 기존 검산 경로에 넣었다. 원시 캐시는 바꾸지 않고,
비교용 전일 시세만 공식 조정 일봉으로 교체한다. 유형별 provenance를 구분한다.

허용 오차를 늘리거나 종목을 제외하지 않았다. 기준가, 날짜, 새 원시 일봉, 거래량 양방향
항등식, 거래대금 보존, 조정 VWAP의 고가·저가 범위 검사는 그대로다. 지원하지 않는 플래그,
누락·비정상 시세와 한도 초과는 계속 전체 스냅샷을 실패시킨다.

## 검증 및 운영 경계

- 스냅샷·권리락·정밀도 회귀 83개 통과
- KR/US provider-shape 포함 결합 회귀 110개 통과
- Ruff, Python 구문, diff 검사 통과
- 배포 후 운영 Python import, 읽기 전용 실제 스냅샷 생성, cron 불변을 확인한다.
- 사용자의 수동 재실행은 주문 중복을 피하기 위해 주문·추적 단계를 차단한 오후 기준
  스크리닝→보고서→PDF→발송 경로로 실행한다. 실제 주문 재실행은 하지 않는다.
