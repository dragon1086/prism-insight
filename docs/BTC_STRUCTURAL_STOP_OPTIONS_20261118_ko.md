# BTC 기존 손절 대안 노출 복구 (M4 입력 품질)

1. 유형/기준선: 새 손절 규칙이 아닌 입력 후보의 손실을 고친다. 기준선main a40b95fa의 BASE DRAFT·계산·실행을 유지한다. 별도 초안 완화안 #1399는 채택하지 않는다. 동일 손실 반례2곳에서 기존 BASE도 같은 SHORT·형성 중 고점 손절을 선택했다.
2. 작동 이유/반증: 내부는 진입방식별2개 구조적 손절 대안을 계산했지만 최종 메뉴는 방식별1개만 남겼다. 06:45의보이는68428.9(FORMING)뒤에는68888.2(CONFIRMED),12:45의67390.6뒤에는67733.0이있고 모두비용검사예시가있었다. 대안을 함께 보여주면 LLM이 원래 시간축·무효화를 비교할 수 있다. 확정 가격이 더 좋은 손절이나 더 높은 승률이라는 뜻은 아니다. 선택이 그대로거나 기존 수익 입력을 잃거나 비용·낙폭이 악화하면 개선 가설은 반증이다.
3. 호환성: 내부에 이미 있는 방식별최대2대안만보이고 DRAFT/SELECT·목표·가격생성·계산·수량·비용·회복·수렴·보호권한은변경하지않는다. 기존가격/ID도유지한다. 모델메뉴최대12개, 출력후보최대2/실제선택1개, 메뉴12KB/전체입력100KB한도유지. 예시는계획당1개만보여문맥을제한하며실제confidence/비중/청산비중은원래스키마에서선택하고호스트가다시계산한다. 이미체결된손절을넓히지않으며최초신규입력에만작용한다.
4. 비교: 알려진개발손실2입력과기존수익1입력에서원문입력·가격·계좌상태·기준지시문을동일하게고정하고메뉴/동적schema변경만검사한다. 기준응답은정확요청동일성으로만재사용한다. 후보모델최대6신규HTTP로현재알려진41과합최대47<=기존48한도다. 모의와독립frozen이먼저이며실제도독립frozen으로검증한다. 가격이닿은결과를실제체결/수익으로바꾸지않는다.
5. 진단/중단: 모든기존계획가격보존,두stop변형노출,예시의실제호스트통과,12KB한도,스타일다양성/원입력불변을확인한다. 실패/결측/예산초과는중단하며유료재시도하지않는다. 알려진수익사례는회귀방지용개발반례일뿐holdout이아니다. 이기능시험으로승률/전체수익개선이나M5통과를주장하지않는다.
6. 결정: 사전등록후보. #1399문구완화는경제적효과가확인되지않아미배포유지하고, 이수정은다른한계층(기존입력선택지보존)만시험한다. 비용예시는확률/지원강도/실행허가가아니다. 새전략/SHADOW/LIVE/실자금/위험기본값변경은없다. 적격계획이늘어도채택/배포/첫정기실행/수익성입증은분리한다.

로컬: 새 기존대안노출/예시예산 검사2개가 변경 전 실패했다. 출력 예시 수에 맞게 원 호스트 검증을 유지했으며 이전 합법 가격/ID를 지웠는지 함께 검사한다. 실제 손실 입력2곳에서 메뉴는8계획·각7,521/7,831바이트로12KB안이며 형성/확정 CURRENT 두 대안이 모두 노출된다. 가격 생성과 판단 지시문은 그대로다.
