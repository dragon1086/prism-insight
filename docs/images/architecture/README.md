# 파이프라인 아키텍처 이미지 관리 안내

이 디렉터리의 PNG 14장은 일반 투자자가 PRISM-INSIGHT의 흐름을 쉽게
이해하도록 만든 최종 인포그래픽입니다. 모두 밝은 배경의 16:9
Full HD(1920×1080) 래스터 이미지이며, 단순 슬라이드 도형이 아니라 차트,
계기판, 필터, 관문, 보호 장치 같은 시각적 비유를 이용해 구성했습니다.

## 사실 관계의 기준

그림의 문구와 수치는 다음 순서로 검증합니다.

1. 실제 실행 코드와 설정
2. 에이전트 프롬프트
3. `tools/generate_pipeline_architecture_pngs.py`의 검증용 텍스트 명세
4. `docs/PIPELINE_ARCHITECTURE_ko.md`의 본문 설명

이미지 모델은 시각 구성에 사용했으며, 상태 이름·임계값·가중치·실행
여부처럼 동작을 단정하는 내용은 코드와 대조해 수정했습니다. 그림은 교육용
설명 자료이며 투자 수익이나 자동 학습을 보장하지 않습니다.

## 수정 절차

1. 코드와 프롬프트에서 근거를 다시 확인합니다.
2. 검증용 텍스트 명세와 문서 본문을 먼저 고칩니다.
3. 이미지 모델로 기존 그림의 구도와 시각 품질을 유지하며 필요한 부분만
   수정합니다.
4. 최종 PNG를 1920×1080으로 저장하고 작은 글자까지 확대 검수합니다.
5. `manifest.json`의 이미지 SHA-256과 문구 명세 해시를 갱신합니다.
6. `pytest -q tests/test_pipeline_architecture_pngs.py`를 실행합니다.

`tools/generate_pipeline_architecture_pngs.py`는 사실 관계를 빠르게 검토하기
위한 저충실도 초안 생성기입니다. 반드시 `--output-dir`로 별도 임시
디렉터리를 지정해야 하며, 이 디렉터리의 최종 이미지를 생성하거나
덮어쓰는 용도로 사용하지 않습니다.

`manifest.json`은 확대 검수를 마친 이미지의 픽셀과 당시의 문구 명세를
한 쌍으로 고정합니다. 그림이나 검증용 문구가 바뀌면 테스트가 실패하므로,
코드 근거를 다시 확인하고 사람의 시각 검수를 거친 뒤에만 해시를
갱신해야 합니다.
