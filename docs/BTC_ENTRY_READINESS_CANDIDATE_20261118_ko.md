# BTC 현재 진입 근거 해석 후보 (M4, 미배포)

1. 경제적 판단 프레이밍 변경이다. M2.6 측정 수리 #1398 위에서 기준/후보의 동일44판단 일정을 비교한다. 기준선의 가격·목표·선택·보유·복구 코드는 유지한다.
2. 가설: 신규 진입 초안이 현재 추세 지속을 반전 확인과 혼동하거나, 직전 봉보다 적은 거래량·근처 저점/고점·R 투영 목표를 각각 독립 차단으로 해석하면 유효한 진행을 놓칠 수 있다. 현재 진행·실제 반대 반응을 종합해 판단하게 한다. 관망 사유가 실제 위험이었거나 신규 거래 손실·비용·낙폭이 증가하면 반증이다.
3. 적용 경로: scenario_calculated_review의 prepared_entry_plans를 실제 제공하는 신규 진입 DRAFT에만 적용한다. 메뉴 없음·보유·회복 첫 관찰·SELECT의 기존 지시문은 바이트 동일하게 보존한다. 15분은 타이밍이며30분/1시간의 구조·근거를 대체하지 않는다. 후보 예시는 근거·확률·허가가 아니다. 회복·수렴·원 목표·비용1.2·총 신규 위험30%·하드스톱·10배는 변경하지 않는다.
4. 미래 경로를 모델에 주지 않고 원7구간 경계와44판단을 동결한다. 같은 합성 회복계좌1만USDT·native 주문/정산·비용·OHLC 경로로 비교하고, 사전 모의 및 독립 frozen을 수행한다. 상승/횡보·미체결·반전 손절 반례가 없으면 전역적 개선을 주장하지 않는다. M5 기준을 바꾸지 않는다.
5. 승률·완료건수·승리/손실 평균 수익률·손익비, 비용 차감 순손익·최대낙폭·손절비용, 진입 시각·보유로 포착한 구간을 함께 본다. 진입 증가만으로 채택하지 않는다. 기준선 열화·자료 결측·계약 또는 실행 이상이면 기존 유지다. 표본이 부족하면 개발 신호만 남긴다.
6. 사전등록 후보다. 유료 호출 한도 선택 응답 전에는 실제 모델 비교하지 않는다. CI·실제 비교·데모 반영·첫 정기 실행·수익성 입증은 분리한다. 새 SHADOW/LIVE·실자금·위험 기본값 변경은 없다.

문장 일관성: 기존 FLAT_ENTRY_PROMPT의 habitual extra close/crossover/retest 금지와 MA_STRUCTURE_PROMPT의 거래량 단독 veto 금지를 신규 DRAFT의 readiness 해석에 연결한다. 목표 R 투영을 시장 지지의 증거로 바꾸지 않으며, 도달 가능성과 경로의 반대 근거는 계속 판단한다. 모든 후보 생성과 WAIT는 호스트 검증을 거친다.

## 로컬 검증

신규 초안 실제 요청 범위 검사6개가 변경 전 실패했다. 후보에서는 같은 LONG/SHORT OPEN·WAIT·동료 후보 선택과 별도 frozen이 유지되며, 메뉴가 없는 경로의 원 DRAFT와 SELECT는 그대로다. 새 준비된 진입 지시문을 별도로 해시 고정하고 replay 계약에도 해당 분기 해시를 기록한다. 관련176개 검사를 통과했다. 이 결과는 모델 행동·수익성 개선의 증거가 아니다.
