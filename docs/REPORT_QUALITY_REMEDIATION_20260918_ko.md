# 보고서 품질 보완: 문제 목록과 단계별 통과 조건

> 아래 초기 점검은 최초 발췌 수정 시점의 기록입니다. 후속 구현·검증 상태는 문서 마지막에 이어집니다.

## 판정

통합 실행 성공은 조사 품질의 합격을 뜻하지 않습니다. 최신 격리 실행의
MRNA·MU·SMCI 보고서와 기존 경쟁사 조사 감사 기록을 기준으로 정리했습니다.
현재 경쟁자료 prefetch는 운영 OFF이므로 아래 수집기 결함을 운영 초안의 직접
원인이라고 단정하지 않습니다. 기존 LLM 조사 경로와 개선 후보의 결함을 구분합니다.

## 우선순위별 문제와 원인

1. **경쟁 비교 누락/후퇴 (최우선)**
   - MU 최신 초안은 이전 보고서의 정량 비교 대신 오래된 경쟁사 기사와 미확인 값을 사용했습니다.
   - 기존 조사는 질문·경쟁사·동일 기간의 필수 커버리지를 고정하지 않습니다.
     개선 후보도 회사 IR 중심 검색 1회와 원문 2개만으로 경쟁 질문 해결을 보장하지 못합니다.
   - 대응: 직접 경쟁사/고객/공급자를 구별하고, 사업별 비교 질문과 원문 후보를 먼저 고정합니다.
     회사 전체 매출을 특정 사업 경쟁력과 혼동하지 않습니다.
   - 통과 조건: 같은 사업·기간·단위·실적/전망 기준의 비교 또는 구체적인 미해결 이유가 있어야 합니다.

2. **자료는 확보했으나 비교 행이 사라질 위험 (확인된 코드 결함)**
   - 선택한 텍스트의 앞 700자를 자르면 표의 기간 머리글/경쟁사 행/문장이 잘립니다.
     선택 단계에서 버린 내용은 기존 excerpt_truncated에 반영되지 않았습니다.
   - 1차 수정: 문장과 연속 Markdown 표를 통째로 선택하고 예산 초과 표는 부분 전달하지 않습니다.
     선택·예산 누락을 표시하고 완전한 발췌가 없으면 별도 실패 사유를 반환합니다.
     캐시 버전도 올렸습니다. 기존 예산과 검색 호출 수는 늘리지 않았습니다.
   - 한계: 표를 더 잘 찾거나 의미적으로 검증하는 수정은 아닙니다. 큰 표의 구조화 추출,
     머리글 밖의 단위/주석 결합, 기업개요의 추가 180자 축약은 후속 과제입니다.

3. **개별 회사·주가 움직임을 산업 수요로 확대 해석**
   - SMCI 근거 기록은 관련주 동반 상승을 sector_tailwind로 사용했습니다.
   - 대응: 회사 실적, 산업 수요, 주가 상대강도, 사업 경쟁력을 별도 필드로 분리합니다.
     SOURCE_CHECKED는 모델 자기평가이며 실제 검증 상태로 승격하지 않습니다.
   - 통과 조건: 기사 제목/동반 상승만으로 산업 수요 증가나 경쟁 우위를 확정하지 않습니다.

4. **미확정 가격과 확정 종가 표현의 충돌**
   - SMCI 초안에 “거래를 마친”과 BAR_FINALITY_UNKNOWN이 함께 있습니다.
   - 대응: 공급자 관측 시각·거래일·마감 확정 상태를 공유하고 현재 가격 서술에 반영합니다.
     미래 매매 조건의 “종가 이탈”이나 과거 확정 종가를 일괄 치환하지 않습니다.
   - 통과 조건: 미확정 관측값은 현재가/관측가로만 서술하며 요약·PDF에서도 유지합니다.

5. **시장 지표의 범위·결측·표시 품질**
   - 지수 거래량 0과 장기 거래량 비율의 관계는 계산 기간/원자료 추가 추적이 필요합니다.
     이를 아직 계산 오류로 단정하지 않습니다.
   - ETF 가격 강도를 실제 자금 순유입으로 해석하지 않고, 518종목 표본을 전체 시장으로 부르지 않습니다.
     과도한 소수점은 표시 단계에서만 줄이고 거래 계산 정밀도는 보존합니다.

6. **조사 성공과 보고서 품질을 구분하는 검증 부족**
   - HTTP 200, 도구 성공, 테스트 통과만으로 질문 해결·인용 정확성은 확인되지 않습니다.
   - 대응: 동일 원문 스냅샷·질문·모델로 기존/수정 입력을 비교합니다.
     질문 해결률, 동일 기준 비교 수, 인용 대응, 미확인 상태의 보존, 토큰·시간을 함께 기록합니다.
   - 새로운 점수/매매 규칙은 추가하지 않습니다. 보고서 개선과 수익률 개선을 구분합니다.

## 진행 순서

1. 발췌 손실 방지 회귀 수정: 로컬 구현 및 관련 68개 테스트 통과.
2. 질문별 출처/경쟁사 선정과 구조화 비교 자료: 미완료.
3. 보고서 본문 → 요약 → BUY 입력의 동일 근거/한계 전달: 미완료.
4. KR·US 각 2개부터 동일 입력 비교 후 자료 부족·다각화 사례까지 확장: 미완료.
5. PDF 소비 경계, 정확한 PR head CI, 운영 스모크를 통과한 범위만 배포합니다.

## 후속 구현: 질문 중심 비교 자료와 제한적 활성화

사용자 승인: 품질을 개선하고 만족할 때 ON합니다. 범용 조사가 검증되지 않았는데 모든 종목을
활성화하지 않습니다. 이번 검증 대상은 US MU와 KR 005930이며, 통과 시 해당 두 종목만
`validated_symbols`에 넣습니다. 나머지 종목은 네트워크/캐시 접근 전 기존 조사 경로를 유지합니다.
검증하지 않은 SK하이닉스의 동일 원문 경로도 자동으로 활성화하지 않습니다.

### 구조와 비용 상한

- 일반 실적 검색을 직접 경쟁사·사업·동일 기간·단위의 비교 질문으로 교체했습니다.
- 메모리 기업에는 공개 Counterpoint DRAM/HBM 원문 주소와 검토한 영문 법인 별칭을 연결했습니다.
  현재 점유율 숫자는 코드에 넣지 않았습니다. DRAM/HBM과 회사 전체 경쟁력을 구분합니다.
- 원문 표·기간·매출 기준 캡션을 함께 보존합니다. 긴 이미지 주소는 삭제하고 캡션을 유지합니다.
  회사 절에는 조각난 180자 주장 대신 출처 위치를 전달합니다.
- 검색 1회+원문 최대 2회, 60초, 뉴스 입력 3,500자 상한을 유지합니다. 검색 장애 시에도
  검토된 원문 주소를 조회할 수 있습니다. 수집 자료와 실제 입력된 자료 수를 따로 기록합니다.
- 신규 조사 LLM 호출은 없지만 기존 뉴스 에이전트의 조사·요약 비용은 남습니다.
  더 충실한 자료는 입력 토큰을 늘릴 수 있으며 절감률을 주장하지 않습니다.
- 경쟁사 조사를 완료했다고 표시하거나 기존 필수 조사/도구를 없애지 않습니다.
  `SOURCE_CHECKED`는 여전히 모델 자기평가이며 독립 사실 인증이 아닙니다.
- 과대 입력과 비정상 receipt가 들어오면 잘린 자료/예외 대신 UNKNOWN 및 기존 경로를 보존합니다.
- 연구 기능 enable/disable 시 기존 시장 문맥 ON과 검증 종목 범위를 보존하도록 설정 도구를 고쳤습니다.

### 보고서 표현과 전략 경계

- US OHLCV에는 조회 시각·출처·최신 행 날짜·마감 미확정 상태를 붙였습니다. 숫자 계산은 유지합니다.
- KR/US 보고서에 “마감했다, 다만 미확정”이라는 모순을 금지하고 과거 확정 종가/미래 조건은 구분합니다.
- 개별 기업 매출과 동반 주가 상승을 산업 수요로 승격하지 않습니다.
- 실제 모델 시험에서 MU의 DRAM 상승/HBM 하락을 “AI 메모리 전체 점유율 확대”로 합치는 문제가
  발견되어 사업별 방향을 따로 대조하도록 추가했습니다. 정의되지 않은 출처 별칭도 금지했습니다.
- 기존 screening → analysis prefetch → KR/US factory → 뉴스 근거 handoff → 전략/요약 → PDF →
  tracking의 `pdf_to_markdown_text` → BUY 경로를 유지합니다. BUY의 F4 근거 대조는 기존대로이며
  점유율 1위를 새 진입 조건으로 추가하지 않습니다. 스크리닝 점수·RR·매수 문턱·SELL·주문·비중은
  변경하지 않습니다. 자료가 충실해져 모델 판단이 바뀔 수 있으나 수익 개선은 별도 검증 대상입니다.

### 실제 자료 점검

- 4종목 탐색: MU/삼성전자는 같은 사업·분기의 세 회사 비교 원문을 확보했습니다.
  LITE는 2차 비교 사이트, RF머트리얼즈는 재무 요약/IR 목록 중심이라 범용 활성화 근거로 부족했습니다.
- 최종 v6에서 MU/삼성전자 원문을 다시 조회했습니다. MU는 수집 2개 중 예산 내 원문 1개를 주입했고,
  삼성전자는 두 번째 조회 실패를 기록하고 비교 원문 1개를 주입했습니다. 이 실패를 성공으로 세지 않습니다.
- Counterpoint 원문 hash `53a2e24cfb2d18aa09088e7c216b38ad3091396b95cc078ab514f68a588873f6`.
  동일 원문에 기존 c8d14f77/신규 발췌기를 적용하면 완전한 표가 0/2 → 2/2로 늘었습니다.
  숫자 행·기간·매출 기준·반올림 안내가 보존됩니다. 두 종목은 같은 원문이므로 독립 출처 두 개가 아닙니다.
- 실제 동일 질문/모델의 고정 자료 A/B도 실행했습니다. 기존 법인명 일치 방식은 이 원문을
  SUBJECT_NOT_FOUND로 제외했지만 신규 방식은 두 사업의 비교를 생성했습니다. 이는 입력 보존/법인명
  연결의 개선이며, 기존 전체 검색 기능의 정확도가 0이었다는 의미가 아닙니다.
- 원문 표시 날짜는 9/2이고 메타데이터는 9/1 20:00 UTC입니다. 메타데이터·조회시각·기준 분기를
  분리하고 현재 조회를 과거 결정 당시 이용 가능성의 증거로 쓰지 않습니다.

### 통과 조건과 중단 조건

실제 뉴스 생성에서 DRAM/HBM 수치·기간·매출 기준과 혼합 추세를 보존하고, 산업 수요/주가 강도를
혼동하지 않으며, PDF→소비자 경계와 관련 회귀·정확한 head CI·서버 스모크를 통과할 때 제한적으로 ON합니다.
원문 구조 변경, 수치 연결 훼손, 과장된 결론, 지연 증가가 발견되면 연구 기능만 OFF합니다.
OFF 시 기존 시장 자료 ON과 원래 경쟁사 조사 경로는 유지합니다.

현재 이 절 작성 시 최종 live 결과/PDF 검사/CI/배포는 진행 중이며, 완료 증거는 아래에 추가합니다.

### 중간 실패를 숨기지 않는 재검증

- v6 첫 실제 한국 출력은 표의 수치는 맞았으나, 삼성의 DRAM/HBM이 모두 상승하는데
  “방향이 다르다”고 서술했습니다. 미국 사례의 반대 방향 예시를 일반 지침에 넣은 것이
  부적절해 예시를 삭제하고 같은 기업·사업·시작/종료값에서 방향을 계산하도록 바꿨습니다.
- URL 인용을 요구하는 새 계약과 `[네이버금융:종목명]`·`[Perplexity:번호]`를 지시하는
  기존 본문이 충돌했습니다. 기존 지시 자체를 양국·양 언어에서 제거했습니다.
  프롬프트 끝에 더 강한 문구만 추가하는 방식으로 해결하지 않았습니다.
- 발행일 메타데이터는 미검증 상태를 유지하고, 표의 반올림 주석과 표 전사를 직인용과
  구분하도록 보강했습니다. 해당 수정 전 한국 출력은 활성화 합격 자료로 쓰지 않습니다.
- 첫 CI는 독립 시장 자료 설정을 함께 OFF하던 옛 테스트 기대값 때문에 실패했습니다.
  새 의도인 설정 보존과 명시적 `--disable-market-context`를 모두 검증하도록 수정했습니다.
- Codacy가 오프라인 비교 도구의 동적 코드 실행과 assert를 차단했습니다. 동적 실행을
  제거하고 기존 발췌 알고리즘을 고정 함수로 보존했으며, 검증 실패는 최적화 실행에서도
  생략되지 않는 예외로 처리합니다. 검사 우회나 branch protection 변경은 하지 않습니다.

## 최종 품질 판정과 배포 승인 범위

**MU와 삼성전자 두 종목의 비교 근거 보강에 한정해 활성화 승인입니다. 전 종목이나 전체 보고서의
사실 무오류 판정은 아닙니다.** LITE·RF머트리얼즈와 검증하지 않은 SK하이닉스는 기존 경로를 유지합니다.
