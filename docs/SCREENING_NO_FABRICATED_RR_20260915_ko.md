# 한미 스크리닝 가공 손익비 제거

## 사용자 승인과 수정 계획

사용자는 +15% 보정이 왜곡의 원인인데 유지한 것을 지적하고, 수정을 마치고 배포하도록
명시적으로 승인했다. 관측 개선에 그친 PR #726으로 핵심 결함을 해결했다고 취급하지 않는다.

범위는 양국 스크리닝 한 계층이다. 기본 여섯 트리거와 추가 후보 경로, BUY/SELL,
사이징, 손절 정책은 변경하지 않는다.
기존 제3슬롯 SHADOW의 켜짐 여부·슬롯 규칙도 유지하되, 새 스크리닝 점수와 이전
점수를 섞어 평가하지 않도록 관측 버전을 분리한다. 이전 로그는 유지하며 이전 평가의
후속 성과도 원래 버전에 귀속한다.

1. 회귀 테스트로 +15% 보정/고정 손절을 실제 매매 손익비로 출력하는 오류를 재현한다.
2. 근거 없는 목표가·손절가·손익비·매매 적합도는 NULL로 바꾼다. 가까운 과거 고점을
   실제 목표가로 대신 넣거나, 신고가 후보/결측 후보를 손익비 0으로 탈락시키지 않는다.
3. 항상 포화되던 agent 점수 항목을 선발 공식에서 제거한다. 기존 모멘텀·상대강도·
   과열도 항목의 상대 가중치는 유지하면서 합계가 1이 되도록 정규화한다.
4. 오케스트레이터의 예전 손익비 변환과 기본 0을 제거한다. 실제 손익비는 BUY 시나리오에서만
   얻으며, 스크리닝 단계에서 없는 정보는 미확정으로 남긴다.
5. KR/US, 모든 기존 체제·트리거, 결측·신고가·가까운 고점·먼 고점 반례와 출력 계약을
   검증하고 exact-head CI 통과 후 DB 배치 서버에 배포한다.

## 작은 대안 비교와 기대 효과

- 현행/로깅만: 잘못된 숫자가 운영에 남으므로 이번 사용자 지적을 해결하지 못한다.
- 과거 고점까지 손익비로 새 하드 게이트: 돌파 후보의 잠재 상승 여력을 잘못 제한하므로 채택하지 않는다.
- 선택안: 가공 숫자와 포화된 점수 제거. 새 목표가 모델/LLM 없이 산술·출처 오류를 고친다.

기존 agent 점수가 모든 유효 후보에 동일한 상수 1이었다면, 새 점수는 기존 점수에서
상수 항을 빼고 나누는 단조 변환이다. 따라서 바텀업 비교에서 동일 순위가 나와도 보정이 남은 것이 아니다.
단, 탑다운은 섹터 확신도 계수를 점수에 곱하므로 가공 상수에 붙던 확신도 보너스도
함께 사라져 후보 순위가 실제로 바뀔 수 있다. 이 변경을 숨기거나 기존 선발이 전부
동일하다고 주장하지 않으며, 순위 반전 반례를 회귀 테스트로 고정한다.
목표는 억지 순위 변경이 아니라 근거 없는 보상/위험을 선택 공식에서 실제로 제거하는 것이다.
절대 점수 스케일 변경의 소비자를 점검한다. 점수 버전 경계를 구분하고 수익성 향상은 주장하지 않는다.

## 남은 별도 과제

### 기존 제3슬롯 관측의 버전 경계

새 평가 버전은 `kr-weak-regime-third-slot-v1-screening-v2`이다. 기존 실험의
슬롯 수·활성화 환경변수·평가 기준은 변경하지 않는다. 스크리닝 변경 이후 관측만
새 버전의 prospective 표본으로 센다. 이전 로그를 폐기하거나 소급 수정하지 않는다.
패킷 도구는 기본적으로 현재 버전을 대상으로 하며, 이전 결과는
`--policy-version kr-weak-regime-third-slot-v1`로 계속 검증할 수 있다.
제3슬롯 패킷 계약은 schema 2 / kr-third-slot-shadow-evidence-v2이며, 제외된 다른
버전의 이벤트 수를 명시한다. 일반 진입품질 Evidence Packet 계약은 변경하지 않는다.
순수한 표준 재점수 후보끼리는 바텀업 순서가 보존되지만, 기존의 재점수 미적용
경로와 혼합되면 상대 점수 척도가 달라지므로 전체 3순위 목록의 불변을 가정하지 않는다.

KR 매크로/역발상의 CompositeScore 대소문자 배선 문제, 새로운 진입 형태 분류기,
BUY의 별도 목표가 fallback은 이번 스크리닝 수정에 함께 넣지 않는다.
이 변경만으로 CRWD를 자동으로 사전 탈락시키거나 BUY와 동일한 판단을 보장하지 않는다.

  이번 KIS와 무관한 수정으로 해결했다고 주장하지 않는다.
