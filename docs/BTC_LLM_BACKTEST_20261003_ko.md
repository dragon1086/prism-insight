# LLM BTC 시나리오 백테스트 계약 및 우선순위

## 범위와 완료 기준
사용자 요청: 중요한 순서로 구현하고 실제 백테스트 실행·재현 검증까지 완료한다.
범위는 M2 실행 재생, M3 증거, M4 오프라인 평가다. 운영 데모·주문·위험 한도·cron을
변경하지 않는다. 수익성 입증이나 자동 승격은 완료 기준으로 삼지 않는다.

1. 가격 데이터의 연속성·시각·해시와 인과적 진행봉 입력을 검증한다.
2. 실제 ScenarioRuntime/ScenarioDemoBroker를 오프라인 세션에 연결한다.
3. 모델 입력·응답·지연을 기록하고 동일 계약의 tape 재생을 재현한다.
4. 아래 사전 고정 파일럿을 실행한다. 거래 0건도 숨기지 않는다.
5. 결과·결측·가정·재현 해시와 테스트를 보고한다.

## 결과 조회 전 고정한 파일럿
- 기간: 2026-10-02 00:00:00–06:00:00 UTC, 5분 판단 72회 예정.
- 종료 이후 강제 매매 없음. 남은 포지션은 미청산/MTM으로 별도 표시한다.
- 시작 자본: 가상 10,000 USDT. 실제 거래소 잔고를 사용하지 않는다.
- 정책: 배포된 Luna/high/fast 프롬프트·스키마·10배/2%/일4%/3연패 한도 그대로.
- 데이터: 공개 Bybit BTCUSDT 1분 Last/Mark OHLC, 과거 고시간봉 warmup,
  실제 펀딩 일정. 운영 거래 DB를 과거 체결처럼 복원하지 않는다.
- 기본 집행: 1분 OHLC 가정 경로. OLHC는 별도 가정 민감도다.
- 수수료 가정: maker 0.02%, taker 0.055%; 슬리피지 0.05%, 스프레드 0.01%.
  주문/취소/변경 지연과 이전 확정분 거래량의 참여율을 명시한다.
- 비교: 무거래 현금 기준선. 기존 4시간봉 전략 대비 우월성을 주장하지 않는다.
- 강건성 후보 등록: OHLC 기본, OLHC 기본, OHLC 수수료/슬리피지 2배.
  tape의 경제 상태가 달라지면 재사용을 거절한다. 실패를 WAIT로 바꾸지 않는다.
- 결과를 본 뒤 기간·파라미터를 골라 바꾸지 않는다. 추가 시도는 별도 등록한다.

## 인과성과 재현성
진행봉은 해당 시점까지 완결된 1분봉만 집계한다. 새 고시간봉 시작 순간에는
직전 알려진 종가·거래량 0의 합성 경계를 명시하고 미래 OHLC/거래량을 복사하지 않는다.
모의 체결용 OHLC/OLHC 경로를 실제 관측된 틱처럼 모델 입력에 넣지 않는다.
모델 지연 동안 가격·펀딩·손절과 독립 보호 시간이 진행된다.
입력/코드/프롬프트/비용 해시와 원응답을 저장한다. tape 재생에서는 임의 input_id만
다시 연결할 수 있으며 가격·수량·위험·이전 계획 등 경제 입력의 변경은 허용하지 않는다.

## 평가 한계
OHLC 순서와 대기열/유동성은 가정이며 실제 체결 증명이 아니다. 현재 모델이 과거
시장 자료를 학습했을 가능성도 배제할 수 없다. 이 기간은 과거 차트를 이미 살펴본
탐색 자료로, 미사용 holdout이 아니다. 실제 수익 개선에는 동결된 정책의 이후 전진
표본과 별도 입증 계약이 필요하다. 기존 진입품질 JSONL Evidence Packet은 관측
성과 평가용이며 이 파일럿의 모의 체결을 실체결 증거로 넣지 않는다.

## 현재 상태
구현 착수. 실행 결과와 검증 기록은 확인 후 추가한다.
