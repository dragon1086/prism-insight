# LLM BTC 시나리오 백테스트 계약 및 우선순위

## 범위와 완료 기준
사용자 요청: 중요한 순서로 구현하고 실제 백테스트 실행·재현 검증까지 완료한다.
범위는 M2 실행 재생, M3 증거, M4 오프라인 평가다. 운영 데모·주문·위험 한도·cron을
변경하지 않는다. 수익성 입증이나 자동 승격은 완료 기준으로 삼지 않는다.

1. 가격 데이터의 연속성·시각·해시와 인과적 진행봉 입력을 검증한다.
2. 실제 ScenarioRuntime/ScenarioDemoBroker를 오프라인 세션에 연결한다.
3. 모델 입력·응답·지연을 기록하고 동일 계약의 tape 재생을 재현한다.
4. 아래 사전 고정 파일럿을 실행한다. 거래 0건도 숨기지 않는다.
5. 결과·결측·가정·재현 해시와 테스트를 보고한다.

## 결과 조회 전 고정한 파일럿
- 기간: 2026-10-02 00:00:00–06:00:00 UTC, 5분 판단 72회 예정.
- 종료 이후 강제 매매 없음. 남은 포지션은 미청산/MTM으로 별도 표시한다.
- 시작 자본: 가상 10,000 USDT. 실제 거래소 잔고를 사용하지 않는다.
- 정책: 배포된 Luna/high/fast 프롬프트·스키마·10배/2%/일4%/3연패 한도 그대로.
- 데이터: 공개 Bybit BTCUSDT 1분 Last/Mark OHLC, 과거 고시간봉 warmup,
  실제 펀딩 일정. 운영 거래 DB를 과거 체결처럼 복원하지 않는다.
- 기본 집행: 1분 OHLC 가정 경로. OLHC는 별도 가정 민감도다.
- 수수료 가정: maker 0.02%, taker 0.055%; 슬리피지 0.05%, 스프레드 0.01%.
  주문/취소/변경 지연과 이전 확정분 거래량의 참여율을 명시한다.
- 비교: 무거래 현금 기준선. 기존 4시간봉 전략 대비 우월성을 주장하지 않는다.
- 강건성 후보 등록: OHLC 기본, OLHC 기본, OHLC 수수료/슬리피지 2배.
  tape의 경제 상태가 달라지면 재사용을 거절한다. 실패를 WAIT로 바꾸지 않는다.
- 결과를 본 뒤 기간·파라미터를 골라 바꾸지 않는다. 추가 시도는 별도 등록한다.

## 인과성과 재현성
진행봉은 해당 시점까지 완결된 1분봉만 집계한다. 새 고시간봉 시작 순간에는
직전 알려진 종가·거래량 0의 합성 경계를 명시하고 미래 OHLC/거래량을 복사하지 않는다.
모의 체결용 OHLC/OLHC 경로를 실제 관측된 틱처럼 모델 입력에 넣지 않는다.
모델 지연 동안 가격·펀딩·손절과 독립 보호 시간이 진행된다.
입력/코드/프롬프트/비용 해시와 원응답을 저장한다. tape 재생에서는 임의 input_id만
다시 연결할 수 있으며 가격·수량·위험·이전 계획 등 경제 입력의 변경은 허용하지 않는다.
단, 원응답이 원입력 ID를 정확히 반영한 경우에만 재연결한다. 잘못되거나 누락된
ID를 재생 과정에서 고쳐 원래 거절된 응답을 유효하게 만들지 않는다.

## 평가 한계
OHLC 순서와 대기열/유동성은 가정이며 실제 체결 증명이 아니다. 현재 모델이 과거
시장 자료를 학습했을 가능성도 배제할 수 없다. 이 기간은 과거 차트를 이미 살펴본
탐색 자료로, 미사용 holdout이 아니다. 실제 수익 개선에는 동결된 정책의 이후 전진
표본과 별도 입증 계약이 필요하다. 기존 진입품질 JSONL Evidence Packet은 관측
성과 평가용이며 이 파일럿의 모의 체결을 실체결 증거로 넣지 않는다.

## 현재 상태
오프라인 구현·고정 파일럿·수정 후 frozen 재생 검증을 완료했다. 운영 서버에는
배포하지 않았으며 데모 주문·DB·위험 한도·cron도 변경하지 않았다.

### 구현과 검증
- `backtest/scenario_data.py`: 과거 시점의 인과적 진행봉과 경계 입력.
- `backtest/scenario_exchange.py`: 실제 runtime/broker에 연결하는 격리 가상 거래소.
- `backtest/scenario_tape.py`: 원입력·원응답·지연·계약 해시와 엄격한 재생.
- `analysis/scenario_dataset.py`: 공개 Last/Mark/펀딩 자료 수집·무결성 검사.
- `analysis/scenario_replay.py`: 모델 지연 중 가격·독립 보호 진행과 결과 보고.
- 대응 회귀 테스트 5개 파일과 CI 연결. 전체 BTC 테스트 **2,631 passed,
  12 skipped, 네트워크 시도 0건**. 집중 테스트 50개 통과.
- Ruff F/E9, 컴파일·AST 검사 통과. 별도 Python 정적 타입 검사 완료를 주장하지 않는다.
- 독립 리뷰 승인 범위는 격리 연구 도구이며 전략·실거래 승격이 아니다.

### 실제 파일럿 결과
자료는 Last/Mark 1분봉 각각 1,800개, 상위 TF warmup, 펀딩 일정 9개다.
데이터 해시는 `fbf9330b416f99b2198c796766ba15dd8a55f572c7a9adddf371ad099f109bbf`다.

최초 세 실행의 소스는 `f502e55a`, 각 72회 판단이다.
- 기본 OHLC: WAIT 66, 검증 차단 6, 체결 0.
- 기본 OLHC: WAIT 63, 검증 차단 9, 체결 0.
- OHLC 비용 2배: WAIT 59, 검증 차단 13, 체결 0.

초기 replayer가 잘못된 input_id까지 수선하는 결함을 발견하고 수정했다.
위 원본 실행·tape는 그대로 보존하며 strict-replay 인증 대상으로 삼지 않는다.
정책·기간·비용을 바꾸지 않고 수정 소스 `94aeaf3e`에서 추가 검증을 사전 등록했다.
- 추가 fresh: 72회, WAIT 59, 검증 차단 13, 체결 0.
- frozen: 실제 LLM 호출 0회, tape 72개 소비. 계약·결과·tape·거래소 해시와
  경제 결과 및 WAIT/차단 건수가 모두 일치했다.
- 결과 해시: `926ef8eed29082f118303afd5b17070ae985207109ffb609f8daf15d5f2d04f4`.
- tape 해시: `2edb0a534d9782fa0e2c16126b4b99f6c48ceefc33ffab95d1eda6ac8debc8a5`.
- 거래소 해시: `da833fdcfbb08765f4849f94fff9f0f4917e604ee7aa2bff58283175403bc1a9`.

총 288회 fresh 호출에서 전송 실패는 0건, 출력 계약 위반은 41건이다.
허용되지 않은 필드 23건, 빈 scenario_id 8건, 잘못된 input_id 6건,
잘못된 revision 4건이다. 차단된 응답도 모두 관망 내용이므로 형식 오류를
고치면 진입이 늘어날 것이라고 단정할 수 없다.

**모든 실행에서 거래 0건, 순변화 0 USDT, 종료 자본 10,000 USDT다.**
승률/PF는 null이며 무노출의 낙폭 0과 비용 2배 결과를 강건성으로 해석하지 않는다.
같은 6시간의 조건 비교일 뿐 여러 시장 국면 검증이 아니고, 조건마다 새 모델
응답을 받아 LLM 변동성도 포함되므로 경로·비용의 인과효과를 주장하지 않는다.

### 재현 방법
Python 3.12.12와 실행 당시 pandas/numpy를 사용한다. 계약에는 BTC 패키지의
테스트 외 Python 소스 전체, 런타임 버전, 프롬프트·비용·자료 해시가 포함된다.
소스나 경제 입력이 다르면 tape를 재사용하지 않는다. 다음은 추가 검증의 frozen
명령이며 새 출력 폴더가 필요하다. OAuth나 거래소 인증 정보는 필요하지 않다.

```bash
PYTHONPATH=prism-btc:. /Users/rocky/work/prism-insight/.venv-bt/bin/python \
  -m analysis.scenario_replay \
  --input "$ARTIFACTS/input/market.json" \
  --output "$ARTIFACTS/new_frozen_output" \
  --tape "$ARTIFACTS/qualification_v2.jsonl" \
  --mode frozen --path OHLC --cost-multiplier 1 --max-decisions 72
```

`ARTIFACTS`는 전달한 `btc_llm_backtest_20261003` 폴더의 절대 경로다.
`registry.json`, `replay_qualification_registry.json`, 원본 tape, 실행별 report.json,
exchange.json, equity.json, 격리 replay.sqlite, `verification.json`을 함께 보존한다.
현재 문서만 바뀐 커밋은 Python 소스 계약을 바꾸지 않는다.
