# 한국 오전 배치 중단: 권리락의 가격·거래량 기준 불일치

## 증거와 원인

2026-09-16 오전 배치는 09:31부터 KIS 자료를 수집하다 09:40에 종목 선정을 중단했다.
인증 실패나 KRX 장애가 아니라, **KIS 마스터와 비수정 일봉의 거래량 표현을 동일하다고
가정한 검증이 당일 무상증자 권리락 종목에서 실패**한 사례다.

- 마스터 2,685종목 중 기존 제외 대상 3개를 뺀 2,682종목의 이력이 존재했다.
- 2,681개는 일치하고 미트박스(475460) 한 종목만 달랐다.
- 공식 마스터: 권리락 `01`, 액면 변경 `00`, 무상증자 `02`, 기준가 2,765원,
  전일 거래량 31,822주, 전일 시총 468억원.
- 날짜가 확정된 9/15 비수정 일봉: 종가 8,290원, 거래량 95,410주, 거래대금 801,599,045원.
  독립 재조회 결과도 캐시와 같아 캐시 오염은 아니었다.
- KIS 공식 수정 일봉: 종가 2,764원, 거래량 286,057주, 거래대금 동일.
- 독립 현재가 응답도 기준가 2,765원을 확인했다.
- `floor(95410 × 2765 / 8290) = 31822`,
  `floor(95410 × 8290 / 2765) = 286057` 두 관계가 정확히 일치했다.

단순히 불일치 검사를 없애면 현재가 약 2,730원과 전일 8,290원을 비교해 **약 -67%의
가짜 가격 하락**을 만든다. 종목 하나를 몰래 제외해도 매크로 트리거의 시장 평균·순위가
달라지므로 그런 우회는 사용하지 않는다.

## 최소 교정 계약

- 지원 조합은 위 명시적 무상증자 권리락 코드에 한정한다. 종목 코드를 하드코딩하지 않는다.
- 전일 비수정 이력·공식 수정 이력·당일 마스터 기준가·독립 현재가 기준가를 대조한다.
- 날짜·행 수·OHLCV/거래대금·정수 거래량 변환 관계를 검증한다. 임의 오차율이나
  전체 일치율 99.9% 같은 기준을 추가하지 않는다.
- 원본 비수정 캐시와 공식 전일 시총은 그대로 보존한다. 시총·가격·거래량을 역산해 덮어쓰지 않는다.
- 검증된 기업행사 종목의 **비교용 전일 snapshot**에만 KIS 공식 수정 일봉 전체를 사용한다.
  수정 종가 2,764를 기준가 2,765로 강제 변경하지 않는다.
- 거래량이 우연히 같거나 0이어도 지원 행사 플래그를 확인한다. 실패·미확정은 기존 중단을 유지한다.
- 추가 조회는 행사 종목에만 제한하며 종목 수·시간 한도를 둔다. 일반 종목 경로는 유지한다.

이 규칙은 이번 관측으로 확인한 표현 호환성이다. KIS가 모든 기업행사에 같은 산식을
보장한다는 주장이 아니다. 미지원 행사·증자 상장일·복합 행사·조정값 사후 수정은 후속 검증 대상으로 남긴다.

## 검증·재실행

- 실제 수치 재현, 원본 불변·비교용 수정 구분, 기준가/날짜/거래량 오류 거부, 정상 경로 유지.
- 실제 KR/US 배치 모듈의 provider-shape 통합 테스트, 정확한 PR head CI와 운영 Python 검사.
- 배포 후 KIS-only 전체 bundle을 읽기 전용으로 확인한다. 선별 검증을 약화하지 않는다.
- 최초 오전 실패는 선정 단계에서 종료되어 보고서·매수 추적이 시작되지 않았다.
  사용자는 장애 수정 후 같은 오전 배치를 비동기로 한 번 재실행하도록 승인했다.
- 기존 오전 실행이 없는지 확인하고 기존 실행 환경·매수 안전장치를 유지한다.
  새 PID·시작 시각·별도 로그를 기록하며, 시작과 최종 성공을 구분한다.

우선 한국 배치 재실행을 시작한 뒤 BTC API 만료 및 US 전달 미확정 대응을 이어간다.
