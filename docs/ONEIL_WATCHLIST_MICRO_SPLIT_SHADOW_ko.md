# 오닐식 후보 감시와 초분할 연계 SHADOW

> 아래는 최초 US 연구 기준선이다. 2026-09-16 승인된 KR 확장과 가격경로 관측,
> 시장별 관측 기간은 [후속 계약](KR_US_WATCH_SHADOW_PROTOCOL_20260916_ko.md)을 따른다.
> 이전 US 로그와 식별자는 변경하지 않는다.

## 1. 사용자 승인과 범위

2026-09-16 사용자는 오닐식 후보 감시를 설계하고 기존 초분할 SHADOW와 궁합을 검토한 뒤,
적합하면 연계 SHADOW를 실행하도록 승인했다. **LIVE 매수·매도 변경 승인이 아니다.**

철학적 궁합은 조건부로 적합하다. 후보 감시는 **언제 다시 검토할지**, 초분할은
최종 매수 적격성이 확인된 이후 **얼마나 작게 시작할지**를 담당한다. 하락했으니 싸다는
판단으로 진입하거나, 손실 중인 포지션에 물타기하는 기능은 아니다.

실제 연계는 **US부터** 시작한다. 기존 운영 초분할이 US 신규 적격 진입의 0→10% 투영에
한정되기 때문이다. KR은 공통 코어 설계의 적용 대상으로 남기며 한국 초분할·감시 운영을
이번에 켰다고 표현하지 않는다. 별도 대시보드·LLM·상주 서비스·cron은 추가하지 않는다.

## 2. 변경 전 증거

공식 도구 `tools/build_micro_split_evidence_packet.py`로 운영 sanitized JSONL을 분석했다.

- Packet: `e5f1ea3c91324e66583d6a88`, 자료 마지막 시각 `2026-09-15T14:41:37.875247Z`.
- 실제 초분할 SHADOW 4이벤트 / 4결정 / 4관측일, 중복 event_id 0.
- 명시적 완료 세션 2개, schema v2 비율 50%, 완료 배치와 미연결 결정 4개.
- 과거 후보 재생 63건은 실제 SHADOW 표본과 별도다.
- 부족 사유: `COMPLETED_SESSIONS_LT_20`, `OBSERVED_DATES_LT_20`,
  `OBSERVED_DECISIONS_LT_30`, `SCHEMA_V2_COVERAGE_LT_100_PCT`.
- 판정: `CONTINUE_CAPTURE`. 이번 연계는 사용자 승인에 따른 별도 사전등록 연구이며,
  기존 초분할이 성과 검증을 통과했다거나 연속 10→30→60→100 단계가 운영 중이라는 뜻이 아니다.
- US 진입품질 Packet `59a93c0239286502743c6b2e`도 후보 51건에서 `data_sufficient=false`다.
  자료가 충분하다는 가정으로 새 정책의 수익성을 주장하지 않는다.

## 3. 실제 파이프라인과 권한

1. 기존 US `us_trigger_batch.run_batch`가 종목을 선정한다. 순위·선정 결과 JSON을 바꾸지 않는다.
2. 선정 직후 선택적 watcher가 신규 후보와 저장된 이전 후보를 재관측한다.
   신규 선정이 없어도 기존 후보를 재관측한다. 감시 실패는 기존 배치 결과에 영향을 주지 않는다.
3. `WATCH_READY`는 기술적 재검토 조건 충족이며 **BUY 승인·주문 신호가 아니다**.
4. 기존 보고서 → BUY 에이전트 → 점수/섹터/cooldown/RR/추세 게이트 → 실행 경로를 유지한다.
   재관측 후보를 실제 선정 결과에 끼워 넣거나 새 보고서를 자동 생성하지 않는다.
5. 기존 US 최종 `entry_eligible` 경계에서 발생한 실제 0→10% SHADOW와,
   동일 배치의 정확한 watch 재검증 참조가 연결될 때에만 별도 연계 이벤트를 기록한다.
6. BUY 검토가 없었던 READY는 `NOT_EVALUATED`로 남긴다. `ENTRY_ELIGIBLE_SCOUT`나
   가상 체결을 만들어내지 않는다. 실제 holdings·주문·손절·SELL·공개 메시지는 바꾸지 않는다.

US orchestrator는 `run_in_executor` 스레드로 trigger batch를 실행한다. ContextVar이
자동 전달된다고 가정하지 않고 batch reference를 명시적으로 넘긴다. 날짜+종목만 맞춰
관측을 결합하지 않는다. 다른 배치·다른 watch 수명·다른 실행 profile은 별개다.

## 4. 사전등록 정책 oneil_watchlist_v1

다음 값은 결과를 보고 최적화한 값이 아닌 **첫 연구안**이다. 값을 변경하면 정책 버전을
바꾸고 새로운 전진 관측 구간을 시작한다.

- 선정 원천: 기존 US 선정 후보. 역발상 가치주 유형은 이번 추세 지속 연구에서 제외한다.
- 입력: 최소 66개 날짜 정렬된 종목·SPY 일봉. 기준 거래일 당일 봉은 제외한다.
  따라서 장중 가격에 즉시 반응하는 시스템이 아니라 보수적인 확정 일봉 감시다.
  마지막 입력은 NYSE 달력의 직전 완료 거래일과 일치해야 한다. 종목과 benchmark가
  함께 오래된 응답인 경우도 결측으로 처리한다. 과거/미래 거래일 override는 운영 상태에 쓰지 않는다.
- 추세: 종가가 MA50 위, MA50이 5개 봉 전보다 상승, 60거래일 상대수익률이 SPY보다 우세.
- pivot: seed 평가봉을 제외한 직전 20개 봉의 고점. 후보 수명 동안 고정한다.
- 재검토 구간: pivot 이상, pivot의 105% 이하. 단순 20일 고점 돌파 대용 지표이며
  정교한 CAN SLIM 베이스·기관 수급·거래량 확인까지 끝났다는 의미는 아니다.
- READY에는 직전 완료 봉보다 종가가 상승한 조건도 요구한다. 높은 곳에서 떨어져
  가격 구간에 들어온 것만으로 강세 재확인이라고 부르지 않는다. 이 조건은 실제 관측 전
  설계 반례(110→104 하락, pivot 100)로 고정한 연구 가설이며 성과 최적화 결과가 아니다.
- 추세 훼손은 무효화하고, 과열·미돌파는 대기한다. 손절가·목표가·실제 R/R은 만들지 않는다.
  실제 매매에서는 최신 BUY 시나리오와 기존 게이트가 최종 권한을 가진다.
- 수명: 5개 완료 시장 거래일. 동일 봉 재실행·오전/오후 재실행·재선정으로 수명을 연장하지 않는다.
- 최대 활성 후보: 20개. 데이터 수집은 별도 제한 시간 20초 내 처리하며 실패는 명시적 결측이다.
- 결측·중복 날짜·미래/당일 미완성 봉·benchmark 날짜 불일치로 정상 판단을 만들지 않는다.

## 5. 초분할과 맞는 점, 충돌할 수 있는 점

### 맞는 점

- 강한 종목의 추세 확인을 우선하고 손절·위험 예산을 완화하지 않는다.
- 적격 진입 이후 정찰 비중 10%를 계산한다. 1슬롯의 10%이며 계좌 전체의 10%가 아니다.
- 고가주에서 10%가 0주로 투영될 수 있다. 강제 1주·올림·확정 체결 추정을 하지 않는다.
- 감시 상태와 전략 목표비중, 브로커 체결 상태를 분리한다.

### 가장 중요한 반례

감시도 확인을 기다리고 초분할도 비중 확대를 기다리면 **큰 승자를 이중으로 늦게 잡을 수 있다**.
현재 유효한 돌파를 강제로 대기시키지 않으며, 손실 감소만 아니라 큰 승자 포착률과
수익 절단률을 검증한다. 이 반례를 해결하려고 손절을 넓히거나 하락 중 비중을 늘리지 않는다.

### 연속 캠페인을 구현할 때의 연결 규칙 (설계만, 이번에는 미가동)

- 무보유 후보는 감시가 관리하고, 최신 BUY 적격성이 확인될 때만 정찰 10% 캠페인을 시작한다.
- 이후 30/60/100% 확대는 캠페인의 이익·추세·추가 위험 검증이 담당한다.
  반복 READY나 재선정을 비중 확대 신호로 재사용하지 않는다.
- 후보 감시 수명 만료가 이미 시작한 캠페인을 자동 청산시키지 않는다. 보유 중에는 기존
  손절·SELL·위험 예산이 우선이며, 감시의 추세 훼손은 별도 재검토 근거로만 전달한다.
- 같은 종목의 후보 수명과 캠페인 수명을 다른 ID로 기록한다. 종료 후 재진입은 새 적격 결정과
  cooldown 검사를 거친다. 상태 재시작으로 정찰·추가 leg를 중복 생성하지 않는다.
- 강세장 100% 초과 확대는 기존 초분할 설계의 별도 조건을 따라 검증하며 이번 연결로 켜지 않는다.

## 6. 지금 관측하는 것과 향후 네 비교군

지금은 다음을 구분해 기록한다.
- 이전 후보의 기술적 READY와 기존 파이프라인에 다시 선정되지 않은 READY.
- 실제 기존 BUY 적격 진입에서 나온 초분할 SHADOW.
- 둘이 같은 배치·정확한 참조로 만난 연계 표본.

**이 교집합만으로 감시가 놓친 종목을 구제했는지, 성과를 개선했는지는 입증할 수 없다.**
향후 동일 후보·동일 가격 경로·동일 비용으로 네 가지를 재생 비교한다.
1. 기존 시점 + 기존 비중
2. 감시 재검토 시점 + 기존 비중
3. 기존 시점 + 초분할
4. 감시 재검토 시점 + 초분할

연속 단계·청산·포트폴리오 현금/슬롯·비용을 갖춘 캠페인 재생은 후속 작업이다.
이번 SHADOW를 완성된 네 비교군 포트폴리오 백테스트로 부르지 않는다.

## 7. 검증·운영 계약

- watcher ON/OFF에서 기존 선정 순위·결과 JSON·BUY/SELL·holdings·주문·공개 메시지 diff 0.
- 같은 봉 재실행, 빈 선정, 재시작, 이전 후보 READY 전이, 과열/추세 훼손/결측을 시험한다.
- collector timeout/저장 실패/연계 callback 예외는 기존 batch와 초분할 이벤트를 훼손하지 않는다.
- 기존 micro 이벤트 schema·개수·Packet 표본과 신규 watcher/연계 이벤트를 섞지 않는다.
- 신규 Packet은 event ID·정책·명시적 배치·watch 수명·실행 profile을 검증한다.
  원문 보고서·계좌 ID·키·원 단위금액을 밖으로 내보내지 않는다.
- 초기 관측 검토 기준은 유효 연계 이벤트가 정확히 연결된 완료 micro 배치 세션 20개와
  고유 연계 결정 30건이다. 완료는 분석·tracking 완료이지 주문 체결을 뜻하지 않는다.
  이는 기능 표본 기준일 뿐 수익성·LIVE 승격 기준은 아니다. 자동 승격하지 않는다.
- 사용자 승인으로 `trading/config/oneil_watchlist_shadow.json`에 US SHADOW를 명시한다.
  기존 micro SHADOW가 켜져 있어야 동작한다. 이 파일은 비밀 설정이 아니다.
- OFF/정책 오류 시 선택적 관측만 중단한다. 배포/관측/연계 표본/수익 입증은 각각 보고한다.
