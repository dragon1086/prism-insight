# 업종별 분석·매매 로드맵

> 시작: 2026-09-26 | 최종 목표: 보고서와 **매매 판단**을 업종별로 다르게 적용

## 원칙

- 업종 판별은 결정적 근거만 사용한다: DART 회사정보의 **공식 업종명(KSIC)** + **최신 재무상태표 구조**.
  KIS/KRX 업종명은 판별에 쓰지 않는다(일반 지주회사·조선 지주회사도 "금융"으로 분류됨).
- 애매하면 일반 기업으로 처리한다(보수적 기본값).
- 일반 기업의 기존 프롬프트·출력은 바이트 단위로 유지한다.
- 매매 로직 변경은 `docs/TRADING_CHANGE_REVIEW_HARNESS.md`와 사용자 승인을 거친다.

## 1단계 — 보고서 업종 관점: 금융사·지주회사 (완료, 2026-09-26)

- `prism_core/sector_profile.py`: 금융(은행·보험·증권·카드캐피탈·금융지주) / 지주회사 / 일반 판별과 업종 관점 문구.
- 공통 참고자료(2장·5장·전략·요약)에 업종 관점 주입, 5장 finance 집필자의 금융업 규칙, 금융사 재무구조 차트는 자기자본비율.
- 5장 비용 상한을 알림 방식으로 전환(초과해도 발행 + 유지보수 알림, 폭주 방지 상한만 차단).

## 2단계 — 보고서 업종 관점: 건설·수주산업·적자 바이오 (완료, 2026-09-26)

DART 공식 업종명을 44개 종목에서 실측하고(db-server, 신원 조회만), 6개 종목(현대건설·한화오션·LIG·삼성E&A·
신라젠·알테오젠)은 전체 수집 결과를 덤프해 판별 규칙을 검증했다.

| kind | 판별 (업종명 + 재무제표) | 관찰된 업종명 / 일반으로 남는 사례 |
|---|---|---|
| `construction` | 업종명이 `…건설업`으로 끝남 + 일반 기업 재무상태표 | 도로·토목·아파트·주거용 건물·건물·비주거용 건물 건설업 / 삼성물산(기타 전문 도매업), 전문공사업(`…공사업`) |
| `order_backlog` (shipbuilding) | `선박…건조업` + 재무상태표 계약 행 | 기타 선박 건조업, 선박 및 수상 부유 구조물 건조업 / 기자재(선박 구성 부분품 제조업) |
| `order_backlog` (defense) | `무기·총포탄·전투용 차량·항공기·우주선` + 계약 행 | LIG·퍼스텍·현대로템·한화에어로스페이스·KAI / 한화시스템(전자부품), 풍산(비철금속) |
| `order_backlog` (engineering) | `…엔지니어링 서비스업`(건축기술… 제외) + 계약 행 | 삼성E&A·한전기술·포스코DX / 세미파이브, 두산에너빌리티(터빈 제조업) |
| `loss_biotech` | `의학 및 약학·의약·생물학·자연과학` + 최신 손익계산서의 모든 누적 기간 영업손실 | 신라젠·헬릭스미스·메지온 / 알테오젠·셀트리온·삼성바이오로직스(흑자) |

- 계약 행: `(유동|비유동)?(계약자산|계약부채|미청구공사|초과청구공사)`와 정확히 일치(주석 번호 제거).
  `확정계약자산/부채`는 위험회피 확정계약이라 제외.
- 영업손익: `영업이익(손실)/영업이익/영업손익` 행만 읽고(`영업손실`은 부호가 모호해 제외), 반기·분기 보고서는
  `누적` 열만 본다. 손익계산서와 포괄손익계산서가 다르면 일반.
- 업종 관점은 공통 참고자료로 주입. 5장 집필자: 적자 바이오는 순위험 규칙을 현금 소진 기간 비교로 교체,
  수주산업은 "계약부채는 차입이 아니고 계약자산은 현금 상쇄 자원이 아니다"를 추가. 건설은 변경 없음.
- 일반·금융·지주 기업의 집필 지시문·참고자료는 main과 바이트 단위 동일.

## 3단계 — DART 수집 실패 종목 조사 (완료, 2026-09-26)

db-server에서 종목당 한 번 실제 수집하며 DART 원응답을 모두 녹화했고, 수정 검증은 녹화 재생(부족분만 실조회)으로 했다.

| 종목 | 확정 원인 | 조치 |
|---|---|---|
| 삼성전자 | 버그 아님. 신원 조회 정상(2회, "통신 및 방송 장비 제조업"). 이전 `ksic_unknown`은 IP 차단 중 관찰 | 없음 |
| 롯데리츠 | 연결재무제표 본문이 "2. 연결재무제표 - 해당사항 없음." → `-` 때문에 공식 미해당 증거로 인식 못 해 별도 재무제표 대체 경로가 열리지 않음 | `_consolidated_not_applicable`가 `-` 허용 |
| 카카오뱅크 | 연결 미해당은 인식하나, 정정 공시 2건의 계보를 연결 기준으로 검증할 수 없어(본문이 공식 미해당) 대체 경로 조건 `unresolved_corrections` 없음에 걸림 | 미해결 정정이 모두 공식 미해당 증거를 가진 경우만 허용. 별도 수집이 계보를 처음부터 다시 검증 |
| SK | 수집 정상. 2025 사업보고서 주석의 종속기업 현황 표(579행)가 표 파서 상한 300행 초과 → `unsupported` 1개가 5장 전체를 막음 | 주석의 행 수 초과 표만 원문에서 제외하고 담당 집필자에게 "공시에 있으나 제공하지 못함" 안내, 영수증 `withheld_tables` 기록. 재무제표의 미지원 표는 계속 차단 |
| 맥쿼리인프라 | 최근 550일 정기공시(사업·반기·분기보고서) 없음(회사명·종목코드 조회 모두 결과 없음). 5장의 유일한 원천이 없음 | 수집기 수정 대상 아님(구조적 한계). 5장 없이 발행 + 유지보수 알림 유지 |

- 리츠 업종 관점 `reit`: KSIC `(부동산|건물) 임대` + DART 회사 개요의 공식 회사이름에 `부동산투자회사` + 재무상태표 `투자부동산` 행.
  상장 리츠 7곳 실측 업종명: 부동산 임대 및 공급업·부동산 임대업·비주거용 건물 임대업(일반 임대·개발 회사도 같은 업종명이라 회사이름이 결정 근거).
  FFO·배당 재원·임대율·임차인·차입 만기/금리·LTV·감정평가를 보도록 공통 참고자료로 주입, 5장 집필자 규칙은 변경 없음.
- 보고서마다 `DART sector profile kind=… basis=…` 로그를 남긴다(배치 로그로 업종 관점 적용 확인).
- 일반·기존 업종의 집필 지시문·참고자료·5장 입력은 main과 바이트 단위 동일(86개 해시 비교).

## 4단계 — 매매 로직 업종별 판단: 금융업 F2 (구현·배포, db-server `live`, 2026-09-26)

사용자 승인(2026-09-26): 금융업 F2 교체만 구현해 `off`로 배포(PR #791, 9bc7d0a). 같은 날 **`live` 전환 명시 승인** — 카드·캐피탈 기준을
법정 최저선(8%)에서 다른 업종처럼 완충을 둔 10%로 올린 뒤(실적 관측 전 조정) db-server `.env`에 `PRISM_KR_SECTOR_F2_MODE=live`.
`off`는 새 기준의 반사실 판정을 남기지 않아 관측만으로 전환 근거가 쌓이지 않고, 새 기준은 공시 비율이 없으면 미달이며 다른 관문은 그대로라
손실 범위가 제한적이라는 판단. 되돌리기는 `.env` 한 줄을 `off`로.

### 하네스 검토 기록 (Strategy adoption and fit gate)

1. **변경 유형·범위**: 경제적 의사결정 변경(금융사 F2 판정 기준). 기준선 main `ff88d63`. KR BUY만, 금융업(bank/insurance/securities/card_capital/financial_group)만.
2. **가설·반증 조건**: 금융업 재무상태표는 예수·보험계약부채가 영업 조달이라 `부채비율 < 200%`를 구조적으로 통과할 수 없고,
   보고서 단계(1단계 업종 관점)는 이미 "부채비율로 판단하지 말라"고 지시해 BUY와 모순된다. 공시 규제 자본비율이 건전성의 올바른 잣대다.
   반증: `live` 후 새로 F2를 통과한 금융사 진입이 기존 기준 통과 종목보다 유의하게 나쁜 결과(손절 비율·30일 수익률)를 보이면 폐기.
3. **기존 전략과의 궁합(실제 코드 추적)**:
   - 스크리닝(`trigger_batch.py`)은 업종 무관 → 변경 없음. 보고서 생성(`cores/analysis.py`)에서 `classify_issuer` 결과가 로그 외에는 버려졌음.
   - BUY 입력은 PDF 본문뿐(`stock_tracking_agent._analyze_report_core`), 업종 관점 문구는 작성자 지시에만 있어 PDF에 보이지 않음.
   - F2 미달 → `fundamental_check.all_passed=false` → `cores/buy_gate.py:184`가 sideways/bear에서 하드 차단, 강세장도 점수 가이드("펀더 게이트 미달 1~2점")로 사실상 차단.
   - SELL(LLM 프롬프트·O'Neil 규칙·손절·추세 청산)은 부채비율·업종 입력이 없어 변경 없음. 주문·사이징 경로도 변경 없음.
   - 수정 계층은 **BUY 보고서별 요청문 하나**. 공유 지시문·결정 게이트·스크리닝·점수 기준은 그대로.
4. **증거(운영 DB 읽기 전용, 2026-09-26)**: F2 판정이 저장된 8/24 이후 KR BUY 102건 중 F2 미달 21건.
   금융사 2건(우리금융지주 9/14: F2가 유일한 미진입 사유, 한화투자증권 9/4: 모멘텀도 미달). 5월 이후 금융사 점수 2 미진입 5건의 30일 수익률은
   +25%·−15%·−6%·−51%(데이터 의심), 14일 −11%로 놓친 기회는 입증되지 않음. 반례: 건설(금호건설 F2 단독 7회, 14일 대부분 −4~−22%)은
   부채비율이 실제 위험을 거르므로 **유지**. 적자 바이오는 F1에서 탈락(의도), 지주는 F2 구조적 탈락 없음, 수주산업·리츠는 표본 없음 → 기록만.
   Entry Quality Packet KR `5ea8366d1d1848ae4a177b88`: 후보 37·청산 1, `data_sufficient=false` → `CONTINUE_CAPTURE`.
5. **원인 구분·유지/중단 조건**: 시나리오에 `_sector_profile`(kind/subtype/basis/f2_rule), 로그 `[SECTOR_BUY][KR] … mode= f2_rule=`.
   `live` 후 최소 관측: 금융사 BUY 판단 20건 또는 6개월 중 늦은 시점. 새 기준으로만 통과한 진입이 손절 비율에서 기존 통과군보다 나쁘면 `off`로 복귀.
   임계값은 업종별 1개씩만 사전 등록(아래), 결과를 본 뒤 조정하지 않는다.
6. **결론**: 전달·기록 LIVE, 금융업 F2 교체 LIVE(사용자 명시 승인, 2026-09-26). 5번 중단 조건 적용.

### 구현

- `prism_core/sector_trading_criteria.py`: 모드(`live`만 활성, 그 외 전부 `off`), F2 블록, 기록 스탬프.
  F2 통과 기준(공시값만, 계산·추정 금지, 없으면 미달): 은행·금융지주 CET1 ≥ 11% 또는 BIS 총자본비율 ≥ 14%,
  보험 K-ICS ≥ 150%(경과조치 전 수치 우선), 증권 NCR ≥ 150%, 카드·캐피탈 조정자기자본비율 ≥ 10%(법정 최저 카드 8%·캐피탈 7%에 완충).
- `cores/analysis.analyze_stock(report_meta=)` → `generate_reports`가 종목별로 모아 `tracking_agent.run(report_meta=)`로 같은 프로세스 안에서 전달.
  DART 추가 조회 없음. 보고서 실패·DART 입력 실패·재실행 경로는 업종 없음 = 일반과 동일.
- 오분류 방향: 비금융이 금융으로 잘못 판별돼도 공시 규제 자본비율이 없으므로 F2 미달(현재보다 엄격하거나 같음).
- 검증: main 워크트리와 같은 격리 하네스로 BUY 지시문·요청문 sha256을 비교해 일반·건설·`off` 금융사가 main과 동일함을 확인(ko/en, 수동).
  회귀 테스트(`tests/test_kr_sector_f2_buy.py`, 주문·네트워크 차단)는 같은 브랜치 기준선 대비 일반·건설·리츠·지주·적자 바이오·`off` 금융사
  요청문이 동일하고 `live` 금융사만 끝에 블록이 붙는지 확인하며, 지시문 자체는 기존 해시 고정 테스트(`tests/test_evidence_capture_repairs.py`)가 지킨다.

### 남은 것

- 배포 후 첫 KR 정기 배치에서 `DART sector profile kind=`와 `[SECTOR_BUY][KR]` 로그 확인(미관측).
- 금융사 보고서에 규제 자본비율이 실리는 빈도 관측(전환 전 남은 보고서 2건: 우리금융지주 CET1 있음, 한화투자증권 NCR 없음 — 둘 다 1단계 업종 관점 이전).
  비율이 없으면 `live`에서도 F2가 NOT_IN_INPUT 미달로 끝난다. 수주산업(계약부채 제외 부채비율)·리츠(LTV·배당) 기준은 표본이 쌓인 뒤 같은 하네스로 재검토.
