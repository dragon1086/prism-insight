# 한미 스크리닝 손익비 계약 검토

## 범위와 수정 계획

- KR/US 기본 여섯 트리거의 명칭과 선택 규칙을 유지한다. 트리거는 후보 발견 경로이고,
  눌림목/돌파는 특정 시점의 진입 구상이다. 트리거명으로 구상을 자동 확정하지 않는다.
- 기존 +15% 목표 보정과 고정 손절로 만든 점수는 실제 매수 손익비가 아니다.
  우선 회귀 테스트로 기존 선발 순서를 보호하고, 공통 순수 함수로 원시 고점까지의
  거리와 가정 손절폭의 출처를 별도 기록한다. 추가 시세/LLM 호출은 하지 않는다.
- 신고가 또는 데이터 부족은 실제 매매 손익비 0이나 탈락으로 변환하지 않는다.
  최근 고점은 확정 저항도, 돌파 이후 목표가도 아니다. 마감 확정 여부도 추정하지 않는다.
- 매매 시나리오의 목표/손절과 함께 저장하는 손익비에 스크리닝 손익비를 덮어쓰는
  KR/US 기록 오류를 수정한다. 시나리오 값이 없으면 NULL이며 과거 기록은 재작성하지 않는다.
- 이번 단계는 기록 계약 수정이다. 선발 점수/가중치/매수·매도/손절·사이징은 유지한다.
  +15% 보정 제거를 선발 순위에 적용하는 변경은 별도 사전 등록과 비교 재현 후 검토한다.

## 반례와 검증

가까운 고점, 이미 고점을 넘은 돌파 후보, 멀리 있는 고점, 자료 부족, 잘못된 숫자를
KR/US에서 함께 검사한다. 기존 선발 점수가 동일하고 추가 조회가 없는지 검증한다.
기록된 원시 고점은 제공된 윈도우의 관측치이며 종가 확정 또는 미래정보 배제의 증거가 아니다.
결정론적 수치 검증은 수익성 백테스트가 아니다. 신규 SHADOW/LIVE 규칙은 활성화하지 않는다.

## 후속 비교 사전 등록안

현행을 기준군으로, (1) 포화된 agent 점수 제거 및 나머지 가중치 정규화,
(2) 검증된 동일 가격·손절·목표 근거를 공유하는 선별을 별개 대안으로 비교한다.
같은 실험에서 매수 프롬프트/청산 규칙까지 바꾸지 않는다. 트리거×체제×버전별로
후보 교체율, 분석 비용, 누락된 유효 후보와 전략 원장 성과를 평가한다.
과거 결측 목표/손절을 현재 데이터나 수익률에서 역산하지 않는다.

판정: PREREGISTER_REPLAY. 이번 기록 수정만으로 수익성 향상이나 선별 개선 완료를 주장하지 않는다.

## 코드 검토 결과

기본 여섯 개는 오전의 거래량 급증·갭 상승·시총 대비 자금 유입과 오후의
일중 상승률·마감 강도·거래량 증가 횡보이다. 이와 별개로 매크로 섹터 리더와
역발상 가치 후보 경로가 이미 존재하며 SHADOW 전용이 아니다. KR 매크로는
매크로 문맥이 필요하고, US 매크로는 strong_bull을 제외한다. 역발상은 양국 모두
sideways/moderate_bear/strong_bear에서 사용한다. US 자금 유입은 부족분 보충 경로다.
코드 경로 확인이며 이번 검토에서 운영 환경별 활성화 설정을 새로 변경하지 않았다.

갭 트리거는 갭·당일 상승·거래대금 조건이지 지지 반등/박스 돌파/추세 확장 구분이 아니다.
같은 종목도 날짜에 따라 가격 구조가 달라진다. 횡보 트리거도 장기 base 검증과 동의어가 아니다.
KR 제3슬롯 SHADOW는 기존 후보의 3순위 관측이며 신규 트리거가 아니다.
추세품질 연구 CAPTURE도 자동으로 새 트리거가 되지 않는다.

스크리닝의 고정 손절 5/7/8%와 최소 +15% 조합은 설정된 모든 기준 손익비를 넘어
agent 적합도 점수를 포화시킨다. 그러나 BUY는 보고서 목표가가 5% 이상 위에 있으면
이를 우선하며, 그다음 저항 거리 80%, 저항이 없으면 +15~30% 순서다.
따라서 관측 고점을 BUY 목표가라고 바꿔 부르는 것도 잘못이다.

별도 발견: KR 매크로/역발상은 CompositeScore를 생성하지만 하이브리드 경로는
composite_score를 검사한다. 후보가 전부 사라진다는 뜻은 아니며 동일 재점수 경로를
거치지 않는 문제다. 선발 순위에 영향을 주므로 이번 기록 수정에 섞지 않았다.

## 남은 한계

- 기존 +15% 보정과 선발 순위는 아직 유지된다. 이번 변경은 이 전략적 문제의 최종 해결이 아니다.
- 새 증거는 기존 선택 결과 파일에 붙는 설명용 정보다. 미선택 전체 후보의 과거 snapshot을
  새로 생성하지 않으며, 이것만으로 과거 순위 재현이나 수익성 검증이 가능해지는 것은 아니다.
- 원시 고점 데이터의 마감 여부는 UNKNOWN이다. 실제 매매 손익비는 별도 시나리오 값이다.
- 기존 watchlist 기록은 소급 수정하지 않는다. 변경 전후 손익비 집계를 섞으면 안 된다.
- 새 분류기·매수 게이트·LLM·유료 데이터·스케줄을 추가하지 않는다.

## 검증 기록

- 공통 계산·양국 실제 함수·세 저장 경로·NULL 표시·provider/feedback: 60개 통과.
- KR multi-account 및 보고서 처리 회귀: 68개 통과.
- US BUY 안전·보고서 처리·약세장 경로 회귀: 89개 통과.
- 신규 파일 Ruff, 순수 함수 Bandit 및 변경 Python 구문 검증 통과.
- 기존 `test_us_volume_surge_flat_excludes_bearish_candle` 1건은 변경 전
  3c41ab08과 변경 후 모두 같은 실패를 재현했다. 이번 변경으로 해결했다고 주장하지 않는다.
- 독립 읽기 전용 검토에서 NULL RR 텍스트 포맷 오류를 발견하여 N/A 표시로 수정하고
  회귀 테스트를 추가했다. 전체 저장소 테스트가 모두 통과했다는 뜻은 아니다.
