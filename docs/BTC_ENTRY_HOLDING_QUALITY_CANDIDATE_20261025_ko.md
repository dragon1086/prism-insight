# 진입·손익비·부분감축 근거 구분 후보 (미배포)

## 사전 범위

사용자의 계속 진행 요청에 따라 기존 미배포 PR1115의 구조 우선 진입 선호를 재사용한다. 기존 네이티브 실험 결과를 바꾸거나 재시작하지 않는다. 별도 복구 정책과는 분리한다.

진입은 추세 참여와 제한 구간 목적을 구분한다. 추세형의 비용 가정 전체계획2:1을 비교하되 host 자격/위험 한도나 보유 EXIT에 강제 gate를 추가하지 않는다. 미가격 runner의 hard-SL 스트레스와 전량 가격화 목표를 구분하고 가상 수익·승률을 발명하지 않는다. 초반 TP를 무조건 줄이는 고정 비중안은 재채택하지 않는다.

부분감축은 실행 빈도나 비율을 강제하지 않는다. 진행 중 봉의 고가가 이전 완성봉 고가보다 낮다는 사실만으로 확정된 lower-high 반전으로 취급하지 않는다(하락의 higher-low도 대칭). 실제 불리한 가격 진행/구조 이탈은 봉 마감 전에도 대응할 수 있고 확정 실패 EXIT는 지연하지 않는다. 지난 감축 증거가 제공되면 이후 무엇이 바뀌었는지 비교한다. 같은 설명의 재표현은 새 악화 증거가 아니며, 과거 자료가 없으면 감축이 없었다고 추정하지 않는다.

이것은 04:55 실제 감축의 오류를 확정한 결론이 아니다. 06:05에는 추가 가격 하락이 있어 두 감축이 같은 근거만 반복됐다는 증거도 없다. 일반적인 확정봉/진행봉 사실 구분과 반복 증거 해석의 명확화이며, 한 거래로 전역 금지 규칙을 만들지 않는다.

## 검증과 한계

- 새 테스트의 최초 결과6실패/7통과, 문구 수정 뒤 관련 경로72통과(network0). 두 프롬프트 상수 외 AST는 기준8be96d와 동일하다. 가격/수량 계산·선택 schema·호스트 자격·주문 경로 변경 없음.
- 진입 LONG/SHORT 1.99/2/2.01 경계, 부분SL→TP·TP→SL·잔량 hard-SL 경로와 기록 순익1회 반영을 기존 제품 테스트로 확인한다.
- 100KB·실제 조립 요청·보유 EXIT/REDUCE·재생 검증을 추가한다. 전체 테스트는 최종 확정본에만 수행한다.
- 문구 테스트가 실제 모델 행동 개선이나 수익성 증거는 아니다. 새 모델 비교가 필요하면 비용 상한과 표본·선택 기준을 별도 등록하고, 강한 진입 기회 보존과 과도한 WAIT/감축 지연 반례를 포함한다.
- 운영 미배포이며 부분SL 성공을 위험 예산 축소의 확정 근거로 쓰지 않는다. 기존 가정 확정 실패의 전량 EXIT·Full SL·10배·15분봉 제외는 유지한다.

독립 제한 검토에서 명시적인 보호 지연·전부 WAIT 강제·부분SL 의무화 충돌은 발견하지 않았다. SELECT는 새 후보 생성이나 추가 모델 호출을 요구하지 않도록 '이미 제공된 eligible 후보 또는 WAIT' 중 선택한다는 문구로 한정했다. 관련6파일 통합104개 통과 후 이 한 줄을 보강했으며, 보강된 프롬프트 hash와 관련 회귀는 별도로 확인한다.

최종 보강 후 입력 빈값·guard·문구/hash 관련88개 통과(network0). 실제 모델 호출은0이며 강한 기회 보존·실제 감축 선택·수익성은 아직 미입증이다. 전체 테스트/운영 배포 전 게이트는 미충족이다.
