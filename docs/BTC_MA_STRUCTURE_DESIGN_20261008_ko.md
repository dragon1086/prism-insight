# BTC MA10/35 변화 경로와 상위 시간봉 장애물

## 범위와 승인
사용자 요청: 배열·가격의 이동 경로·발산/수렴과 상위4시간/12시간/일봉(주봉 포함) 이평 지지저항을 함께 판단하도록 설계·검증·구현한다. M4 경제 판단/입력 변경이며 M0 집행 안전과 M5 수익 입증을 구분한다. 기준선 a80fcf51. 기존30분/1시간 중심,15분 타이밍,10배·단계별 손실 상한·첫 회복WAIT·주문 만료·동일방향/추가진입/보호 제한은 유지한다.

## 최소 채택/궁합 검토
1. 변경은 새 진입과 보유 관리의 판단 입력/프롬프트다. 자동 진입·손절·익절 하드 규칙을 추가하지 않는다. 이전 PR#980의 flat-only 범위와 달리 이번 상위 지지저항/경로 설명은 보유 판단에도 제공한다.
2. 가설은 정적인 배열/위치를 변화 과정과 혼동하거나 현재 MA를 과거 봉에 적용하는 오류를 줄이고, 단기 기회의 상위 이평 장애물까지의 실제 거리를 비교하도록 하는 것이다. 발산·교차·접촉 자체가 수익을 보장하지 않는다. 늦은 추격,왕복 교차,저항 돌파 실패가 반례다.
3. 경로: engine snapshot의 같은 시점MA 이력→bounded context 요약→LLM 제안→기존wire/가격/위험/recovery검증→실행/보호. 호스트 권한은 그대로이고 설명용 사실이 OPEN 권한을 발급하지 않는다. 상위 방향 라벨은 거부권이 아니지만 실제 가까운 가격 장애물과 비용은 WAIT 근거가 될 수 있다.
4. 시점성/반례 테스트와 주문 없는 같은 원본 입력 비교를 먼저 수행한다. 신규 경로가 없는 과거 기록은 그 결측을 표시하고 최신 MA로 과거 봉을 채우지 않는다. 독립 미래 표본과 실제 체결비용이 없으면 수익 개선은 미입증이다.
5. 효과와 부진은 입력 누락/수학 오류,LLM 근거 오류,집행 불확실,국면 변화로 분리한다. 입력·요청·원응답·소스 정책 해시를 기록하며 별도 상주 작업을 만들지 않는다. 회귀 시 이 MA 맥락/지시만 되돌리고 기존 보유 보호는 유지한다.
6. 현 판정은 구현 및 정책 검증 단계다. 정상 CI/격리 테스트/논리 검토와 실제 모델 검증을 통과하기 전 운영에 반영하지 않는다. 통과해도 데모 정책 반영이지 성과 승격이나 위험 한도 인상이 아니다.

## 데이터 정의
- 각 시간봉에 최근3개 확정봉의 해당 시점 SMA10/35·OHLC와 현재 관측 형성봉을 제한적으로 제공한다. 확정봉의 MA는 그 봉까지의 이력으로 계산한다. 형성봉은 관측시각·남은 시간·잠정값임을 보존한다.
- 발산/수렴은 기본적으로 abs(MA10-MA35)의 가격 단위 간격 확대/축소다. 기존 가격 정규화 간격과 압축 문턱0.0015는 보조 설명이며 기존 필드의 의미는 변경하지 않는다. 동일한 가격 단위 간격인데 분모 가격이 바뀌어 정규화 간격만 변한 경우를 구분한다.
- 확정봉의 연속 축소 횟수와 압축 횟수,형성봉의 현재 확대/축소를 분리한다. 진행 중 한 봉을 완성된 지속시간으로 세지 않는다. '오랜' 수렴에 새 하드 문턱을 만들지 않고 관측된 횟수/시간을 제공한다.
- 현재와 직전의 가격 위치/MA 배열/기울기/간격을 분리한다. 상대 위치 전환이 가격 이동 때문인지 MA 이동 때문인지 수치로 볼 수 있게 한다. 접촉/한 번의 교차를 재시험 성공이나 장기 추세 확정으로 이름 붙이지 않는다.
- 상위4시간/12시간/1일/1주의 MA10/35를 확정/형성으로 구분해 reference와의 거리·위/아래를 제공한다. 형성Last SMA와 Mark 기준 거리의 가격 기준 차이를 명시한다. 같은 선의 두 버전을 독립된 지지저항 두 표로 과대평가하지 않는다. 미확인 프레임은 unavailable이며 없는 지지저항을 보충하지 않는다.

## 판단 계약
상승/하락 교차,기존 배열의 추가 발산,수렴 후 재발산,발산 후 수렴,압축 중 왕복,가격과 배열의 엇갈림을 LONG/SHORT 대칭으로 비교한다. 두 선 사이의 횡보는 혼재로 취급하되 자동 매매 금지는 아니다. 아래에서 회복해 band에 들어왔는지,위에서 이탈해 들어왔는지에 따라 기존 포지션의 근거 약화를 평가한다.
단기 방향의 이익 경로에 있는 상위 MA를 목표·부분익절·잔량 유지 판단에 사용하되, MA 접촉마다 자동 청산하지 않는다. 돌파/지지 전환을 이미 확인했는지 잠정 신호인지 구분한다. 반대 방향 전환도 기존 포지션/주문/정산을 끝내기 전 반대 OPEN은 금지한다. 작은 수량이 무효인 설정을 유효하게 바꾸지는 않는다.

## 모델 비교 사전 등록
모델 결과를 보기 전에9개 원본 사례를 고정한다. 보존 사례5개는10/7 21:05최초관측,21:35약세flat,10/8 02:00band혼재flat,15:55숏 재평가,16:15숏EXIT 입력이다. 당시 없는MA이력을 새로 채우지 않고 자체 시각MA가 있는 최신 확정점/형성점만 사용한다.
합성4개는 단일15분 테이프에서 모든 시간봉을 집계한 장기압축후상승/하락과 상승배열중band하락진입/하락배열중band상승진입이다. 모두합성 시세·계좌이며 실제 경제 성과가 아니다. 미래 구간은 만들지 않고 해당 시각의 형성prefix만 제공한다.
기존/후보 각1회로 총18회,순서는사례별A/B,B/A로 교대한다. 같은원본자료지만 후보의snapshot MA경로와모델context가추가되는 입력+정책 비교다. 결과가 마음에 들지 않는다는 이유로 사례를바꾸거나 선택적으로 재호출하지 않는다. 원응답·입력/요청hash·형식/위험/회복검증·사실근거대조를별도로 기록한다. 가상체결/손익을만들지 않는다.

### 초기 검증 후 필요한 기술/근거 정정
18개 제안은 계약 검증을 통과했지만 별도의 전체회복입력 크기 스트레스에서107,517/107,479바이트로 기존100KB 제한을 넘었다. 상위MA 값을 canonical levels에 한 번만 두고 ID로 참조하며 원본 snapshot을 남긴 채 요약 중복과 JSON 공백만 제거한다. 제한을 늘리거나 원자료를 조용히 버리지 않는다. 동일 스트레스 최종값은94,422/94,413바이트다.
초기 후보의 매도량/총거래량 혼동,혼재된 프레임을 모두MA아래라고 묶어 말한 오류,확정/형성 이평 구분의 모호함도 명시적으로 보완한다. 수학·집행 게이트 통과와 올바른 이유는 별도로 평가한다. 최종 후보9개 전체를 각1회 다시 호출해 총27개를 보존하고 성공 사례만 고르지 않는다. 이 반복 개선은 독립 성과 검증이 아니다.
