## 최초 계획과 구현 대조

- **공통 시장 근거:** 구현. 미국 고정 16 ETF의 5/20/60거래일 수정주가 수익률과 SPY 대비

  packet을 전달한다. source, 완료봉 날짜, hash, 수집 시각을 남긴다.
- **한국·미국 시장 참여 폭:** 부분 구현. 기존 배치 관측 종목군의 상승/하락/보합과
  유효/전체/누락 수를 기록·전달한다. 장중 관측일 수 있고 전시장 MA50/200 상회 비율이 아니다.
  한국 성장/가치 지표를 코스닥/코스피로 대신 만들지 않는다.
- **섹터/산업 정합성:** 교정. 반도체 산업 주도를 Technology 전체 가점으로 넓히지 않는다.
  기존 yfinance 조회에서 얻은 산업만 사용하며 추가 종목별 조회는 없다. 기존 가중치는 유지한다.
- **목표가·손익비:** 교정. 양국·양 언어 BUY의 임의 +15~30% 목표와 R/R를 맞추기 위한
  저항선 건너뛰기를 제거한다. 근거 있는 +15% 목표 자체를 금지하지 않는다.
  목표 근거·보유기간·청산 방식·출처시점을 먼저 기록한 뒤 기존 R/R를 평가한다.
- **경쟁근거 prefetch:** 선택형 구현·실측. Search 1회 + Scrape 최대 2회,
  60초 상한·성공 6시간/실패 5분 캐시. 제한된 발췌를 회사/뉴스 분석에 재사용한다.
  수집 성공을 경쟁사 비교 완료로 취급하지 않으며 기존 경쟁사 조사 도구를 제거하지 않는다.
- **TradingView 운영 ON:** 보류. 인증과 기능 실측은 별도 감사에 기록되어 있으나,
  자동 판단·공개 채널 이용에 대한 권한이 확인되지 않았다. Essential 구독을 별도 이용권한으로 간주하지 않는다.
- **명시적 peer registry, 동일 사업·기간 비교 완료율 자동 검증:** 미구현. 이름이 있는 경쟁사 수를 품질로 세지 않는다.
- **종목 기술 팩트 전면 통합·시장 서술 모순 자동 검사:** 미완료. 공유 시장 숫자와 확정 국면은
  전달하지만 기존 자유 서술 전체의 의미 일치까지 코드가 검증하지 않는다.
- **미국 후보군 확대·정교한 setup·VCP:** 보류. 공급자·후보군·전략 변경을 동시에 묶지 않는다.
- **실제 ETF 순유입·신용·유동성·추가 공포지수:** 미구현. 가격 상승을 현금 유입으로 표현하지 않는다.
- **초분할 LIVE·국면 문턱 완화:** 이번 범위 밖. 기존 SHADOW와 주문/비중/손절/SELL 권한을 보존한다.

## 실제 코드 경로와 전략 적합성

1. `trigger_batch.py`, `prism-us/us_trigger_batch.py`: 기존 발견 트리거·cap·순위 가중치를 유지한다.
   미국 업종 매칭의 잘못된 넓히기만 교정한다. 참여 폭은 metadata이지 새 점수나 하드 게이트가 아니다.
2. 양국 orchestrator: 계산된 국면을 강제한 뒤 원래 market packet을 보존하고,
   선정 단계의 참여 폭을 같은 context에 합친다. 새 LLM 감시나 cron을 추가하지 않는다.
3. 양국 analysis/factory: 기존 1~5절을 유지한다. 같은 근거가 전략·요약 전에 들어가고
   시장 근거 ID와 수치가 PDF 추출까지 보존되는 회귀를 둔다.
4. 양국 tracking/BUY: 공유 market packet·산업 범위를 전달한다. BUY는 보고서의
   출처·시점·실적/예상·보유정보/실제 수급을 구분한다. 기존 점수 문턱과 조정 한도는 유지한다.
5. `prism_core/trading_scenario_contract.py`: 명시된 목표 근거가 unknown/잘못된 형식이면
   신규 진입을 허용하지 않는다. 과거 provenance 없는 응답은 하위 호환된다.
   이 형식 검사는 LLM의 출처 주장을 사실로 인증하는 장치가 아니다.
6. 주문/비중/SELL: 수정하지 않는다. 가까운 저항을 반드시 익절하라는 SELL 규칙을 추가하지 않는다.
   신고가 추세추종의 별도 기대수익 모델은 미구현이며 이번 수정만으로 전체 전략 궁합이 완성된 것은 아니다.

변경 성격은 입력·분류·산술 계약 교정과 설명 근거 추가다. 수익률 최적화 실험이 아니다.
최근 특정 종목의 손절을 이유로 점수 문턱이나 위험 예산을 완화하지 않는다.
오류·출처 연결 훼손·미완료봉 혼입·과도 지연이 발견되면 선택형 입력을 OFF하고
기존 자료 경로를 유지한다. 부진하면 시장 변화와 새 입력 효과를 분리해 분석하며
근거 없는 목표가 fallback을 정상 전략으로 복구하지 않는다.

## 운영 설정과 복귀

모두 기본 OFF. 비밀값이 없는 `runtime/report_research_config.json`을 CLI로 생성한다.

```bash
# 시장 설명 자료만 ON; 경쟁근거 prefetch는 검증 전 OFF
python tools/configure_report_research.py --disable --enable-market-context
# 모두 OFF
python tools/configure_report_research.py --disable
```

`PRISM_REPORT_RESEARCH_ENABLED=false`는 연구 prefetch 즉시 중단,
`REPORT_MARKET_CONTEXT_ENABLED=false`는 시장 문맥 즉시 중단이다.
KR KIS·US 기존 시세 공급자·정규 배치 시간은 그대로다. app-server에는 이번 작업을 배포하지 않는다.

참고: [TradingView 일반 약관 §3](https://www.tradingview.com/policies/),
[공식 MCP 안내](https://www.tradingview.com/mcp/docs). MCP 기능 제공과 자동 판단·공개 재배포 권한은 구분한다.
