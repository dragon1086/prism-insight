# 한국 보고서 품질 개선 운영 반영 계획

## 목적과 적용 경로

검증된 한국 자료 수집·계산 개선이 개발 브랜치에 남아 있던 누락을 해결한다. 기존 `analyze_stock` 호출 경로에 기본 적용하여 정규 배치와 Telegram `/report`가 같은 기능을 사용하게 한다. 미완료 10역할 실험, 회사별 정답 치환, 구조화 사실 레지스트리는 활성화하지 않는다.

1. 기존 4개 시장 자료 응답을 재사용해 보고서 지표를 계산한다. 추가 시세 호출이나 매매 규칙 변경은 없다.
2. 기존에 검증한 DART 발행사 확인·공시 선택·HTML 표/주석 해독 모듈을 독립적으로 이식한다. 조회·시간·크기 상한과 출처·기간·연결/별도 경계를 보존한다. 기존 수집 설정 전체나 TradingView 코드를 되살리지 않는다.
3. 확보한 공시 근거를 기존 기업 현황·개요·뉴스에 전달하고, 계산값·출처 안내를 전략·요약·최종 PDF에 보존한다. 기존 모델 단계 수와 병렬 설정은 유지한다.
4. 사람과 AI가 함께 읽는 보고서답게 관측값·기준일·해석을 먼저 쓰고 필요한 한계만 짧게 설명한다. 내부 상태코드는 공개 문장으로 번역한다. 없는 최신 종가를 이전 종가나 조회 가격으로 바꾸지 않는다.

## 검증·배포 조건

- 과거 개발 worktree와 산출물을 그대로 보존한다. 현재 main에서 분리한 worktree에 필요한 변경만 적용한다.
- 계산값·기간·표 단위·자료 누락·실패 fallback·시장 캐시의 종목 간 분리 회귀를 실행한다.
- 실제 한국 분석 함수의 생성 입력→전략·요약→PDF/BUY 전달을 주문 없는 모의 실행으로 확인한다.
- 운영 Python·실제 공개자료의 읽기 전용 확인, 필요 시 실제 한국 보고서 1건을 격리 생성한다. 여러 종목 A/B 실험을 다시 시작하지 않는다.
- 정확한 PR head CI 후 DB/app clean main에 ff-only 배포하고, 봇·설정·cron 불변을 확인한다. 첫 정규 배치 관측 여부는 별도로 기록한다.

## 해석의 한계

표 구조 보존은 모든 숫자의 의미 검증과 다르다. 일부 공시·주석 선택은 전수 열람이나 전역 최신 확인을 뜻하지 않는다. 가격 결측을 자연스럽게 설명하는 변경은 데이터 복구 기능이 아니다. 검증된 산술·자료 전달과 실제 투자 수익성은 구분한다.

## 배포 전 확인

- 보고서·공시·계산·표현 통합 회귀 1,116개, 기존 공급자/소비 경계 72개 통과. 별도 독립 검토 1,058개 통과. 실행 묶음은 중복이 있어 합산하지 않는다.
- 실제 SKT 읽기 전용 공시 조회에서 공식 발행사 확인, 총 27회 요청, 원문 4섹션 확보를 확인했다. 반기 공시 `20260813001728` 및 과거 연차 보충 공시 `20260318000532`가 연결됐다.
- 각 기존 분석 입력은 약 23KB이며 상한 24KB를 넘는 완전 블록은 제외했다. 전수 공시·주석 보존 또는 모든 필수 투자 사실의 확보를 주장하지 않는다.
- 기존 장중/완료 거래일 수급의 내부 원자료는 유지하면서 공개 부록에서는 상태 코드·해시 대신 수치·기간·연속 순매수 구분을 자연어로 표시한다.
- TypeScript 기반 LSP 결과를 Python 타입 검증으로 사용하지 않는다. Python 구문·Ruff·실제 모듈 테스트로 확인했다.
- 운영 배포와 실제 한국 모델 보고서 확인은 이 문서 작성 시점의 후속 검증이며 아직 성공으로 기록하지 않는다.
