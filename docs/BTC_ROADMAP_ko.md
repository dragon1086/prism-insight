### M0. 보호·체결 안전성 — 진행 중, 최우선

**2026-10-04 M0/M1 펀딩 정산 차단:** 실제 전진 감사 중 정상 Funding execution을
unmatched로 오분류해 전량 체결 후 정산이 보류되는 결함을 확인했다. Funding과 SETTLEMENT를
exact ID·시각·방향·수량·금액으로 대조하되 펀딩을 중복 과금하지 않는다.
재현·수정·검증 계약을 따르며, 기존 위험 차단을
임의 해제하거나 과거 정산을 수동 성공 처리하지 않는다. 자연 실행 정산은 별도 확인한다.

**2026-09-16 API 키 만료 사고:** 메인 demo의 Bybit33004를 확인했다. 인증 실패를 명시하고
무의미한 같은 세션 반복 호출을 줄이되 복구·진입 fence를 유지한다. 메인 실제 노출 재확인과
거래 재개는 유효 키 교체 후 남은 운영 작업이다. 사고 및 남은 조치를
따르며 코드 교정을 인증 복구 완료로 표시하지 않는다.

**2026-09-15 강제청산 위험 검사 후속(M0/M1):** 공유 demo 진입의 실제 마진 자료와
운용자금 기준 스트레스를 보강한다. 격리 전환·자금 이동·기존 포지션 강제 청산은 하지 않는다.
검사 계약과 미완료 점검 목록에
