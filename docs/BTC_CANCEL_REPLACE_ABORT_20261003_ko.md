# 미체결 취소·재배치의 확인된 중단 정리

## 범위 (M0 실행 안전)
국면별 프레이밍 연구(PR #887)에서 기존/후보 모두, 미체결 취소 후 재배치 ADJUST가
취소 확인을 기다리다 중단된 뒤 PENDING에 남아 후속 판단을 막는 결함을 발견했다.
기존 주문은 확정 취소, 새 ADJUST 자식은0개, 배치는ABORTED, 계좌는flat/무주문이었다.
이 파일은 실행 오류 교정만 기록한다. 운영 프롬프트·2%/10배·중단 조건은 변경하지 않는다.

## 불변조건과 수정
- 모든 자식 주문은 거래소 제출 전에 UNKNOWN 의도로 영속 기록한다.
- 자식이 없는 명시적ABORTED ADJUST만 복구 후보로 삼는다. 기존 취소의 정확한 종료
  증거, 전체flat/무주문, 미확정/레거시 격리 사유 없음, 보호 확인을 모두 요구한다.
- 해당 의도의 자체 체결0 종료 증거만 생성한다. 시나리오 전체 체결·비용·손익은
  기존 정산 경로로 확정하며, 실제 제출이나 정산을 성공으로 꾸미지 않는다.
- 프로세스 중단의 EXECUTING 배치는INTERRUPTED로 구분한다. 재실행·신규 자식 제출과
  ABORTED/COMPLETE 재분류를 금지한다. UNKNOWN 주문이나 취소 미확정은 계속 차단한다.
- 주문을 재제출하지 않는다. 대기가 해제된 뒤 다음 슬롯에서 새 모델 판단을 받아야 한다.

## 검증
실패를 먼저 재현했다. 정상 복구, 알 수 없는 자식/기존 주문, 취소 미확정, 비flat,
외부 주문, 배치 부재/COMPLETE, 중단 배치의 반복 조회·재실행을 검사했다.
실제runtime/모의 거래소에서 취소→중단→정확한flat 확인→새 판단 재개를 검사하고,
체결·수수료가 만들어지지 않는 것을 확인했다. 독립 검토는 수정에 승인했다.
최종 전체 테스트·CI·서버 격리 검사·배포/정규 실행은 PR에 별도로 기록한다.

## 프레이밍 연구와 운영의 분리
같은 실행 교정을 양쪽에 적용한6시간 탐색 비교에서 새 프레이밍은 종료 거래가1→3건으로
늘었지만 순손익은+153.97→+81.86USDT, 최대낙폭은0.55→1.32%였다. 이미 본 구간의
독립 LLM 응답 비교로, 프레이밍의 순수 인과효과나 수익성 입증은 아니다.
후보는 PR #887에 보존하고 운영 프롬프트는 유지한다. 이 실행 수정만 별도로 반영한다.
원본 중단된 실험과 추가 실험 모두 응답/tape/소스 해시를 보존한다.
