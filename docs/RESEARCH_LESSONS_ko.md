# 매매 연구에서 배운 것 (교훈 장부)

연구용 리플레이 코드와 표를 쌓아 두는 대신, **다음 결정에 바로 쓸 교훈**만 여기에 남긴다.
새 매매 규칙·트리거·프롬프트를 검토할 때는 [`TRADING_CHANGE_REVIEW_HARNESS.md`](TRADING_CHANGE_REVIEW_HARNESS.md)와 함께
이 문서를 먼저 읽고, 같은 질문을 다시 검증하기 전에 아래 결론과 겹치는지 확인한다.
새 연구를 마치면 결론과 교훈을 이 표에 한 줄 이상 추가한다(코드만 남기는 연구 PR은 만들지 않는다).

## 매매 방향 결정 (사용자, 2026-10-07)

- 일반적인 단타 기준(당일 수급·테마 분위기로 1~3일 사고파는 규칙)은 쓰지 않는다. 손실 매매가 짧게 끝나는 것은 손절의 결과일 뿐이다.
- 뉴스·테마 정보는 텔레그램에 정보로 보여 주고, LLM에는 재료를 참고하는 정도로만 준다(매수·보유·매도 규칙 근거 아님).
- 손실로 털린 종목은 지켜보다가 다시 강해지면 재진입해서 큰 흐름을 탄다. 재진입 규칙을 키우는 것이 다음 개선의 중심이다.

## 연구 방법에 대한 교훈 (2026-10-02~04)

1. **방향은 사용자가 정한다.** 가설의 정의·대상 종목·보유 기간·성공 기준·적용 방식을 연구 전에 사용자에게 확인한다.
   교과서 평균값으로 정의를 정하면 "효과 없음"만 반복된다(포켓피봇·신고가·장중 보정 연구).
2. **대상 종목이 결과를 정한다.** 재진입처럼 "이미 고른 종목"에 쓰려는 신호는 시장 전체가 아니라 PRISM이 실제로
   분석·진입·손절·보류한 종목에서 재야 한다. 대상이 아무나면 결과도 아무나다(50·200일선 회복 v1).
3. **비교 기준을 같은 집단 안에 둔다.** 같은 종목의 다른 날, 같은 감시 기간의 무작위 진입, 원래 판단 시점 진입과 비교한다.
   무작위 비교의 중앙값은 반복마다 따로 계산한다(평균을 낸 뒤 중앙값을 보면 0%로 뭉개진다).
4. **평균은 소수 대박에 끌려간다.** 상위 1~2건을 뺀 결과와 중앙값을 함께 본다(한국 재진입 우위는 2~3건에 의존).
5. **판단 시각이 결과를 바꾼다.** 점심 가격과 종가로 같은 규칙을 판정하면 신호 일치율이 한국 65%, 미국 50%뿐이었다.
   장중 규칙은 실제 판단 시각의 가격으로 검증한다.
6. **사용자 용어로 보고한다.** 내부 연구 이름(캠페인, A2, ①C 등) 대신 "재진입 감시 기간", "흔들기 후 회복 매수"처럼 쓴다.

종료 공지 누락을 별도 발견해 수정했다. **모의 거래 손익이 맞아도 거래소 응답 모양과
공지까지 포함한 실제 생명주기 검증을 대체하지 못한다.** 자세한 사전등록·결과·결측은
BTC 검증 기록에 남긴다.

## BTC 최신 운영 보완의 전후 비교 (2026-10-04)

직전 검증 3b5a4a69와 현재 8a53364f를 같은 과거 LLM 기록으로 대조한 864슬롯에서
주문·체결·자산곡선과 최종 경제 결과가 동일했다(수익률 차이 0). 최근 네 파일 변경은
정산/알림 수리이며 매매 정책 변경이 아니다. **교훈: 새 LLM 호출의 우연한 차이를 코드
개선 효과로 포장하지 말고, 동일 입력 비교와 실제 장애 형태의 복구 검증을 분리한다.**
종료 거래의 비용 포함 손익을 독립 재구성해도 B/C는 최대 수익 1건 제외 시 음수다.
이는 큰 승자를 타는 추세추종의 실패 판정이 아니다. 소수 승자 의존 자체보다 해당 승자를
반복 포착·증액하는 능력과 그 사이 손실/비용을 검증해야 하며 이번 표본은 부족하다.
미종료 시나리오 기여분에는 부분 청산 실현손익도 포함되므로 전부 평가이익이라고 하지 않는다.
상세 방법과 한계는 정밀 비교 기록에 남긴다.
