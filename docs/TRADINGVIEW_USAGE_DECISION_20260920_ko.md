# TradingView 공식 MCP 운영 판정

확인일: 2026-09-20 KST. 검토 대상: TV 자료 → PRISM 자동 판단 → KIS 주문.

## 결정: 현재 조건에서는 NO-GO

이 경로는 안전하다고 승인하지 않는다. [일반 약관 3절](https://www.tradingview.com/policies/)에
데이터를 이용한 알고리즘 판단·자동매매 제한이 있기 때문이다. 주문을 KIS에서 실행하거나
보고서로 요약해 BUY에 전달해도 이 제한에서 벗어난다고 볼 근거가 없다.
이는 공개 조건을 실제 구조에 적용한 운영 판단이며 법원의 판단은 아니다.

## 반대 근거와 구분

[공식 MCP 출시문](https://www.tradingview.com/blog/en/tradingview-mcp-server-public-beta-60864/)은
AI 스크리닝·브리핑·문서 분석·코드 계산을 소개한다. 따라서 사람이 요청하고 읽는 개인 분석까지
일괄 금지라고 판단하지 않는다. 다만 출시문과 [MCP 문서](https://www.tradingview.com/mcp/docs)에서
외부 무인 매매를 허용하는 예외는 찾지 못했다. 구독·OAuth 성공은 그 허가의 증거가 아니다.

약관 25절도 검토했지만 외부 MCP까지의 적용 범위가 명확하지 않아 주된 판단 근거로 삼지 않았다.
계정별 별도 계약은 열람하지 않았고, 제재 발생 확률·손해 규모도 산정할 수 없다.
판단 변경에는 실제 자동매매 용도를 포괄하는 명시적 허가나 공식 조건 변경이 필요하다.

## 현재 상태와 개발 방향

운영 서버를 읽기 전용으로 확인했다: f586cc9, tracked 변경 없음, 새 TV 수집·인증 모듈 없음.
따라서 이번 개발로 해당 자동매매 데이터 흐름을 추가하지 않았다. 기존 운영 전체의 위험이
없다는 뜻은 아니다.

개인 표시용 연구와 자동매매 입력을 분리하고, 직접 DART 공시 수집·보고서 품질 개선은 계속한다.
권한 문제를 사용자에게 떠넘기거나, 반대로 근거 없이 무위험이라고 약속하지 않는다.
비공식 tradingviewapi.com의 문구는 판정 근거에서 제외했다. 독립 연구 검토도 같은 결론이다.
