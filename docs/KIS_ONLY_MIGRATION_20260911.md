# 한국 시장 데이터 KIS 단일 제공자 전환

## 변경 계획과 완료 기준
1. 카카오/브라우저 로그인뿐 아니라 KRX Open API, 직접 KRX 패키지, FDR/Naver 시장 데이터 fallback을 실행 경로에서 제거한다. 거래소명·MCP 별칭·역사 자료는 데이터 제공자 연결과 구분한다.
2. 기존 KIS 가격·지수·투자자 수급을 재사용한다. 전종목 목록·종목명·전일 시총은 KIS 공식 마스터, 전일 OHLCV는 KIS 날짜별 원자료로 수집하고 출처·날짜 검증 캐시를 둔다. 과거 데이터를 현재 값으로 합성하지 않는다.
3. 매수·매도·추적·일지·주간자료·백테스트·유틸리티의 직접 호출을 공통 KIS API로 통일한다. 과거 시총/재무 시계열 등 KIS가 제공하지 않는 자료는 UNKNOWN/미지원으로 알린다. 기존 매매 기준을 완화하지 않는다.
4. 오래된 환경변수나 설정이 남아 있어도 제거한 제공자를 다시 활성화하지 못하도록 한다. 금지 import·endpoint 재유입 검사와 KIS 장애 시 우회하지 않는 검사를 추가한다.
5. 기존 동작을 회귀 테스트로 보호하고, 실제 KIS 전체 입력·콜드/웜 수집 비용을 검증한다. 실행 중인 수동 복구 배치를 먼저 확인하고 완료 전 운영 파일/런타임 의존성을 교체하지 않는다.
6. CI·독립 검토 후 배포한다. 원천 값 확보, 스키마/범위 검증, 배치 전체 완료, 투자 성과를 구분한다. 완전히 확인하지 못한 항목을 완료라고 보고하지 않는다.

## 범위 경계
카카오 챗봇 기능, 뉴스/공시/기업 IR 열람, 미국의 기존 데이터 경로는 이번 한국시장 제공자 교체와 다르다. 사용자 인증파일과 비밀값은 출력·커밋·임의 삭제하지 않는다. 매매 원장·계좌·과거 관측 자료는 보존한다.

## 현재 KIS 원천 제약
- 개별 가격·지수·수급은 KIS 조회이며 실패 시 다른 시장 데이터 제공자로 우회하지 않는다.
- 현재 PER/PBR/EPS/BPS는 오늘의 한 행이다. 과거 전용 요청은 미지원이다.
- 현재 개별 시총은 동일 quote의 가격×상장주수라는 계산을 명시한다. 과거 시총으로 확장하지 않는다.
- 스크리닝용 전일 시총은 별도 공식 마스터의 `prdy_avls_scal`(전일 기준, 억원)을 사용한다. 전일 OHLCV·거래량과 날짜를 검증해야 한다.
- 전체시장 과거 시점 유니버스와 시장 전체 수급 등 미지원 영역은 결손을 숨기지 않는다.

## 검증에서 확인한 경계
- 실제 KIS 전체 이력 콜드 조회: 2,684종목 일봉, 약 484.5초. 최초 마스터 대조는 거래량 6건의 1~4주 차이를 거부했다.
- 원문 정수값은 일봉 거래량의 binary32 표현과 정확히 일치했다. 백분율 오차 허용 대신 이 표현 동등성만 한정적으로 수용하고 원래 수치는 유지한다. 공식 문서가 float32 보장을 명시한 것은 아니다.
- 개선 후보의 캐시 재사용 실측: 당일·전일·전일 시총 각각 2,684종목, 약 30.2초. 원천 시총 0·전일 거래량 0·당일 거래량/거래대금 0을 확인한 비거래 종목 1개는 사유를 남겨 제외했다.
- 900초는 응답 수락 예산이며 블로킹 I/O를 강제로 중단하는 기능이 아니다. 자정이 지나면 날짜가 섞인 묶음을 반환하지 않는다.
- 현재 사실의 source/as_of/latest_only/계산식 메타데이터를 MCP와 보고서 입력까지 전달한다. 최신 한 행을 과거 추세·평균 차트로 그리지 않는다.
- 업종 표기 차이를 동일 업종으로 비교한다. KIS의 넓은 `금융`은 정확한 `은행`·`기타금융` 구분으로 꾸미지 않고 둘과 보수적으로 비교한다. 정확한 두 분류끼리는 여전히 구분한다. 넓은 제조 분류도 보수적으로 비교하므로 일부 후보가 이전보다 더 제한될 수 있다. 상한 수치나 기존 DB를 바꾸지 않는다.
- 주말 매도 후 평가·회고는 전체시장 과거 유니버스를 요구하지 않고 필요한 종목의 정확한 과거 일봉을 조회한다.
- 실제 운영 비공개 MCP 설정도 구형 모듈을 호출하고 있었음을 확인했다. 소스뿐 아니라 이 설정과 설치 패키지까지 교체·검증해야 배포 완료다.
