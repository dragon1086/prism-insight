# 오닐 참고 적응형 비중: 입력 생산·검증 경계

## 범위

`oneil-adaptive-v1`의 수치·매매 규칙은 바꾸지 않는다. 이번 변경은 격리된 입력
생산기와 검토 근거 연결이다. 기존 BUY/SELL 프롬프트, 주문, cron, 운영 flag는 보존한다.
구현된 입력이 있다고 해서 prospective SHADOW가 운영 중이거나 LIVE에 적합한 것은 아니다.

## 동시간 거래량

- 거래소 캘린더의 현재 거래일과 직전20거래일을 고정한다. 휴일·DST·조기폐장을
  반영한다. 비교 불가능한 짧은 거래일을 임의로 빼고 다른 날로 교체하지 않는다.
- 각 날짜의 정규장 개장부터 같은 경과 분까지 모든5분봉이 있어야 한다.
  예를 들어 현재 개장40분 시점이라면 과거20일도 각각 개장40분 누적량을 사용한다.
- 봉 누락·중복·비정상 OHLCV·기업행사·가격 기준 불명은 MISSING/INVALID로 표시한다.
  시간외 거래량·미완성 봉은 계산하지 않는다. 일봉 평균이나 선형 환산으로 대체하지 않는다.
- 현재 1개 및 과거20개 누적값, 날짜 목록, 캘린더 출처, 원본 해시를 보존한다.
- 생산기는 quote를 만들지 않는다. 마지막 봉의 종가를 현재 호가라고 부르지 않는다.
- `LIVE_CAPTURE`는 실제 수집 시각과 당시 확정 구간을 만족해야 한다.
  과거 구간을 나중에 받은 것은 `RECONSTRUCTED_REPLAY`이며 prospective 입력으로 사용할 수 없다.
  시간창 완결성 확인은 공급자의 값이 영원히 수정되지 않는다는 보증이 아니다.
  과거 비교일 자료는 재사용할 수 있지만 현재 마지막 확정봉의 조회 시작/완료는
  해당 봉 종료 후120초 이내여야 한다. 각 요청의 실제 수집 시각을 보존한다.
  이 CLI의 전체 기간 조회를 매분 반복하는 스케줄은 설치하지 않는다.

## 베이스·주도주 검토 근거

기존 보고서의 resistance나 F1~F4 문장을 키워드로 긍정 판정하지 않는다.
기존20일 고가 proxy를 proper-base로, 기존 진입 허가를 성장 주도주 증명으로 승격하지 않는다.

별도 `oneil-setup-review-v1` 검토 기록은 다음을 요구한다.

- 같은 market/symbol/decision, 보고서 SHA256, 가격 기준 식별자.
- 명시적 검토자 종류·참조와 검토 시각, 검토 기준 참조.
- base 및 leadership의 CONFIRMED/REJECTED/MISSING 판정.
- 각 판정에 사용한 보고서의 정확한 문자 범위와 해시, 자료 as-of.
- base의 명시적 pivot 값. 누락이나 근거와 연결되지 않은 값을 역산하지 않는다.

`HUMAN_REVIEW`나 `VALIDATED_RULE_OUTPUT`의 명시적 승인만 입력으로 인정한다.
단순 `MODEL_ONLY` 판정은 자동 인증하지 않는다. 이 어댑터가 확인하는 것은 **검토 기록의
일관성과 원문 연결**이며, 검토자의 진위·베이스 적정성·재무 사실을 독립적으로 입증하지 않는다.
검토자는 호출자가 인증해야 한다. 자동 패턴 판별기·주도주 선별기를 구현한 것으로 부르지 않는다.

원문 보고서는 출력하지 않고 해시·상태·형식화된 setup만 반환한다. 입력 보고서나 검토
기록이 없으면 결측을 남긴다. 과거 보고서를 현재 검토한 기록을 과거 판단 시점으로 소급하지 않는다.

## 실제 입력 연결

독립 CLI는 기존 bounded 시세 수집기를 재사용한다. 명시적으로 요청한 한 종목의
공개5분봉과 캘린더만 읽으며 DB·계좌·LLM·메시지·주문에 접근하지 않는다.
원본 가격 응답은 별도 결과물에 고정해 재실행할 수 있게 한다.
setup 검토와 거래량이 준비돼도 실제 fresh quote와 현재 admission/RR/risk/sector/slot
게이트는 별도다. 모든 것이 준비되기 전에는 실행 가능 신호를 만들지 않는다.

`oneil_input_bridge.assemble_evidence`는 입력을 새 정책의 형식으로 연결하지만
실행 허가를 부여하지 않는다. 과거 재구성 입력은 prospective 연결 경계에서 거부한다.
이 경계는 **증액용**이며 기존 손절 보호 경로의 전제조건이 아니다. 거래량·보고서가
없어도 기존 보호 루프는 독립적으로 계속 돌아야 한다.

## 수용 기준

1. 동일 고정 입력의 출력 해시가 같다.
2. 휴일/DST/조기폐장·빠진 봉·중복 봉·미래 자료·0분모·단위 불일치를 검증한다.
3. 이전20거래일의 동일 경과 시각이 정확히 맞는 경우에만 RVOL을 제공한다.
4. source span/hash/identity/검토 시각이 맞지 않으면 setup은 결측 또는 거절이다.
5. 구조화된 입력→기존 적응형 평가기까지 격리 통합시험을 수행한다.
6. 실제 공개가격 조회는 읽기 전용 smoke로 구분하고 수익성·운영 검증으로 부르지 않는다.

## 실행 예시

```bash
python3 tools/build_oneil_adaptive_inputs.py \
  --symbol AAPL --as-of 2026-09-25T14:00:00Z --calendar NASDAQ \
  --output /absolute/new-output.json
```

기본값은 RECONSTRUCTED_REPLAY다. `--saved`로 이전 결과의 원본 가격을 재사용하면
추가 네트워크 호출 없이 재계산하며, 이 경우 LIVE_CAPTURE 지정은 금지한다.
보고서 텍스트·검토 JSON은 선택적 `--report`, `--review`, `--decision-ref`로 제공한다.
없으면 setup을 MISSING으로 남긴다. 결과 JSON은 새 파일에0600으로 생성하며 덮어쓰지 않는다.

## 실제 가격 스모크 (2026-09-27)

AAPL, 대상 시각2026-09-25 14:00UTC(10:00ET), 현재일+직전20거래일을 수집했다.
6개 제한된 요청에서 원시5분봉3913개를 받았으며, 정규장 개장30분의 정확한
126개 봉(21일×6개)으로 누적 거래량을 계산했다. 시간외·나머지 구간을 합에 넣지 않았다.

- 대상일 개장30분 누적: 2,653,458주.
- 직전20거래일 같은 시각 평균: 6,210,531.45주.
- 비율: 0.4272513587배.
- 비교 날짜: 2026-08-27~2026-09-24, 거래소 캘린더의 휴일 제외.
- 수집 완료: 2026-09-27T08:56:10.090323Z. 과거를 나중에 받은 재구성 자료다.
- 최종 Packet `91db6ff6d6d4dabadcddb54d09095afc758e1e0d119962a985477bbc617f5440`.
  같은 원본을 두 번 재생해 ID와 수치가 일치했다. 가격값의 영구 불변 보장은 아니다.

intraday 상태는OK지만 setup은MISSING이며 evaluation_ready=false다.
FRESH_QUOTE_NOT_SUPPLIED, CURRENT_ADMISSION_GATES_NOT_SUPPLIED,
REPORT_OR_REVIEW_MISSING, NO_PROSPECTIVE_INTRADAY_INPUT을 명시했다.
이 스모크는 해당 종목의 매수·증액 판단이나 전략 성과가 아니다.

소프트웨어 검증: 신규 입력 관련60개, 기존 정책·원장·수집기까지 포함한255개
회귀 검사가 통과했다. 별도 KR/US 실제 모듈 가격 형식/배치 통합51개 검사도 통과했다.
Ruff·compileall·diff check 통과. 원격 CI 및 운영 배포·정규 배치 관측은 미실행이다.

## 남은 범위

거래량 생산·검토 원문 연결·입력 조립기와 별도로
`oneil-auto-review-v1` 자동 계산기를 추가했다. 완성 일봉의 한정된 플랫 베이스와
분기 성장·SPY 대비 가격 성과를 계산해 보조 보고서/검토 JSON을 생성한다.
기존 보고서의 긍정 문구를 판독해 통과시키는 방식이 아니며 기존 보고서를 수정하지 않는다.
상세 규칙·제한은 [자동 검토 계약](entry-quality-experiments/oneil-auto-review-v1.md)을 따른다.
실제 보고서의 수치 입력→별도 PDF-bound sidecar→전략 진입 후 최초 계획 연결을 추가했다.
`ONEIL_AUTO_REVIEW_CAPTURE_ENABLED` 기본 OFF이며 기존 최초 캡처 flag도 필요하다.
fresh quote/현재 게이트 공급, 원장 ingestion과 주기 실행은 아직 후속이다.
이번 단계 때문에 새로운 매수 기준을 운영에 넣거나 SHADOW flag를 켜지 않았다.
